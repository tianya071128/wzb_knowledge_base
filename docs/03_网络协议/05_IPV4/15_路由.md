# 路由

路由是网络层的核心能力，本质是**为 IP 数据包选择一条从源到目的的最优转发路径**。

## 路由的基本概念

**路由（Routing）** 就是为数据包选择一条从源到目的地的“最佳路径”的过程。

**路由器（Router）**: 执行这一功能的网络设备。

**路由表**：路由器 / 主机内核维护一张路由表，每一条叫**路由条目**。 数据包到来，查路由表，选出最合适的下一跳，转发出去。

**下一跳 (next‑hop)**：把包交给相邻的那个设备 IP。

::: tip 关键理解

路由器工作在 OSI 第三层（网络层），它**只看 IP 地址**，不看 MAC 地址。每经过一跳路由器，数据帧的二层头部都会被拆除并重新封装，但三层 IP 包的源/目的 IP 不变。

:::

## 路由表：路由决策

无论是路由器还是普通主机，操作系统内核都会维护一张**路由表（Routing Table）**。所有 IP 数据包转发时，都以这张表为依据选择出口和下一跳。

### 路由条目核心字段

每一条路由规则称为一条「路由条目」，核心字段如下：

| 字段                    | 含义                                | 说明                                                         |
| ----------------------- | ----------------------------------- | ------------------------------------------------------------ |
| 目标网络                | 目标网段的网络号                    | 如 `192.168.1.0/24`，代表所有 192.168.1.x 的 IP 都匹配这条路由 |
| 子网掩码/前缀长度       | 用于与目的 IP 做最长前缀匹配        | 如 `192.168.1.0/24`，代表所有 192.168.1.x 的 IP 都匹配这条路由 |
| 子网掩码                | 和前缀长度等价，用来计算网络号      | `255.255.255.0` 对应 `/24`                                   |
| 下一跳（Next Hop）      | 数据包下一步要交给的相邻设备 IP     | 跨网段转发时，把包扔给下一个路由器 / 网关；直连网段没有下一跳 |
| 出接口（Interface）     | 数据包从本机哪个网卡 / 物理接口发出 | 如 `以太网`、`eth0`、`GigabitEthernet0/0/1`                  |
| 管理距离 / 优先级（AD） | 不同路由来源的信任等级              | 数值越小，优先级越高。同目标网段存在多条路由时，优先选优先级高的 |
| 度量值（Metric）        | 同一种路由来源下，路径的优劣程度    | 数值越小，路径越好。用于同协议、同前缀的多条路由选优         |

## 路由的来源分类

路由器通过三种方式获得路由条目：

### 直连路由

- **生成方式**：路由器 / 主机的接口配置 IP，且接口物理、协议均为 UP 状态时，自动生成该接口所在网段的路由。
- **特点**：优先级最高、零配置、仅覆盖接口直连的网段。
- 举例：网卡配置 `192.168.7.102/24`，系统自动生成 `192.168.7.0/24` 直连路由。

### 静态路由

- **生成方式**：由管理员手动逐条配置写入路由表。
- **特点**：稳定、无协议开销、不会自动更新；网络拓扑变化时必须手动修改，适合小型、拓扑固定的网络。

#### 默认路由

**特殊的静态路由，目标网络为 `0.0.0.0/0`。当所有精确路由都匹配失败时，兜底使用这条路由，通常指向网关，是主机上网的核心路由。**

### 动态路由

- **生成方式**：路由器之间运行动态路由协议（如 OSPF、RIP、BGP），自动互相交换路由信息、学习路径，拓扑变化时自动更新路由表。
- **特点**：自适应拓扑变化、维护成本低，适合中大型企业网、互联网骨干。

## 主机路由 vs 路由器路由

普通电脑也有路由表，但和路由器的作用有本质区别：

| 对比项      | 普通主机（PC / 服务器）                   | 路由器                                   |
| ----------- | ----------------------------------------- | ---------------------------------------- |
| 核心作用    | 只处理本机收发的数据包                    | 处理所有过境的 IP 数据包，负责跨网段转发 |
| IP 转发功能 | 默认关闭，不会转发别人发过来的包          | 默认开启，核心功能就是转发               |
| 路由表规模  | 条目极少，通常只有「直连网段 + 默认路由」 | 条目多，全网段路由信息                   |
| 路由来源    | 手动配置 / DHCP 获取                      | 直连 + 静态 + 动态路由协议               |
