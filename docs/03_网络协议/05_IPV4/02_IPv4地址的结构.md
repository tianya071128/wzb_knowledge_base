# IPv4 地址的结构

IPv4 地址是一个 **32 位**的二进制数，用于唯一标识互联网中的主机。

## 表示方式

### 二进制形式

```
11000000.10101000.00000001.01100100
```

### 点分十进制

将 32 位分为 4 组（每组 8 位），每组转换为十进制，用 `.` 分隔：

```
192.168.1.100
```

每段取值范围：0 ~ 255

## 网络号 + 主机号

IPv4 地址由两部分组成：

```
|<-------- 网络号 -------->|<---- 主机号 ---->|
         192.168.1                  .100
```

- **网络号（Network ID）**：

  IP 地址的**高位部分**，用于标识主机所属的**逻辑网段**。

  - 同一网段内所有主机的网络号完全相同；
  - 路由器依靠网络号进行路由决策，把数据包转发到对应的目标网段，不需要关心具体主机。

- **主机号（Host ID）**：

  IP 地址的**低位部分**，用于标识**同一网段内的某一台具体设备**（电脑、手机、服务器等）。

  - 在同一个网络号下，主机号必须唯一；
  - 数据包到达目标网段后，依靠主机号（结合 ARP 协议映射 MAC 地址）交付给具体终端。

### 类比理解

```
IP 地址 = 网络号 + 主机号
类比：   小区名  + 楼栋房号

192.168.1.100/24
└─ 网络号: 192.168.1   → “哪个小区”
└─ 主机号: 100          → “哪栋房”
```

同一个网络内的所有主机，网络号相同，主机号不同：

```
192.168.1.1    → 网络号 192.168.1，主机号 1（通常是网关）
192.168.1.100  → 网络号 192.168.1，主机号 100
192.168.1.200  → 网络号 192.168.1，主机号 200
```

### 它有什么作用？

这种分层结构，是互联网能扩展到全球规模的根本设计之一。

1. **路由聚合，压缩路由表**
   
如果没有网络号，路由器需要为每台主机记录一条路由，全球几十亿台设备的路由表将无法维护。有了网络号后，路由器只记录“去哪个网络”，一条路由就能覆盖整个网段：
   
   ```
   没有网络号：路由器记录每台主机的位置 → 路由表爆炸
   有了网络号：路由器只记录“去 192.168.1.0/24 走 eth0” → 一条路由覆盖 254 台主机
```

2. **路由时只看网络号，不管主机号**
   
   互联网上的主干路由器在做转发决策时，**只关心你把包发到哪个网段（网络号）**，而不关心网段里具体的哪台机器。这极大压缩了全球路由表的条目数。只有到达目标网段的最后一跳路由器，才会用主机号把包最终送到你手上。
   
3. **判断是否“直连”**

   一台主机要发数据时，会用**自己的掩码**去计算目标IP的网络号。如果发现目标IP的网络号和自己一样，说明对方在同一个局域网内，可以直接通信（通过ARP找MAC地址）；如果网络号不同，就必须把数据包发给默认网关，由路由器进行转发。
