# IP

IP（Internet Protocol，网际协议）是网络层的核心协议，负责将数据包从源主机传送到目的主机。IP 提供**无连接、不可靠、尽力而为**的数据报传输服务。

## 核心职责

### 跨网段主机寻址

IP 为互联网中每台主机分配唯一地址，使得不同网段的主机能够互相识别和通信：

- 通过 IP 地址 + 子网掩码判断目标主机是否在同一网段
- 同网段：直接通过 MAC 地址交付（ARP 解析）
- 跨网段：将数据包发送给默认网关（路由器），由路由器逐跳转发

### 路由选路转发

路由器根据目的 IP 查询路由表，选择最优路径将数据包转发到下一跳：

- 每个路由器独立做转发决策（逐跳转发）
- 匹配规则：最长前缀匹配（最精确的路由优先）
- 无匹配时走默认路由（`0.0.0.0/0`）

### 报文分片与重组

当 IP 数据报大小超过链路 MTU（最大传输单元）时，路由器会将其分片：

```
原始数据报: 4000 字节（MTU = 1500）
    ↓ 分片
片1: 1480 字节数据 + 20 字节首部（MF=1, Offset=0）
片2: 1480 字节数据 + 20 字节首部（MF=1, Offset=185）
片3: 1040 字节数据 + 20 字节首部（MF=0, Offset=370）
```

- 分片由路由器完成，重组由目的主机完成
- 通过 Identification、Flags（MF）、Fragment Offset 字段关联各分片
- 任一分片丢失则整个数据报丢弃（IP 不重传，交给上层处理）


## IP 的特点

### 无连接

发送数据前不需要建立连接，每个数据包（数据报）独立路由：

- 没有握手、没有会话状态，路由器不记录“连接”信息
- 同一批数据包可能走不同路径到达目的地
- 路由器负担轻，转发速度快

对比 TCP：TCP 需要先三次握手建立连接，维护连接状态，保证顺序和可靠性。

### 不可靠

IP 不做任何交付保证：

- **不保证到达**：数据包可能被丢弃（TTL 耗尽、拥塞、校验和错误）
- **不保证顺序**：不同路径导致到达顺序可能与发送顺序不同
- **不重传**：丢失的数据包不会自动重发
- **不确认**：没有 ACK 机制，发送方不知道对方是否收到

这些责任交给上层协议（如 TCP）处理。

### 尽力而为（Best Effort）

网络会尽最大努力转发数据包，但不做任何承诺：

- 路由器尽力转发，但资源不足时会丢弃
- 没有 QoS 保证（延迟、带宽、丢包率均无承诺）
- 网络拥塞时不会通知发送方降速（与 TCP 的拥塞控制不同）

### 总结对比

| 特点 | 含义 | 后果 |
| --- | --- | --- |
| 无连接 | 无需建立连接 | 开销小，但无法保证同一连接内的一致性 |
| 不可靠 | 不保证到达/顺序 | 需要上层（TCP）做确认、重传、排序 |
| 尽力而为 | 尽力转发不承诺 | 网络质量无保障，实时应用需额外机制 |

## IPv4

### 地址格式

IPv4 地址为 32 位，通常用点分十进制表示：

```
192.168.1.100
```

每段取值范围 0~255，共 4 段，总共约 43 亿个地址。

### 地址分类

| 类别 | 范围 | 网络位 | 主机位 | 用途 |
| --- | --- | --- | --- | --- |
| A | 1.0.0.0 ~ 126.255.255.255 | 8 位 | 24 位 | 大型网络 |
| B | 128.0.0.0 ~ 191.255.255.255 | 16 位 | 16 位 | 中型网络 |
| C | 192.0.0.0 ~ 223.255.255.255 | 24 位 | 8 位 | 小型网络 |
| D | 224.0.0.0 ~ 239.255.255.255 | - | - | 组播 |
| E | 240.0.0.0 ~ 255.255.255.255 | - | - | 保留/实验 |

### 特殊地址

| 地址 | 说明 |
| --- | --- |
| `0.0.0.0` | 本机（未分配地址时使用） |
| `127.0.0.1` | 回环地址（localhost） |
| `255.255.255.255` | 广播地址 |
| `10.x.x.x` | A 类私有地址 |
| `172.16.x.x ~ 172.31.x.x` | B 类私有地址 |
| `192.168.x.x` | C 类私有地址 |

### 子网掩码

子网掩码用于划分 IP 地址中的网络部分和主机部分：

```
IP:       192.168.1.100
掩码:     255.255.255.0   （即 /24）
网络地址: 192.168.1.0
主机地址: 100
广播地址: 192.168.1.255
```

CIDR 表示法：`192.168.1.100/24` 表示前 24 位为网络位。
