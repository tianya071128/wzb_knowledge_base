# IP 配套协议

IPv4 位于**网络层**，配套协议分为：**网络层同层协议、跨层支撑协议**。

## 网络层同层协议

特点：报文拥有独立协议标识，直接封装在二层帧内；ICMP/IGMP 载荷承载于 IP 报文之中。

### ICMP（Internet 控制报文协议）

协议号：1

作用：差错报告、网络诊断（ping、tracert），IP 的控制协议。

### IGMP（互联网组管理协议）

协议号：2

作用：IPv4 组播体系，主机向路由器申请接收指定组播流。

## 跨层支撑协议

### 数据链路层

#### ARP（地址解析协议）

作用：IPv4 地址解析为 MAC 地址；同网段发送 IP 报文的前置条件。

### 应用层（依靠 UDP/TCP 传输）

#### DHCP（动态主机配置协议）

作用：自动分配 IP、掩码、网关、DNS 等 IP 运行所需参数。
