# 有类编址

有类编址（Classful Addressing）是 IPv4 早期的标准地址划分方案，由 IANA 统一制定规则：**根据 IP 首字节的高位二进制特征，固定划分网络号与主机号的边界**，不支持灵活调整，所有网络按固定长度分为 A、B、C、D、E 五大类。

其中 A、B、C 三类是**单播地址**，可分配给主机作为通信地址，有明确的「网络号 + 主机号」两级结构；D 类是组播地址，E 类为保留实验地址，D和E类 无网络号 / 主机号划分。

## A 类

```
0xxxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx
│← 网络号(8位) →│←───── 主机号(24位) ─────→│
```

- 首位固定为 `0`，首字节范围：**1 ~ 126**
- 网络数量：2⁷ - 2 = 126 个（去掉 0 和 127）
- 每个网络可用主机：2²⁴ - 2 ≈ **1677 万**台
- 默认掩码：`255.0.0.0`（/8）
- 适用场景：超大型组织（早期分配给政府、大企业、高校）
- 典型示例：`10.x.x.x`（私有）、`127.x.x.x`（回环，不可用）

## B 类

```
10xxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx
│←── 网络号(16位) ──→│←── 主机号(16位) ──→│
```

- 前两位固定为 `10`，首字节范围：**128 ~ 191**
- 网络数量：2¹⁴ = 16384 个
- 每个网络可用主机：2¹⁶ - 2 = **65534** 台
- 默认掩码：`255.255.0.0`（/16）
- 适用场景：中型组织（企业、大学）
- 典型示例：`172.16.x.x ~ 172.31.x.x`（私有）

## C 类

```
110xxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx
│←──── 网络号(24位) ────→│← 主机号(8位) →│
```

- 前三位固定为 `110`，首字节范围：**192 ~ 223**
- 网络数量：2²¹ ≈ 209 万个
- 每个网络可用主机：2⁸ - 2 = **254** 台
- 默认掩码：`255.255.255.0`（/24）
- 适用场景：小型网络（小型企业、实验室）
- 典型示例：`192.168.x.x`（私有）

## D 类（组播）

```
1110xxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx
```

- 前四位固定为 `1110`，首字节范围：**224 ~ 239**
- 不划分网络号/主机号，整个 32 位是一个组播组地址
- 用途：一对多通信（视频会议、路由协议广播等）
- 典型示例：`224.0.0.1`（所有主机）、`224.0.0.5`（OSPF）

## E 类（保留）

```
1111xxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx
```

- 前四位固定为 `1111`，首字节范围：**240 ~ 255**
- 保留用于实验和研究，不分配给任何主机
- 典型示例：`255.255.255.255`（受限广播）

## 总览对比

| 类别 | 前缀 | 首字节 | 网络位 | 主机位 | 可用主机数 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| A | `0` | 1~126 | 8 | 24 | ≈1677 万 | 超大型网络 |
| B | `10` | 128~191 | 16 | 16 | 65534 | 中型网络 |
| C | `110` | 192~223 | 24 | 8 | 254 | 小型网络 |
| D | `1110` | 224~239 | - | - | - | 组播 |
| E | `1111` | 240~255 | - | - | - | 保留/实验 |

## 核心缺陷与淘汰原因

有类编址是互联网早期的简单方案，随着网络规模爆发式增长，其设计缺陷完全暴露，最终被无类编址（CIDR）全面替代：

### 1. 地址浪费极其严重

- A 类网段单网可容纳 1600 万台主机，绝大多数机构根本用不完，大量地址闲置
- C 类网段只有 254 个地址，稍大的企业就不够用，只能申请 B 类，又造成 B 类地址的巨大浪费
- 整体地址利用率极低，加速了 IPv4 地址枯竭

### 2. 骨干网路由表膨胀

数量庞大的 C 类网段，每个都需要在全球骨干路由表中占一条独立条目，导致路由器路由表爆炸式增长，转发性能下降、内存开销剧增。

### 3. 划分不灵活

网络号边界完全固定，不能根据企业实际规模调整网段大小，也无法在内部进一步划分子网隔离业务，无法满足精细化网络规划需求。

### 4. 演进替代方案

为解决上述问题，行业逐步推出了三层优化方案，最终全面进入无类编址时代：

1. 子网划分：在主机号中借出部分位作为子网号，把大网段拆分为多个小网段
2. VLSM（可变长子网掩码）：同一主类网络下，不同子网可以使用不同长度的掩码
3. CIDR（无类域间路由）：彻底抛弃 A/B/C 类概念，用「IP 地址 / 前缀长度」自由定义网段边界，同时支持路由聚合（超网），大幅压缩路由表规模
