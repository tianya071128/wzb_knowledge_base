# 编写泛型

## 泛型类的设计

### 基本设计原则

```java
// 1. 使用有意义的类型参数名称
public class Cache<K, V> {
    private Map<K, V> cache = new HashMap<>();
    
    public void put(K key, V value) {
        cache.put(key, value);
    }
    
    public V get(K key) {
        return cache.get(key);
    }
}

// 2. 提供便捷的构造方法
public class Box<T> {
    private T item;
    
    public Box() {}
    
    public Box(T item) {
        this.item = item;
    }
    
    public static <T> Box<T> of(T item) {
        return new Box<>(item);
    }
}

// 使用
Box<String> box = Box.of("Hello");
```

### 多类型参数的类

```java
// 三元组
public class Triple<A, B, C> {
    private A first;
    private B second;
    private C third;
    
    public Triple(A first, B second, C third) {
        this.first = first;
        this.second = second;
        this.third = third;
    }
    
    public A getFirst() { return first; }
    public B getSecond() { return second; }
    public C getThird() { return third; }
    
    // 静态工厂方法
    public static <A, B, C> Triple<A, B, C> of(A first, B second, C third) {
        return new Triple<>(first, second, third);
    }
}

// 使用
Triple<String, Integer, Boolean> triple = Triple.of("age", 25, true);
```

### 接口继承

```java
// 接口可以继承其他接口
public interface Comparable<T> {
    int compareTo(T o);
}

public interface Sortable<T extends Comparable<T>> extends Comparable<T> {
    default boolean isLessThan(T other) {
        return compareTo(other) < 0;
    }
}

// 实现类
public class Student implements Sortable<Student> {
    private String name;
    private int score;
    
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
    
    @Override
    public int compareTo(Student other) {
        return Integer.compare(this.score, other.score);
    }
}
```

## 泛型方法的设计

### 类型推断优化

```java
// 1. 利用类型推断
public class Collections {
    // 编译器会自动推断 T 的类型
    public static <T> List<T> emptyList() {
        return new ArrayList<>();
    }
    
    public static <T> Set<T> emptySet() {
        return new HashSet<>();
    }
    
    public static <T> Map<T, T> emptyMap() {
        return new HashMap<>();
    }
}

// 使用 - 无需显式指定类型
List<String> list = Collections.emptyList();
Set<Integer> set = Collections.emptySet();
```

### 泛型方法的限制

```java
// 使用边界限制类型
public <T extends Comparable<T>> T max(T a, T b) {
    return a.compareTo(b) >= 0 ? a : b;
}

// 多个边界
public <T extends Comparable<T> & Serializable> T findMax(List<T> list) {
    return list.stream()
        .max(Comparable::compareTo)
        .orElse(null);
}

// 使用
String maxStr = max("apple", "banana"); // "banana"
Integer maxNum = max(10, 20); // 20
```



## 高级泛型模式

### 1. 递归类型边界

```java
// 类型参数引用自身
public abstract class Enum<E extends Enum<E>> implements Comparable<E> {
    private final String name;
    private final int ordinal;
    
    protected Enum(String name, int ordinal) {
        this.name = name;
        this.ordinal = ordinal;
    }
    
    public final String name() { return name; }
    public final int ordinal() { return ordinal; }
    
    @Override
    public int compareTo(E other) {
        return Integer.compare(this.ordinal, other.ordinal);
    }
}

// 使用
public class Color extends Enum<Color> {
    public static final Color RED = new Color("RED", 0);
    public static final Color GREEN = new Color("GREEN", 1);
    public static final Color BLUE = new Color("BLUE", 2);
    
    private Color(String name, int ordinal) {
        super(name, ordinal);
    }
}
```

### 2. 泛型方法链

```java
public class Builder<T> {
    private T instance;
    
    public Builder(T instance) {
        this.instance = instance;
    }
    
    public static <T> Builder<T> of(T instance) {
        return new Builder<>(instance);
    }
    
    public <R> Builder<R> map(Function<T, R> mapper) {
        return new Builder<>(mapper.apply(instance));
    }
    
    public T get() {
        return instance;
    }
}

// 使用
String result = Builder.of(10)
    .map(x -> x * 2)      // Builder<Integer>
    .map(x -> x + "元")   // Builder<String>
    .get();                // "20元"
```

### 3. 泛型与注解结合

```java
// 定义泛型注解
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
public @interface EntityInfo {
    Class<?>[] value();
}

// 使用泛型注解
@EntityInfo({String.class, Integer.class})
public class MyEntity {
    // ...
}

// 运行时获取泛型信息
EntityInfo info = MyEntity.class.getAnnotation(EntityInfo.class);
Class<?>[] types = info.value(); // [String.class, Integer.class]
```

## 泛型设计的最佳实践

### 1. 优先使用泛型方法

```java
// 好的设计 - 泛型方法
public class Utils {
    public static <T> T firstNonNull(T a, T b) {
        return a != null ? a : b;
    }
}

// 不好的设计 - 使用 Object
public class Utils {
    public static Object firstNonNull(Object a, Object b) {
        return a != null ? a : b;
    }
}
```

### 2. 使用通配符增加灵活性

```java
// 使用 extends 提高读取灵活性
public double sum(List<? extends Number> numbers) {
    double sum = 0;
    for (Number n : numbers) {
        sum += n.doubleValue();
    }
    return sum;
}

// 使用 super 提高写入灵活性
public void addIntegers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
    list.add(3);
}
```

### 3. 避免过度使用泛型

```java
// 好的设计 - 只在必要时使用
public class Cache<K, V> {
    private Map<K, V> cache = new HashMap<>();
    
    public void put(K key, V value) {
        cache.put(key, value);
    }
    
    public V get(K key) {
        return cache.get(key);
    }
}

// 不好的设计 - 不必要的泛型
public class StringProcessor<T> {
    public String process(T input) {
        return input.toString();
    }
}
```

### 4. 提供清晰的错误信息

```java
public class TypeSafeContainer<T> {
    private Map<Class<?>, Object> items = new HashMap<>();
    
    public <R> R get(Class<R> type) {
        Object item = items.get(type);
        if (item == null) {
            throw new IllegalArgumentException(
                "No item of type " + type.getName() + " found"
            );
        }
        return type.cast(item);
    }
    
    public <R> void put(Class<R> type, R item) {
        items.put(type, item);
    }
}

// 使用
TypeSafeContainer container = new TypeSafeContainer();
container.put(String.class, "Hello");
container.put(Integer.class, 100);

String str = container.get(String.class);   // "Hello"
Integer num = container.get(Integer.class); // 100
```

## 总结

编写泛型的关键要点：

1. **合理命名类型参数**：使用 T、E、K、V 等约定俗成的名称
2. **使用边界限制**：通过 `extends` 和 `super` 限制类型范围
3. **优先使用泛型方法**：比泛型类更灵活
4. **利用类型推断**：减少冗余的类型声明
5. **注意类型擦除**：运行时泛型信息会丢失
6. **提供清晰的 API**：让使用者容易理解和使用

通过合理使用泛型，可以编写出更安全、更通用、更易维护的代码。
