# 使用泛型

## 泛型类的使用

### 基本使用

```java
// 定义泛型类
public class Box<T> {
    private T item;
    
    public void setItem(T item) {
        this.item = item;
    }
    
    public T getItem() {
        return item;
    }
}

// 使用泛型类
Box<String> stringBox = new Box<>();
stringBox.setItem("Hello");
String str = stringBox.getItem(); // 无需强制转换

Box<Integer> intBox = new Box<>();
intBox.setItem(100);
int num = intBox.getItem();
```

### 多个类型参数

```java
// 定义多个类型参数的泛型类
public class Pair<K, V> {
    private K key;
    private V value;
    
    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }
    
    public K getKey() {
        return key;
    }
    
    public V getValue() {
        return value;
    }
}

// 使用
Pair<String, Integer> pair = new Pair<>("age", 25);
String key = pair.getKey();
Integer value = pair.getValue();
```

## 泛型接口的使用

### 定义和使用

```java
// 定义泛型接口
public interface Comparable<T> {
    int compareTo(T o);
}

// 实现泛型接口
public class Student implements Comparable<Student> {
    private int age;
    private String name;
    
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    @Override
    public int compareTo(Student other) {
        return Integer.compare(this.age, other.age);
    }
}
```

### 集合中的泛型接口

```java
// List 接口
List<String> list = new ArrayList<>();
list.add("item1");
list.add("item2");

// Set 接口
Set<Integer> set = new HashSet<>();
set.add(1);
set.add(2);

// Map 接口
Map<String, Integer> map = new HashMap<>();
map.put("one", 1);
map.put("two", 2);
```

## 泛型方法的使用

### 基本语法

```java
// 泛型方法定义
public <T> void printArray(T[] array) {
    for (T element : array) {
        System.out.println(element);
    }
}

// 调用泛型方法
Integer[] intArray = {1, 2, 3, 4, 5};
String[] strArray = {"a", "b", "c"};

printArray(intArray); // 编译器自动推断 T 为 Integer
printArray(strArray); // 编译器自动推断 T 为 String
```

### 泛型方法的返回值

```java
// 返回泛型类型
public <T> T getFirstElement(List<T> list) {
    if (list.isEmpty()) {
        return null;
    }
    return list.get(0);
}

// 使用
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
String firstName = getFirstElement(names); // 返回 "Alice"

List<Integer> numbers = Arrays.asList(10, 20, 30);
Integer firstNum = getFirstElement(numbers); // 返回 10
```

### 多个类型参数的方法

```java
// 多个类型参数
public <K, V> void printKeyValue(K key, V value) {
    System.out.println(key + " = " + value);
}

// 使用
printKeyValue("name", "Alice");
printKeyValue(1, "one");
printKeyValue("age", 25);
```


## 实际应用示例

### 示例1：通用的容器类

```java
public class Container<T> {
    private List<T> items = new ArrayList<>();
    
    public void add(T item) {
        items.add(item);
    }
    
    public T get(int index) {
        return items.get(index);
    }
    
    public int size() {
        return items.size();
    }
}

// 使用
Container<String> stringContainer = new Container<>();
stringContainer.add("item1");
stringContainer.add("item2");
String item = stringContainer.get(0);
```

### 示例2：通用的工具方法

```java
public class ArrayUtils {
    // 交换数组中的两个元素
    public static <T> void swap(T[] array, int i, int j) {
        T temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }
    
    // 查找元素在数组中的位置
    public static <T> int indexOf(T[] array, T element) {
        for (int i = 0; i < array.length; i++) {
            if (array[i].equals(element)) {
                return i;
            }
        }
        return -1;
    }
}

// 使用
Integer[] numbers = {1, 2, 3, 4, 5};
ArrayUtils.swap(numbers, 0, 4);
int index = ArrayUtils.indexOf(numbers, 3);
```

### 示例3：泛型与反射

```java
public class TypeReference<T> {
    private Type type;
    
    public TypeReference() {
        this.type = ((ParameterizedType) getClass()
            .getGenericSuperclass())
            .getActualTypeArguments()[0];
    }
    
    public Type getType() {
        return type;
    }
}

// 使用
TypeReference<List<String>> ref = new TypeReference<List<String>>() {};
Type type = ref.getType(); // 获取 List<String> 的类型信息
```

## 注意事项

### 1. 不能实例化泛型数组

```java
// 错误
T[] array = new T[10]; // 编译错误

// 正确做法
Object[] array = new Object[10];
T item = (T) array[0];
```

### 2. 不能创建泛型类型的实例

```java
// 错误
T obj = new T(); // 编译错误

// 正确做法 - 使用工厂方法或 Class 对象
public <T> T createInstance(Class<T> clazz) {
    try {
        return clazz.newInstance();
    } catch (Exception e) {
        throw new RuntimeException(e);
    }
}
```

### 3. 泛型类中静态方法不能使用类的泛型类型

```java
// 错误
public class Box<T> {
    public static T getStatic() { // 编译错误
        return null;
    }
}

// 正确 - 静态方法需要自己的泛型
public class Box<T> {
    public static <E> E getStatic() {
        return null;
    }
}
```

## 总结

使用泛型的关键点：

1. **泛型类**：定义一次，适用于多种类型
2. **泛型接口**：提供通用的接口规范
3. **泛型方法**：方法级别复用，类型自动推断
4. **通配符**：处理泛型的继承关系
5. **类型擦除**：运行时泛型信息消失

合理使用泛型可以写出更安全、更简洁、更易维护的代码。
