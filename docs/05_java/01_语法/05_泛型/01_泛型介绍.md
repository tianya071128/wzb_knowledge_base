# 泛型介绍

## 什么是泛型

泛型（Generics）是 Java 5 引入的重要特性，它允许在定义类、接口和方法时使用类型参数，从而实现代码的类型安全和复用。

## 泛型的核心优势

### 1. 类型安全

泛型在编译时期提供类型检查，避免运行时的类型转换错误：

```java
// 不使用泛型 - 运行时可能出错
List list = new ArrayList();
list.add("hello");
String s = (String) list.get(0); // 需要强制类型转换

// 使用泛型 - 编译时检查
List<String> list = new ArrayList<>();
list.add("hello");
String s = list.get(0); // 无需强制转换，类型安全
```

### 2. 代码复用

泛型允许编写通用的代码，适用于多种类型：

```java
// 通用的工具方法
public <T> void printArray(T[] array) {
    for (T element : array) {
        System.out.println(element);
    }
}

// 可用于任何类型
Integer[] intArray = {1, 2, 3};
String[] strArray = {"a", "b", "c"};
printArray(intArray);
printArray(strArray);
```

### 3. 消除强制类型转换

泛型自动处理类型转换，代码更简洁：

```java
// 不使用泛型
Map map = new HashMap();
map.put("key", "value");
String value = (String) map.get("key");

// 使用泛型
Map<String, String> map = new HashMap<>();
map.put("key", "value");
String value = map.get("key"); // 无需强制转换
```

## 泛型的使用场景

### 1. 集合框架

Java 集合框架是泛型最典型的应用：

```java
List<String> list = new ArrayList<>();
Set<Integer> set = new HashSet<>();
Map<String, Integer> map = new HashMap<>();
```

### 2. 自定义数据结构

```java
public class Box<T> {
    private T content;
    
    public void put(T item) {
        this.content = item;
    }
    
    public T get() {
        return content;
    }
}
```

### 3. 工具类和算法

```java
public class Collections {
    public static <T extends Comparable<? super T>> void sort(List<T> list) {
        // 排序算法
    }
}
```

## 泛型的基本语法

### 类型参数命名约定

- `T` - Type（类型）
- `E` - Element（元素）
- `K` - Key（键）
- `V` - Value（值）
- `N` - Number（数字）
- `R` - Result（结果）

### 泛型的基本使用

```java
// 泛型类
public class MyClass<T> {
    private T field;
}

// 泛型接口
public interface MyInterface<T> {
    void method(T param);
}

// 泛型方法
public <T> void myMethod(T param) {
    // 方法体
}
```

## 总结

泛型是 Java 中非常重要的特性，它提供了：

- **编译时类型安全检查**
- **代码复用性提高**
- **消除强制类型转换**
- **更清晰的代码语义**
