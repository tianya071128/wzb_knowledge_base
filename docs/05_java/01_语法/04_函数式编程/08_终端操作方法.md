# 终端操作方法

## 概述

Stream 的**终端操作**（Terminal Operations）是触发 Stream 实际执行的操作，执行后 Stream 被关闭，不能再被使用。终端操作会返回一个结果、产生副作用或消费整个流。

终端操作是 Stream 管道的**终点**，没有终端操作，中间操作不会被执行。

## 遍历操作

### forEach

`forEach(Consumer<? super T> action)` 遍历 Stream 中的每个元素并执行指定操作。

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// 遍历打印
names.stream().forEach(System.out::println);

// 遍历执行复杂操作
names.stream().forEach(name -> {
    System.out.println("Name: " + name);
    System.out.println("Length: " + name.length());
});
```

### forEachOrdered

`forEachOrdered(Consumer<? super T> action)` 按照元素的**遭遇顺序**（encounter order）遍历。在并行流中，`forEach` 不保证顺序，而 `forEachOrdered` 保证顺序。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// 并行流中使用 forEachOrdered 保证顺序
numbers.parallelStream().forEachOrdered(System.out::println);
// 保证输出：1, 2, 3, 4, 5（按顺序）

// 并行流中使用 forEach 不保证顺序
numbers.parallelStream().forEach(System.out::println);
// 可能输出：3, 1, 5, 2, 4（顺序不确定）
```

## 收集操作

### collect

`collect(Collector<? super T, A, R> collector)` 是最常用的终端操作，将 Stream 元素收集到各种数据结构中。

#### 收集为 List

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

List<String> result = names.stream()
    .filter(name -> name.length() > 3)
    .collect(Collectors.toList());
// 结果：["Alice", "Charlie"]

// Java 16+ 简化写法
List<String> result = names.stream()
    .filter(name -> name.length() > 3)
    .toList();
```

#### 收集为 Set

```java
List<String> names = Arrays.asList("Alice", "Bob", "Alice", "Charlie");

Set<String> uniqueNames = names.stream()
    .collect(Collectors.toSet());
// 结果：{"Alice", "Bob", "Charlie"}（自动去重）
```

#### 收集为 Map

```java
List<User> users = Arrays.asList(
    new User("Alice", 20),
    new User("Bob", 25),
    new User("Charlie", 30)
);

// 姓名 -> 年龄
Map<String, Integer> nameToAge = users.stream()
    .collect(Collectors.toMap(User::getName, User::getAge));
// 结果：{Alice=20, Bob=25, Charlie=30}

// 处理键冲突
Map<String, User> userMap = users.stream()
    .collect(Collectors.toMap(
        User::getName,
        user -> user,
        (existing, replacement) -> existing // 保留第一个
    ));
```

#### 收集为其他数据结构

```java
// 收集为 LinkedList
LinkedList<String> linkedList = names.stream()
    .collect(Collectors.toCollection(LinkedList::new));

// 收集为 TreeSet（自动排序）
TreeSet<String> treeSet = names.stream()
    .collect(Collectors.toCollection(TreeSet::new));

// 收集为 TreeMap
TreeMap<String, Integer> treeMap = users.stream()
    .collect(Collectors.toMap(
        User::getName,
        User::getAge,
        (a, b) -> a,
        TreeMap::new
    ));
```

### Collectors 的常用归约操作

#### joining — 字符串连接

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

String joined = names.stream()
    .collect(Collectors.joining(", "));
// 结果："Alice, Bob, Charlie"

// 带前缀和后缀
String formatted = names.stream()
    .collect(Collectors.joining(", ", "[", "]"));
// 结果："[Alice, Bob, Charlie]"
```

#### counting — 计数

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

long count = numbers.stream()
    .collect(Collectors.counting());
// 结果：5

// 等价写法
long count = numbers.stream().count();
```

#### summing / averaging — 求和与平均值

```java
List<User> users = Arrays.asList(
    new User("Alice", 20),
    new User("Bob", 25),
    new User("Charlie", 30)
);

// 求和
int totalAge = users.stream()
    .collect(Collectors.summingInt(User::getAge));
// 结果：75

// 平均值
double avgAge = users.stream()
    .collect(Collectors.averagingInt(User::getAge));
// 结果：25.0
```

#### maxBy / minBy — 最大值与最小值

```java
List<User> users = Arrays.asList(
    new User("Alice", 20),
    new User("Bob", 25),
    new User("Charlie", 30)
);

// 年龄最大的用户
Optional<User> oldest = users.stream()
    .collect(Collectors.maxBy(Comparator.comparingInt(User::getAge)));
// 结果：Optional[Charlie, 30]

// 年龄最小的用户
Optional<User> youngest = users.stream()
    .collect(Collectors.minBy(Comparator.comparingInt(User::getAge)));
// 结果：Optional[Alice, 20]
```

#### groupingBy — 分组

```java
List<User> users = Arrays.asList(
    new User("Alice", "Engineering"),
    new User("Bob", "Marketing"),
    new User("Charlie", "Engineering"),
    new User("David", "Marketing")
);

// 按部门分组
Map<String, List<User>> byDept = users.stream()
    .collect(Collectors.groupingBy(User::getDepartment));
// 结果：{Engineering=[Alice, Charlie], Marketing=[Bob, David]}

// 分组后计数
Map<String, Long> countByDept = users.stream()
    .collect(Collectors.groupingBy(
        User::getDepartment,
        Collectors.counting()
    ));
// 结果：{Engineering=2, Marketing=2}

// 多级分组
Map<String, Map<Integer, List<User>>> multiGroup = users.stream()
    .collect(Collectors.groupingBy(
        User::getDepartment,
        Collectors.groupingBy(User::getAge)
    ));
```

#### partitioningBy — 分区

```java
List<User> users = Arrays.asList(
    new User("Alice", 20),
    new User("Bob", 25),
    new User("Charlie", 30),
    new User("David", 18)
);

// 按年龄是否大于 20 分区
Map<Boolean, List<User>> partitioned = users.stream()
    .collect(Collectors.partitioningBy(u -> u.getAge() > 20));
// 结果：{false=[Alice(20), David(18)], true=[Bob(25), Charlie(30)]}

// 分区后计数
Map<Boolean, Long> countPartitioned = users.stream()
    .collect(Collectors.partitioningBy(
        u -> u.getAge() > 20,
        Collectors.counting()
    ));
// 结果：{false=2, true=2}
```

## 聚合操作

### count

`count()` 返回 Stream 中元素的数量。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

long count = numbers.stream().count();
// 结果：5

// 配合 filter 使用
long evenCount = numbers.stream()
    .filter(n -> n % 2 == 0)
    .count();
// 结果：2
```

### min / max

`min(Comparator)` 和 `max(Comparator)` 返回 Stream 中的最小值和最大值。

```java
List<Integer> numbers = Arrays.asList(5, 2, 8, 1, 9);

Optional<Integer> min = numbers.stream().min(Integer::compareTo);
// 结果：Optional[1]

Optional<Integer> max = numbers.stream().max(Integer::compareTo);
// 结果：Optional[9]

// 自定义对象
List<User> users = Arrays.asList(
    new User("Alice", 20),
    new User("Bob", 25),
    new User("Charlie", 30)
);

Optional<User> youngest = users.stream()
    .min(Comparator.comparingInt(User::getAge));
// 结果：Optional[Alice, 20]
```

## 归约操作

### reduce

`reduce` 将 Stream 元素归约为一个值。有三种重载形式：

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// 1. 无初始值：返回 Optional
Optional<Integer> sum = numbers.stream()
    .reduce((a, b) -> a + b);
// 结果：Optional[15]

// 2. 有初始值：返回具体类型
int sum = numbers.stream()
    .reduce(0, (a, b) -> a + b);
// 结果：15

// 3. 有初始值 + 并行累加器
int sum = numbers.parallelStream()
    .reduce(0,
        (a, b) -> a + b,        // 累加器
        Integer::sum);          // 组合器（并行时使用）
// 结果：15
```

```java
// 字符串拼接
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

String result = names.stream()
    .reduce("", (a, b) -> a + b);
// 结果："AliceBobCharlie"

// 带分隔符
String result = names.stream()
    .reduce("", (a, b) -> a.isEmpty() ? b : a + ", " + b);
// 结果："Alice, Bob, Charlie"
```

```java
// 自定义对象归约
List<User> users = Arrays.asList(
    new User("Alice", 20),
    new User("Bob", 25),
    new User("Charlie", 30)
);

// 计算总年龄
int totalAge = users.stream()
    .reduce(0, (sum, user) -> sum + user.getAge(), Integer::sum);
// 结果：75
```

## 查找操作

### findFirst

`findFirst()` 返回 Stream 中的第一个元素。这是一个**短路操作**。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

Optional<Integer> first = numbers.stream()
    .filter(n -> n > 3)
    .findFirst();
// 结果：Optional[4]

// 空 Stream
Optional<Integer> empty = Stream.<Integer>empty().findFirst();
// 结果：Optional.empty
```

### findAny

`findAny()` 返回 Stream 中的任意一个元素。在并行流中，`findAny` 比 `findFirst` 更高效。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// 顺序流：通常返回第一个
Optional<Integer> any = numbers.stream().findAny();
// 结果：Optional[1]（通常是第一个）

// 并行流：可能返回任意一个
Optional<Integer> anyParallel = numbers.parallelStream().findAny();
// 结果：可能是任意一个元素
```

> **提示**：如果只关心是否存在匹配元素，使用 `anyMatch` 比 `findAny` 更高效。

## 匹配操作

### anyMatch

`anyMatch(Predicate)` 判断 Stream 中是否**至少有一个**元素满足条件。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

boolean hasEven = numbers.stream()
    .anyMatch(n -> n % 2 == 0);
// 结果：true（有偶数）

boolean hasNegative = numbers.stream()
    .anyMatch(n -> n < 0);
// 结果：false（没有负数）
```

### allMatch

`allMatch(Predicate)` 判断 Stream 中是否**所有**元素都满足条件。

```java
List<Integer> numbers = Arrays.asList(2, 4, 6, 8);

boolean allEven = numbers.stream()
    .allMatch(n -> n % 2 == 0);
// 结果：true（全是偶数）

boolean allPositive = numbers.stream()
    .allMatch(n -> n > 0);
// 结果：true（全是正数）
```

### noneMatch

`noneMatch(Predicate)` 判断 Stream 中是否**没有**元素满足条件。

```java
List<Integer> numbers = Arrays.asList(1, 3, 5, 7);

boolean noEven = numbers.stream()
    .noneMatch(n -> n % 2 == 0);
// 结果：true（没有偶数）

boolean noNegative = numbers.stream()
    .noneMatch(n -> n < 0);
// 结果：true（没有负数）
```

## 数组操作

### toArray

`toArray()` 将 Stream 元素收集为数组。

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// 转换为 Object[]
Object[] array = names.stream().toArray();

// 转换为指定类型数组
String[] stringArray = names.stream()
    .toArray(String[]::new);

// 带过滤
Integer[] evenArray = Stream.of(1, 2, 3, 4, 5)
    .filter(n -> n % 2 == 0)
    .toArray(Integer[]::new);
// 结果：[2, 4]
```

## Optional 处理

很多终端操作返回 `Optional`，需要正确处理空值情况。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

Optional<Integer> result = numbers.stream()
    .filter(n -> n > 10)
    .findFirst();

// 1. 判断是否存在
if (result.isPresent()) {
    System.out.println(result.get());
}

// 2. 提供默认值
int value = result.orElse(0);

// 3. 提供默认值（延迟计算）
int value = result.orElseGet(() -> getDefault());

// 4. 存在时执行操作
result.ifPresent(System.out::println);

// 5. 存在时执行操作，不存在时执行其他操作
result.ifPresentOrElse(
    System.out::println,
    () -> System.out.println("No value")
);

// 6. 转换为另一个 Optional
Optional<String> str = result.map(n -> "Value: " + n);

// 7. 抛出异常
int value = result.orElseThrow(() -> new RuntimeException("Not found"));
```

## 终端操作速查表

| 操作             | 方法签名                                  | 说明                   |
| ---------------- | ----------------------------------------- | ---------------------- |
| **遍历**         |                                           |                        |
| `forEach`        | `void forEach(Consumer<T>)`               | 遍历每个元素           |
| `forEachOrdered` | `void forEachOrdered(Consumer<T>)`        | 按顺序遍历（并行流用） |
| **收集**         |                                           |                        |
| `collect`        | `<R> R collect(Collector<T,A,R>)`         | 收集到数据结构         |
| `toArray`        | `Object[] toArray()`                      | 收集为数组             |
| **聚合**         |                                           |                        |
| `count`          | `long count()`                            | 计数                   |
| `min`            | `Optional<T> min(Comparator<T>)`          | 最小值                 |
| `max`            | `Optional<T> max(Comparator<T>)`          | 最大值                 |
| `reduce`         | `T reduce(T identity, BinaryOperator<T>)` | 归约                   |
| **查找**         |                                           |                        |
| `findFirst`      | `Optional<T> findFirst()`                 | 第一个元素（短路）     |
| `findAny`        | `Optional<T> findAny()`                   | 任意一个元素           |
| **匹配**         |                                           |                        |
| `anyMatch`       | `boolean anyMatch(Predicate<T>)`          | 任一匹配（短路）       |
| `allMatch`       | `boolean allMatch(Predicate<T>)`          | 全部匹配（短路）       |
| `noneMatch`      | `boolean noneMatch(Predicate<T>)`         | 全不匹配（短路）       |

## 总结

终端操作是 Stream 管道的终点，触发中间操作的执行：

- **遍历类**：`forEach`、`forEachOrdered` 遍历元素
- **收集类**：`collect`（配合 Collectors）收集到各种数据结构，`toArray` 收集为数组
- **聚合类**：`count`、`min`、`max`、`reduce` 计算聚合值
- **查找类**：`findFirst`、`findAny` 查找元素，返回 Optional
- **匹配类**：`anyMatch`、`allMatch`、`noneMatch` 条件匹配，返回 boolean

终端操作的特点：

- **触发执行**：没有终端操作，中间操作不会执行
- **一次性消费**：执行后 Stream 被关闭，不能再次使用
- **返回结果**：返回具体值、Optional 或产生副作用
