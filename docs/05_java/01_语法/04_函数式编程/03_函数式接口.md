# 函数式接口

## 什么是函数式接口

函数式接口（Functional Interface）是 Java 8 引入的核心概念，指**有且仅有一个抽象方法**的接口。函数式接口是 Lambda 表达式的类型基础——每个 Lambda 表达式在编译时都会被自动转换为某个函数式接口的实例。

```java
// 标准函数式接口：只有一个抽象方法
@FunctionalInterface
public interface Runnable {
    void run();
}

// 也是函数式接口：一个抽象方法 + 默认方法不算在内
@FunctionalInterface
public interface Comparator<T> {
    int compare(T o1, T o2);  // 唯一的抽象方法

    boolean equals(Object obj); // 这是 Object 类的方法，不算抽象方法
}
```

> **注意**：接口中的 `default` 方法和 `static` 方法有具体实现，不计入抽象方法数量，因此不影响接口成为函数式接口。

## @FunctionalInterface 注解

`@FunctionalInterface` 是专门用于标记函数式接口的注解。它的作用类似于 `@Override`：

- **不是强制的**：不加也能编译通过，只要接口满足函数式接口条件即可
- **推荐加上**：编译器会检查接口是否满足函数式接口条件，不满足时报错

```java
// 正确：一个抽象方法
@FunctionalInterface
public interface MyInterface {
    void doSomething();
}

// 编译错误：两个抽象方法，不是函数式接口
@FunctionalInterface
public interface BadInterface {
    void methodA();
    void methodB(); // 编译器报错：Multiple non-overriding abstract methods found
}
```

## 自定义函数式接口

虽然 Java 提供了丰富的内置函数式接口，但在某些场景下自定义函数式接口能让代码语义更清晰。

```java
// 自定义：表示一个数学上的"变换"操作
@FunctionalInterface
public interface Transformer<T> {
    T transform(T input);
}

// 使用
Transformer<String> upper = s -> s.toUpperCase();
String result = upper.transform("hello"); // "HELLO"
```

```java
// 自定义：表示带两个参数的计算规则
@FunctionalInterface
public interface Calculator<T> {
    T calculate(T a, T b);
}

// 使用
Calculator<Integer> add = (a, b) -> a + b;
Calculator<Integer> multiply = (a, b) -> a * b;
System.out.println(add.calculate(3, 5));     // 8
System.out.println(multiply.calculate(3, 5)); // 15
```

### 自定义函数式接口可以包含的内容

函数式接口除了唯一的抽象方法外，还可以包含：

```java
@FunctionalInterface
public interface AdvancedProcessor<T> {
    // 1. 唯一的抽象方法
    T process(T input);

    // 2. 默认方法（有实现，不计入抽象方法）
    default void log(T input) {
        System.out.println("Processing: " + input);
    }

    // 3. 静态方法
    static <T> AdvancedProcessor<T> identity() {
        return input -> input;
    }

    // 4. Object 类的公共方法（equals、hashCode、toString 等）
    // 这些方法即使没有显式声明，也被认为存在，不计入抽象方法
}
```

## Java 内置核心函数式接口

Java 在 `java.util.function` 包中提供了 43 个内置函数式接口。以下按功能分类介绍最常用的接口。

### 四大核心接口

这四个接口覆盖了最常见的函数式编程场景：

#### Predicate\<T\> — 断言

接受一个参数，返回 `boolean` 结果。用于条件判断和过滤。

```java
@FunctionalInterface
public interface Predicate<T> {
    boolean test(T t);
}
```

```java
// 基本使用
Predicate<Integer> isPositive = n -> n > 0;
System.out.println(isPositive.test(5));   // true
System.out.println(isPositive.test(-3));  // false

// 在 Stream 中使用
List<Integer> numbers = Arrays.asList(1, -2, 3, -4, 5);
List<Integer> positives = numbers.stream()
    .filter(n -> n > 0)
    .collect(Collectors.toList()); // [1, 3, 5]

// 组合：and
Predicate<Integer> isEven = n -> n % 2 == 0;
Predicate<Integer> isPositiveEven = isPositive.and(isEven);
System.out.println(isPositiveEven.test(4));  // true
System.out.println(isPositiveEven.test(-4)); // false

// 组合：or
Predicate<String> isShort = s -> s.length() < 5;
Predicate<String> startsWithA = s -> s.startsWith("A");
Predicate<String> matchEither = isShort.or(startsWithA);
System.out.println(matchEither.test("Hi"));       // true（短）
System.out.println(matchEither.test("Alexander")); // true（A 开头）

// 组合：negate（取反）
Predicate<Integer> isNotPositive = isPositive.negate();
System.out.println(isNotPositive.test(-3)); // true
```

#### Function\<T, R\> — 转换

接受一个参数 `T`，返回结果 `R`。用于数据转换和映射。

```java
@FunctionalInterface
public interface Function<T, R> {
    R apply(T t);
}
```

```java
// 基本使用
Function<String, Integer> length = s -> s.length();
System.out.println(length.apply("hello")); // 5

// 字符串转大写
Function<String, String> toUpper = s -> s.toUpperCase();
System.out.println(toUpper.apply("hello")); // "HELLO"

// 组合：andThen（先执行当前，再执行参数）
Function<String, String> trim = s -> s.trim();
Function<String, String> trimThenUpper = trim.andThen(toUpper);
System.out.println(trimThenUpper.apply("  hello  ")); // "HELLO"

// 组合：compose（先执行参数，再执行当前）
Function<String, String> compose = toUpper.compose(trim);
System.out.println(compose.apply("  hello  ")); // "HELLO"

// 恒等函数：输入什么返回什么
Function<String, String> identity = Function.identity();
System.out.println(identity.apply("hello")); // "hello"
```

#### Consumer\<T\> — 消费

接受一个参数，无返回值。用于执行副作用操作（如打印、存储等）。

```java
@FunctionalInterface
public interface Consumer<T> {
    void accept(T t);
}
```

```java
// 基本使用
Consumer<String> printer = s -> System.out.println(">> " + s);
printer.accept("hello"); // >> hello

// 在集合中使用
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(name -> System.out.println(name));

// 组合：andThen（依次执行两个消费操作）
Consumer<String> logFirst = s -> System.out.println("[LOG] " + s);
Consumer<String> logSecond = s -> System.out.println("[AUDIT] " + s);
Consumer<String> logAll = logFirst.andThen(logSecond);
logAll.accept("action");
// 输出：
// [LOG] action
// [AUDIT] action
```

#### Supplier\<T\> — 供应

不接受参数，返回一个结果。用于延迟创建对象、生成数据等。

```java
@FunctionalInterface
public interface Supplier<T> {
    T get();
}
```

```java
// 基本使用
Supplier<String> greeting = () -> "Hello, World!";
System.out.println(greeting.get()); // Hello, World!

// 延迟创建对象
Supplier<List<String>> listFactory = ArrayList::new;
List<String> list = listFactory.get();

// 工厂模式
Supplier<User> userFactory = () -> new User("default");

// 在 Optional 中使用
Optional<String> opt = Optional.empty();
String result = opt.orElseGet(() -> "default value");
```

### 双参数变体

当需要处理两个参数时，使用 `Bi` 前缀的变体接口：

| 接口                  | 方法签名                 | 说明       |
| --------------------- | ------------------------ | ---------- |
| `BiPredicate<T, U>`   | `boolean test(T t, U u)` | 双参数断言 |
| `BiFunction<T, U, R>` | `R apply(T t, U u)`      | 双参数转换 |
| `BiConsumer<T, U>`    | `void accept(T t, U u)`  | 双参数消费 |

```java
// BiPredicate：检查键值对是否满足条件
BiPredicate<String, Integer> isValidEntry = (key, value) ->
    key != null && !key.isEmpty() && value > 0;
System.out.println(isValidEntry.test("age", 25)); // true

// BiFunction：合并两个值
BiFunction<String, String, String> concat = (a, b) -> a + " " + b;
System.out.println(concat.apply("Hello", "World")); // "Hello World"

// BiConsumer：Map 遍历
Map<String, Integer> scores = Map.of("Alice", 90, "Bob", 85);
scores.forEach((name, score) ->
    System.out.println(name + ": " + score));
```

### 运算符接口

输入和输出类型相同的特殊变体：

| 接口                | 方法签名              | 说明                       |
| ------------------- | --------------------- | -------------------------- |
| `UnaryOperator<T>`  | `T apply(T t)`        | 一元运算符，输入输出同类型 |
| `BinaryOperator<T>` | `T apply(T t1, T t2)` | 二元运算符，输入输出同类型 |

```java
// UnaryOperator：字符串处理链
UnaryOperator<String> trim = s -> s.trim();
UnaryOperator<String> toLower = s -> s.toLowerCase();
UnaryOperator<String> pipeline = trim.andThen(toLower);
System.out.println(pipeline.apply("  HELLO  ")); // "hello"

// BinaryOperator：归约操作
BinaryOperator<Integer> max = BinaryOperator.maxBy(Integer::compareTo);
System.out.println(max.apply(3, 7)); // 7

BinaryOperator<Integer> add = (a, b) -> a + b;
int sum = Stream.of(1, 2, 3, 4, 5).reduce(0, add); // 15
```

### 基本类型特化接口

为了避免自动装箱/拆箱带来的性能开销，Java 为 `int`、`long`、`double` 提供了特化版本的函数式接口：

| 接口                   | 等价泛型形式              | 说明                    |
| ---------------------- | ------------------------- | ----------------------- |
| `IntFunction<R>`       | `Function<Integer, R>`    | int 参数，避免装箱      |
| `LongFunction<R>`      | `Function<Long, R>`       | long 参数，避免装箱     |
| `DoubleFunction<R>`    | `Function<Double, R>`     | double 参数，避免装箱   |
| `IntConsumer`          | `Consumer<Integer>`       | 消费 int，避免装箱      |
| `LongConsumer`         | `Consumer<Long>`          | 消费 long，避免装箱     |
| `DoubleConsumer`       | `Consumer<Double>`        | 消费 double，避免装箱   |
| `IntSupplier`          | `Supplier<Integer>`       | 供应 int，避免拆箱      |
| `LongSupplier`         | `Supplier<Long>`          | 供应 long，避免拆箱     |
| `DoubleSupplier`       | `Supplier<Double>`        | 供应 double，避免拆箱   |
| `IntPredicate`         | `Predicate<Integer>`      | 断言 int，避免装箱      |
| `LongPredicate`        | `Predicate<Long>`         | 断言 long，避免装箱     |
| `DoublePredicate`      | `Predicate<Double>`       | 断言 double，避免装箱   |
| `IntUnaryOperator`     | `UnaryOperator<Integer>`  | int 一元运算，无装箱    |
| `LongUnaryOperator`    | `UnaryOperator<Long>`     | long 一元运算，无装箱   |
| `DoubleUnaryOperator`  | `UnaryOperator<Double>`   | double 一元运算，无装箱 |
| `IntBinaryOperator`    | `BinaryOperator<Integer>` | int 二元运算，无装箱    |
| `LongBinaryOperator`   | `BinaryOperator<Long>`    | long 二元运算，无装箱   |
| `DoubleBinaryOperator` | `BinaryOperator<Double>`  | double 二元运算，无装箱 |
| `IntToLongFunction`    | —                         | int → long 转换         |
| `IntToDoubleFunction`  | —                         | int → double 转换       |
| `LongToIntFunction`    | —                         | long → int 转换         |
| `LongToDoubleFunction` | —                         | long → double 转换      |
| `DoubleToIntFunction`  | —                         | double → int 转换       |
| `DoubleToLongFunction` | —                         | double → long 转换      |

```java
// 不推荐：使用 Function<Integer, Integer>，每次调用涉及自动装箱
Function<Integer, Integer> square = x -> x * x;

// 推荐：使用 IntUnaryOperator，无装箱开销
IntUnaryOperator square = x -> x * x;
System.out.println(square.applyAsInt(5)); // 25

// IntStream 中使用特化接口
IntStream.rangeClosed(1, 100)
    .map(x -> x * x)          // IntUnaryOperator
    .filter(x -> x > 50)      // IntPredicate
    .forEach(System.out::println); // IntConsumer
```

## 接口的组合方法

内置函数式接口提供了丰富的默认方法用于组合，这是构建复杂逻辑的关键。

### Predicate 的组合方法

| 方法                                                   | 说明   |
| ------------------------------------------------------ | ------ |
| `default Predicate<T> and(Predicate<? super T> other)` | 逻辑与 |
| `default Predicate<T> or(Predicate<? super T> other)`  | 逻辑或 |
| `default Predicate<T> negate()`                        | 逻辑非 |

```java
Predicate<Integer> gt10 = x -> x > 10;
Predicate<Integer> lt20 = x -> x < 20;

// and：同时满足
Predicate<Integer> between = gt10.and(lt20);
System.out.println(between.test(15)); // true
System.out.println(between.test(25)); // false

// or：满足其一
Predicate<Integer> outside = gt10.or(lt20);
System.out.println(outside.test(5));  // true（< 20）

// negate：取反
Predicate<Integer> le10 = gt10.negate();
System.out.println(le10.test(10)); // true
```

### Function 的组合方法

| 方法                                                                        | 说明                      |
| --------------------------------------------------------------------------- | ------------------------- |
| `default <V> Function<T,V> andThen(Function<? super R,? extends V> after)`  | 先执行当前，再执行 after  |
| `default <V> Function<V,R> compose(Function<? super V,? extends T> before)` | 先执行 before，再执行当前 |

```java
Function<Integer, Integer> doubleIt = x -> x * 2;
Function<Integer, Integer> addThree = x -> x + 3;

// andThen：先 double，再 +3
Function<Integer, Integer> doubleThenAdd = doubleIt.andThen(addThree);
System.out.println(doubleThenAdd.apply(5)); // (5*2)+3 = 13

// compose：先 +3，再 double
Function<Integer, Integer> addThenDouble = doubleIt.compose(addThree);
System.out.println(addThenDouble.apply(5)); // (5+3)*2 = 16
```

### Consumer 的组合方法

| 方法                                                     | 说明                     |
| -------------------------------------------------------- | ------------------------ |
| `default Consumer<T> andThen(Consumer<? super T> after)` | 先执行当前，再执行 after |

```java
Consumer<String> printUpper = s -> System.out.println(s.toUpperCase());
Consumer<String> printLength = s -> System.out.println("Length: " + s.length());

Consumer<String> pipeline = printUpper.andThen(printLength);
pipeline.accept("hello");
// 输出：
// HELLO
// Length: 5
```

## 完整接口速查表

以下是 `java.util.function` 包中最常用的函数式接口汇总：

| 接口                  | 抽象方法                  | 用途                 |
| --------------------- | ------------------------- | -------------------- |
| **判定类**            |                           |                      |
| `Predicate<T>`        | `boolean test(T t)`       | 单参数条件判断       |
| `BiPredicate<T, U>`   | `boolean test(T t, U u)`  | 双参数条件判断       |

| `UnaryOperator<T>`    | `T apply(T t)`            | 同类型一元变换       |
| `BinaryOperator<T>`   | `T apply(T t1, T t2)`     | 同类型二元运算       |
| **消费类**            |                           |                      |
| `Consumer<T>`         | `void accept(T t)`        | 单参数消费（无返回） |
| `BiConsumer<T, U>`    | `void accept(T t, U u)`   | 双参数消费           |
| **供应类**            |                           |                      |
| `Supplier<T>`         | `T get()`                 | 无参供应             |
| **无参无返回**        |                           |                      |
| `Runnable`            | `void run()`              | 无参无返回           |
| **比较类**            |                           |                      |
| `Comparator<T>`       | `int compare(T o1, T o2)` | 对象比较             |

## 使用场景与最佳实践

### 1. 选择合适的内置接口

优先使用 `java.util.function` 中的内置接口，避免重复造轮子：

```java
// 不推荐：自定义功能相同的接口
@FunctionalInterface
interface StringProcessor {
    String process(String s);
}

// 推荐：直接使用 Function<String, String> 或 UnaryOperator<String>
UnaryOperator<String> processor = s -> s.trim().toLowerCase();
```

### 2. 基本类型优先使用特化接口

在性能敏感的场景中，使用 `IntFunction`、`IntPredicate` 等特化接口避免装箱开销：

```java
// 不推荐：自动装箱
Function<Integer, Integer> doubler = x -> x * 2;

// 推荐：无装箱
IntUnaryOperator doubler = x -> x * 2;
```

### 3. 利用组合方法构建管道

使用 `andThen`、`compose`、`and`、`or` 等方法组合简单逻辑为复杂逻辑：

```java
// 构建数据处理管道
Function<String, String> clean = String::trim;
Function<String, String> normalize = String::toLowerCase;
Function<String, String> validate = s -> {
    if (s.isEmpty()) throw new IllegalArgumentException("empty input");
    return s;
};

Function<String, String> pipeline = clean.andThen(normalize).andThen(validate);
```

### 4. 函数式接口作为方法参数

将函数式接口作为方法参数，使方法行为可配置：

```java
// 通用转换方法
public static <T, R> List<R> transform(List<T> list, Function<T, R> mapper) {
    List<R> result = new ArrayList<>();
    for (T item : list) {
        result.add(mapper.apply(item));
    }
    return result;
}

// 不同的转换策略
List<String> names = Arrays.asList("Alice", "Bob");
List<Integer> lengths = transform(names, String::length);
List<String> uppers = transform(names, String::toUpperCase);
```

## 总结

函数式接口是 Java 函数式编程的基石：

- **定义**：有且仅有一个抽象方法的接口，用 `@FunctionalInterface` 标记
- **内置接口**：`java.util.function` 包提供 43 个接口，核心为 Predicate、Function、Consumer、Supplier
- **双参数变体**：BiPredicate、BiFunction、BiConsumer 处理双参数场景
- **特化接口**：Int/Long/Double 前缀的接口避免自动装箱开销
- **组合能力**：andThen、compose、and、or、negate 等默认方法支持逻辑组合
- **最佳实践**：优先使用内置接口，基本类型场景使用特化接口
