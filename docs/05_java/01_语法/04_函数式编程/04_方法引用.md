# 方法引用

## 什么是方法引用

方法引用（Method Reference）是 Java 8 引入的语法特性，用于**直接引用已有方法**，是 Lambda 表达式的一种**简化写法**（语法糖）。当 Lambda 方法体仅仅是调用一个已存在的方法时，就可以用方法引用来替代，使代码更加简洁和可读。

方法引用使用 `::` 双冒号操作符，语法格式为 `目标引用::方法名称`。

```java
// Lambda 写法
Consumer<String> printer = s -> System.out.println(s);

// 方法引用写法（等价，更简洁）
Consumer<String> printer = System.out::println;
```

> **核心原则**：方法引用能简化代码的前提是——Lambda 方法体**只有一行方法调用**，且不涉及额外的逻辑。

## 四种方法引用形式

Java 支持四种不同类型的方法引用，根据目标对象和方法类型的不同进行区分：

| 类型                           | 语法                      | 等价的 Lambda                            |
| ------------------------------ | ------------------------- | ---------------------------------------- |
| 引用静态方法                   | `ClassName::staticMethod` | `(args) -> ClassName.staticMethod(args)` |
| 引用某个对象的实例方法         | `instanceRef::method`     | `(args) -> instanceRef.method(args)`     |
| 引用某个类的任意对象的实例方法 | `ClassName::method`       | `(obj, args) -> obj.method(args)`        |
| 引用构造方法                   | `ClassName::new`          | `(args) -> new ClassName(args)`          |

---

### 1. 引用静态方法

引用某个类的静态方法。语法为 `类名::静态方法名`。

Lambda 的参数直接传递给静态方法。

```java
// Lambda
Function<String, Integer> parser = s -> Integer.parseInt(s);

// 方法引用（引用 Integer 的静态方法 parseInt）
Function<String, Integer> parser = Integer::parseInt;

System.out.println(parser.apply("123")); // 123
```

```java
// Lambda
Function<Integer, String> toString = n -> String.valueOf(n);

// 方法引用
Function<Integer, String> toString = String::valueOf;

System.out.println(toString.apply(42)); // "42"
```

```java
// Lambda
BiFunction<Double, Double, Double> power = (a, b) -> Math.pow(a, b);

// 方法引用
BiFunction<Double, Double, Double> power = Math::pow;

System.out.println(power.apply(2.0, 3.0)); // 8.0
```

### 2. 引用某个对象的实例方法

引用**特定对象**的实例方法。语法为 `对象引用::方法名`。

Lambda 的参数传递给该对象的实例方法。

```java
String greeting = "Hello, World!";

// Lambda
Supplier<String> upper = () -> greeting.toUpperCase();

// 方法引用（引用 greeting 对象的 toUpperCase 方法）
Supplier<String> upper = greeting::toUpperCase;

System.out.println(upper.get()); // "HELLO, WORLD!"
```

```java
PrintStream out = System.out;

// Lambda
Consumer<String> printer = s -> out.println(s);

// 方法引用（引用 out 对象的 println 方法）
Consumer<String> printer = out::println;

printer.accept("hello"); // hello
```

```java
List<String> list = new ArrayList<>(Arrays.asList("Banana", "Apple", "Cherry"));

// Lambda
Comparator<String> comp = (a, b) -> list.indexOf(a) - list.indexOf(b);

// 方法引用不适用此场景（indexOf 的参数不是 Lambda 的直接参数）
// 需要保持 Lambda 写法
```

### 3. 引用某个类的任意对象的实例方法

引用**某个类型**的实例方法，但具体调用哪个对象的方法由 Lambda 的**第一个参数**决定。语法为 `类名::方法名`。

这是最容易混淆的一种形式——Lambda 的**第一个参数成为方法的调用者**，其余参数成为方法的参数。

```java
// Lambda
Function<String, String> upper = s -> s.toUpperCase();

// 方法引用（第一个参数 s 是 String 类型的调用者）
Function<String, String> upper = String::toUpperCase;

System.out.println(upper.apply("hello")); // "HELLO"
```

```java
// Lambda
BiFunction<String, String, Boolean> starts = (str, prefix) -> str.startsWith(prefix);

// 方法引用（第一个参数 str 是调用者，第二个参数 prefix 是方法参数）
BiFunction<String, String, Boolean> starts = String::startsWith;

System.out.println(starts.apply("hello", "he")); // true
```

```java
// Lambda：排序
List<String> names = Arrays.asList("Charlie", "Alice", "Bob");
names.sort((a, b) -> a.compareTo(b));

// 方法引用
names.sort(String::compareTo);

System.out.println(names); // [Alice, Bob, Charlie]
```

### 4. 引用构造方法

引用某个类的构造方法来创建新对象。语法为 `类名::new`。

Lambda 的参数传递给构造方法的参数列表，编译器会根据目标函数式接口的参数签名自动选择匹配的构造方法。

```java
// Lambda
Supplier<List<String>> listFactory = () -> new ArrayList<>();

// 方法引用（引用 ArrayList 的无参构造方法）
Supplier<List<String>> listFactory = ArrayList::new;

List<String> list = listFactory.get();
```

```java
// Lambda
Function<String, StringBuilder> builder = s -> new StringBuilder(s);

// 方法引用（引用 StringBuilder 的 String 参数构造方法）
Function<String, StringBuilder> builder = StringBuilder::new;

StringBuilder sb = builder.apply("hello");
```

```java
// Lambda
BiFunction<Integer, Integer, int[]> arrayCreator = (rows, cols) -> new int[rows][cols];

// 方法引用
BiFunction<Integer, Integer, int[][]> arrayCreator = int[][]::new;

int[][] matrix = arrayCreator.apply(3, 4);
```

```java
// 在 Stream 中使用：将字符串列表转换为 User 对象列表
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
List<User> users = names.stream()
    .map(User::new) // 等价于 name -> new User(name)
    .collect(Collectors.toList());
```

### 5. 引用数组创建（特殊形式）

数组创建可以看作构造方法引用的一种特殊形式：

```java
// Lambda
Function<Integer, String[]> arrayFactory = size -> new String[size];

// 方法引用
Function<Integer, String[]> arrayFactory = String[]::new;

String[] arr = arrayFactory.apply(5); // 创建长度为 5 的 String 数组
```

## 方法引用的类型匹配

编译器通过**目标类型**（函数式接口的抽象方法签名）来推断方法引用对应哪个方法。匹配规则如下：

### 静态方法引用匹配

```java
// Integer.parseInt(String) -> int
// 匹配 Function<String, Integer>（apply 接受 String，返回 Integer）
Function<String, Integer> f = Integer::parseInt;
```

### 实例方法引用匹配

```java
// 对象引用方式：
// "hello".toUpperCase() -> String
// 匹配 Supplier<String>（get 无参数，返回 String）
Supplier<String> s = "hello"::toUpperCase;

// 类引用方式：
// String.toUpperCase(String this) -> String
// 匹配 Function<String, String>（apply 的第一个参数是调用者）
Function<String, String> f = String::toUpperCase;
```

### 构造方法引用匹配

```java
// ArrayList() 无参构造 -> 匹配 Supplier<List<String>>
Supplier<List<String>> s = ArrayList::new;

// ArrayList(Collection) 有参构造 -> 匹配 Function<Collection, List<String>>
Function<Collection<String>, List<String>> f = ArrayList::new;
```

## 使用场景

### 1. Stream 操作中的方法引用

方法引用在 Stream API 中使用最为广泛，使数据处理管道更加清晰：

```java
List<String> names = Arrays.asList("alice", "bob", "charlie");

// map：转换
List<String> uppers = names.stream()
    .map(String::toUpperCase)       // s -> s.toUpperCase()
    .collect(Collectors.toList());

// filter：过滤
List<String> longNames = names.stream()
    .filter(s -> s.length() > 3)    // 无法简化为方法引用（有比较逻辑）
    .collect(Collectors.toList());

// forEach：遍历
names.stream()
    .forEach(System.out::println);  // s -> System.out.println(s)
```

```java
// 排序
List<String> names = Arrays.asList("Charlie", "Alice", "Bob");

names.sort(String::compareToIgnoreCase); // (a, b) -> a.compareToIgnoreCase(b)

// 按长度排序
names.sort(Comparator.comparingInt(String::length));
```

### 2. 对象创建与工厂模式

```java
// 工厂方法
class UserFactory {
    public static User create(String name) {
        return new User(name);
    }
}

// Lambda
Function<String, User> f1 = name -> UserFactory.create(name);

// 方法引用
Function<String, User> f2 = UserFactory::create;
```

### 3. 集合操作

```java
// 集合转换
List<String> words = Arrays.asList("hello", "world");

// toUpperCase 转换
List<String> result = words.stream()
    .map(String::toUpperCase)
    .collect(Collectors.toList());

// 求长度
List<Integer> lengths = words.stream()
    .map(String::length)
    .collect(Collectors.toList());
```

### 4. Optional 中的方法引用

```java
Optional<String> opt = Optional.of("hello");

// Lambda
String result = opt.map(s -> s.toUpperCase()).orElse("default");

// 方法引用
String result = opt.map(String::toUpperCase).orElse("default");
```

## 方法引用的限制

### 1. 不能处理异常

方法引用调用的方法如果抛出受检异常（checked exception），需要在函数式接口层面处理。方法引用本身不提供额外的异常处理机制。

```java
// 如果 parse 方法抛出 ParseException，需要包装
// 方法引用不能直接处理异常
Function<String, Date> parser = s -> {
    try {
        return new SimpleDateFormat("yyyy-MM-dd").parse(s);
    } catch (ParseException e) {
        throw new RuntimeException(e);
    }
};
// 此处无法使用 SimpleDateFormat::parse 方法引用
```

### 2. 无法传递额外参数

方法引用只能传递函数式接口定义好的参数，不能在调用时添加额外参数。

```java
// 不能使用方法引用：因为 indexOf 需要额外参数 "a"
// 必须使用 Lambda
BiFunction<String, String, Integer> finder = (str, a) -> str.indexOf(a);
```

### 3. 方法重载时的歧义

当目标类有多个同名方法（重载），编译器可能无法推断应该引用哪一个，此时需要显式指定类型或使用 Lambda。

```java
class Example {
    static void print(String s) { ... }
    static void print(Integer i) { ... }
}

// 可能产生歧义，需要明确目标类型
Consumer<String> c1 = Example::print;   // 推断为 print(String)
Consumer<Integer> c2 = Example::print;  // 推断为 print(Integer)
```

### 4. 不能用于字段访问

方法引用只能引用方法，不能引用字段。需要访问字段时使用 Lambda。

```java
// 错误：不能引用字段
// Function<User, String> getName = User::name;

// 正确：使用 Lambda 或 getter 方法
Function<User, String> getName = user -> user.getName();
// 或者如果有 getName 方法
Function<User, String> getName = User::getName;
```

## 方法引用 vs Lambda 表达式

| 对比维度 | 方法引用                   | Lambda 表达式              |
| -------- | -------------------------- | -------------------------- |
| 语法     | `ClassName::methodName`    | `(params) -> expression`   |
| 简洁性   | 更简洁（仅调用已有方法时） | 更灵活（可包含任意逻辑）   |
| 可读性   | 语义明确，一目了然         | 逻辑复杂时可读性下降       |
| 灵活性   | 只能调用已有方法           | 可以包含任意代码逻辑       |
| 参数处理 | 受限于已有方法签名         | 可自由定义参数             |
| 异常处理 | 不便于额外异常处理         | 可在方法体内 try-catch     |
| 适用场景 | 方法体只有一行方法调用     | 方法体有多行逻辑或条件判断 |

### 何时使用方法引用

- Lambda 方法体**只有一行方法调用**
- 调用的方法名能**清晰表达意图**
- 不需要额外的参数或异常处理

### 何时使用 Lambda

- 方法体包含**多行逻辑**
- 需要**条件判断**或**异常处理**
- 方法引用会导致**可读性下降**（如嵌套方法调用）

```java
// 推荐方法引用：简洁清晰
names.forEach(System.out::println);

// 推荐 Lambda：逻辑复杂，方法引用反而不清晰
names.forEach(name -> log.info("Processing: {}", name));

// 推荐方法引用
Function<String, Integer> parse = Integer::parseInt;

// 推荐 Lambda：需要额外处理
Function<String, Integer> parse = s -> {
    try {
        return Integer.parseInt(s);
    } catch (NumberFormatException e) {
        return 0;
    }
};
```

## 总结

方法引用是 Lambda 表达式的语法糖，使代码更加简洁：

- **四种形式**：静态方法引用、对象实例方法引用、类实例方法引用、构造方法引用
- **语法**：使用 `::` 双冒号操作符分隔目标和方法名
- **匹配规则**：编译器根据目标函数式接口的方法签名自动推断
- **最佳场景**：Stream 操作、集合转换、对象工厂
- **限制**：不能处理额外异常、不能传递额外参数、重载时可能歧义
- **选择原则**：方法体只有一行方法调用时用方法引用，否则用 Lambda
