# 函数式编程介绍

## 什么是函数式编程

函数式编程（Functional Programming）是一种**声明式编程范式**，它将计算视为数学函数的求值过程，强调通过表达式和函数的组合来描述程序逻辑，而非通过显式的状态变更和控制流语句。

函数式编程的核心思想是：**程序是由一系列函数调用组成的，数据在这些函数之间流动和变换**。

## 函数式编程的核心特征

### 纯函数（Pure Function）

纯函数是函数式编程的基石，满足以下两个条件：

1. **相同输入始终产生相同输出**：函数的返回值仅取决于输入参数，不依赖任何外部状态。
2. **无副作用（No Side Effects）**：函数执行过程中不会修改外部状态（如全局变量、I/O 操作等）。

```java
// 纯函数示例
public static int add(int a, int b) {
    return a + b; // 相同输入永远返回相同结果，不修改任何外部状态
}

// 非纯函数示例
public static int addWithGlobal(int a) {
    return a + globalValue; // 依赖外部状态，相同输入可能返回不同结果
}
```

### 不可变数据（Immutable Data）

函数式编程倾向于使用不可变数据结构——一旦创建就不能被修改。需要修改数据时，创建一个新的副本而非就地更改。

```java
// Java 中的不可变对象示例
String original = "hello";
String modified = original.toUpperCase(); // 原字符串不变，返回新字符串
```

### 函数作为一等公民（First-Class Function）

在函数式编程中，函数是一等公民，可以：

- 赋值给变量
- 作为参数传递给其他函数
- 作为其他函数的返回值
- 存储在数据结构中

```java
// Java 8+ 中函数作为一等公民的体现
Function<String, Integer> lengthFunc = String::length;  // 赋值给变量
int result = lengthFunc.apply("hello");                  // 调用

// 作为参数传递
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(name -> System.out.println(name));         // Lambda 作为参数
```

### 高阶函数（Higher-Order Function）

高阶函数是指**接受函数作为参数或返回函数作为结果**的函数。

```java
// 接受函数作为参数
public static <T> List<T> filter(List<T> list, Predicate<T> predicate) {
    return list.stream().filter(predicate).collect(Collectors.toList());
}

// 返回函数
public static Function<Integer, Integer> multiplier(int factor) {
    return x -> x * factor;
}
```

## 函数式编程 vs 命令式编程

| 对比维度 | 命令式编程                 | 函数式编程               |
| -------- | -------------------------- | ------------------------ |
| 关注点   | 如何执行（How）            | 做什么（What）           |
| 状态管理 | 可变状态，通过赋值修改变量 | 不可变状态，避免修改     |
| 控制流   | 循环、条件语句             | 函数调用、递归、高阶函数 |
| 副作用   | 常见且普遍                 | 尽量避免，追求纯函数     |
| 代码风格 | 描述执行步骤               | 描述数据变换关系         |

```java
// 命令式风格：使用 for 循环
List<Integer> doubled = new ArrayList<>();
for (int n : numbers) {
    doubled.add(n * 2);
}

// 函数式风格：使用 Stream API
List<Integer> doubled = numbers.stream()
    .map(n -> n * 2)
    .collect(Collectors.toList());
```

## Java 中的函数式编程支持

Java 从 **Java 8** 开始引入了大量函数式编程特性：

| 特性          | 说明                                                                       |
| ------------- | -------------------------------------------------------------------------- |
| Lambda 表达式 | 匿名函数的简洁语法，如 `(a, b) -> a + b`                                   |
| 方法引用      | 使用 `::` 语法直接引用已有方法，如 `String::toUpperCase`                   |
| Stream API    | 支持函数式风格的数据集合操作（map、filter、reduce 等）                     |
| 函数式接口    | 只有一个抽象方法的接口，如 `Function`、`Predicate`、`Consumer`、`Supplier` |
| Optional      | 用于优雅处理 `null` 值，避免空指针异常                                     |
| 默认方法      | 接口中可以定义带实现的方法（`default` 关键字）                             |
