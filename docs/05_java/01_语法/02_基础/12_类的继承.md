# 类的继承

继承是面向对象的三大特征之一，通过 `extends` 关键字让子类复用父类的字段和方法，实现代码复用和层次化设计。

## 基本语法

```java
[修饰符] class 子类名 extends 父类名 {
    // 子类特有的字段和方法
}
```

```java
public class Animal {
    String name;
    int age;

    public void eat() {
        System.out.println(name + "在吃东西");
    }
}

public class Dog extends Animal {
    public void bark() {
        System.out.println(name + "在汪汪叫");
    }
}
```

```java
Dog dog = new Dog();
dog.name = "旺财";   // 继承自父类的字段
dog.eat();           // 继承自父类的方法
dog.bark();          // 子类自己的方法
```

## 单继承

Java 只支持**单继承**，一个类只能继承一个父类：

```java
// ❌ 错误：不能同时继承多个类
public class Dog extends Animal, Pet { }

// ✅ 正确：只能继承一个类
public class Dog extends Animal { }
```

> **多层继承**是允许的：`A` 继承 `B`，`B` 继承 `C`，此时 `A` 间接拥有 `B` 和 `C` 的成员。

## 继承成员访问规则

1. 父类 `public / protected` 的字段、方法：子类可以继承使用
2. 父类 **default (包私有)**：只有同包子类可用；**不同包的子类不能继承访问**
3. 父类 `private`：**子类完全继承不到，看不见**。想要使用只能通过父类 public/protected 方法。

## super 关键字

`super` 用于引用父类的成员：

### 访问父类字段

```java
public class Animal {
    String name = "动物";
}

public class Dog extends Animal {
    String name = "狗";

    public void printNames() {
        System.out.println(name);        // 狗（子类字段）
        System.out.println(super.name);  // 动物（父类字段）
    }
}
```

### 调用父类方法

```java
public class Animal {
    public void eat() {
        System.out.println("动物在吃东西");
    }
}

public class Dog extends Animal {
    @Override
    public void eat() {
        super.eat();  // 调用父类的 eat 方法
        System.out.println("狗在啃骨头");
    }
}
```

```java
Dog dog = new Dog();
dog.eat();
// 输出：
// 动物在吃东西
// 狗在啃骨头
```

### 调用父类构造方法

`super(...)` 必须在子类构造方法的**第一行**调用：

```java
public class Animal {
    String name;

    public Animal(String name) {
        this.name = name;
    }
}

public class Dog extends Animal {
    String breed;

    public Dog(String name, String breed) {
        super(name);        // 调用父类构造方法，必须第一行
        this.breed = breed;
    }
}
```

> **注意**：如果子类构造方法中没有显式调用 `super(...)`，编译器会自动插入 `super()` 调用父类无参构造方法。如果父类没有无参构造方法，则必须显式调用。

## 构造方法和继承

1. 构造方法**不能被继承**。子类不会拥有父类的构造方法。
2. 创建子类对象时，会先调用父类构造方法，再执行子类构造方法

```java
public class Animal {
    public Animal() {
        System.out.println("父类构造方法");
    }
}

public class Dog extends Animal {
    public Dog() {
        System.out.println("子类构造方法");
    }
}

new Dog();
// 输出：
// 父类构造方法
// 子类构造方法
```

## 方法重写（Override）

子类可以重写父类的方法，提供自己的实现：

```java
public class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("汪汪汪");
    }
}

public class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("喵喵喵");
    }
}
```

```java
Animal dog = new Dog();
Animal cat = new Cat();
dog.makeSound();  // 汪汪汪
// cat.makeSound();  // 喵喵喵
```

### 重写规则

- 方法名、参数列表必须与父类方法**完全相同**
- 返回类型可以相同或是父类返回类型的**子类型**
- 访问修饰符**不能比父类更严格**（`protected` → `private` ❌）
- 抛出的异常**不能比父类更宽泛**

### @Override 注解

`@Override` 是可选但推荐的注解，编译器会检查是否真正重写了父类方法：

```java
@Override
public void makeSound() { ... }  // 如果没有真正重写，编译器会报错
```

## final 与继承

### final 类

`final` 修饰的类**不能被继承**：

```java
public final class String { ... }  // String 是 final 类，无法继承
```

### final 方法

`final` 修饰的方法**不能被子类重写**：

```java
public class Animal {
    public final void eat() {
        System.out.println("动物在吃东西");
    }
}

public class Dog extends Animal {
    // ❌ 编译错误：不能重写 final 方法
    // @Override
    // public void eat() { ... }
}
```

## 所有类的父类：Object

Java 中所有类都隐式继承 `java.lang.Object`，拥有以下常用方法：

| 方法 | 说明 |
| --- | --- |
| `toString()` | 返回对象的字符串表示 |
| `equals(Object)` | 判断对象是否相等 |
| `hashCode()` | 返回对象的哈希码 |
| `getClass()` | 返回对象的运行时类 |
