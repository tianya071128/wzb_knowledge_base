# 方法重载

方法重载（Overloading）是指同一个类中可以定义多个同名方法，只要它们的**参数列表不同**（参数个数、类型或顺序不同）。

## 基本规则

重载的判断标准只看**参数列表**，与返回类型、访问修饰符无关：

- ✅ 参数个数不同
- ✅ 参数类型不同
- ✅ 参数顺序不同
- ❌ 仅返回类型不同（不算重载）
- ❌ 仅参数名不同（不算重载）

```java
public class Calculator {
    // 参数个数不同
    public int add(int a, int b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 参数类型不同
    public double add(double a, double b) {
        return a + b;
    }

    // 参数顺序不同
    public void print(String s, int n) { ... }
    public void print(int n, String s) { ... }
}
```

```java
Calculator calc = new Calculator();
calc.add(1, 2);       // 调用 int add(int, int)
calc.add(1, 2, 3);    // 调用 int add(int, int, int)
calc.add(1.5, 2.5);   // 调用 double add(double, double)
```

## 构造方法重载

构造方法也可以重载，提供不同的初始化方式：

```java
public class Student {
    String name;
    int age;

    public Student() {
        this.name = "未知";
        this.age = 0;
    }

    public Student(String name) {
        this.name = name;
        this.age = 0;
    }

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

```java
Student s1 = new Student();              // 无参
Student s2 = new Student("张三");        // 单参
Student s3 = new Student("张三", 20);    // 双参
```

## 类型自动转换

调用重载方法时，如果参数类型不精确匹配，Java 会尝试自动转换：

```java
public class Printer {
    public void print(int n) {
        System.out.println("int: " + n);
    }

    public void print(double n) {
        System.out.println("double: " + n);
    }
}

Printer p = new Printer();
p.print(10);      // 精确匹配，调用 print(int)
p.print(10.5);    // 精确匹配，调用 print(double)
p.print(10L);     // long → double，调用 print(double)
```

## 方法的参数匹配规则（调用时找方法）

1. 优先**完全匹配类型**
2. 基本类型自动向上提升（int→long→float→double）
3. 引用类型向上转型
4. 可变参数作为最后选择

```java
public void fun(int a){
    System.out.println("int");
}
public void fun(long a){
    System.out.println("long");
}

fun(10);   //优先匹配 int
fun(10L);  //匹配 long
```



## 与方法重写的区别

| 对比项 | 重载（Overloading） | 重写（Overriding） |
| --- | --- | --- |
| 位置 | 同一个类中 | 父类与子类之间 |
| 方法名 | 相同 | 相同 |
| 参数列表 | 必须不同 | 必须相同 |
| 返回类型 | 可以不同 | 相同或子类型 |
| 访问修饰符 | 无限制 | 子类不能更严格 |
| 调用时机 | 编译时确定（静态绑定） | 运行时确定（动态绑定） |
