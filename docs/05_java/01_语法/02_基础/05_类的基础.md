# 类

类是 Java 的核心，是创建对象的模板。一个类可以包含**字段（属性）**、**方法**、**构造器**和**代码块**。

## 定义类

```java
[修饰符] class 类名 {
    // 字段（属性）
    // 构造器
    // 方法
}
```

```java
public class Student {
    // 字段
    String name;
    int age;

    // 构造器
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 方法
    public void study() {
        System.out.println(name + "正在学习");
    }
}
```

## 创建对象

使用 `new` 关键字调用构造器来创建对象实例：

```java
Student stu = new Student("张三", 20);
stu.study();    // 张三正在学习
```
