# 接口

接口（Interface）是一种完全抽象的类型，定义了一组方法的契约。类通过实现接口来承诺提供接口中定义的方法。Java 支持多实现，弥补了单继承的限制。

## 基本语法

```java
[修饰符] interface 接口名 {
    // 抽象方法（Java 8 前默认都是 public abstract）
    返回类型 方法名(参数列表);

    // 常量（默认是 public static final）
    类型 常量名 = 值;
}
```

```java
public interface Flyable {
    void fly();            // 抽象方法
    int MAX_SPEED = 1000;  // 常量
}
```

## 实现接口

使用 `implements` 关键字实现接口，必须实现接口中的所有没有 `default` 的抽象方法：

```java
public class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鸟在飞翔");
    }
}
```

```java
Flyable bird = new Bird();
bird.fly();  // 鸟在飞翔
```

## 多实现

Java 支持一个类实现多个接口，弥补单继承的限制：

```java
public interface Flyable {
    void fly();
}

public interface Swimmable {
    void swim();
}

public class Duck implements Flyable, Swimmable {
    @Override
    public void fly() {
        System.out.println("鸭子在飞");
    }

    @Override
    public void swim() {
        System.out.println("鸭子在游泳");
    }
}
```

```java
Duck duck = new Duck();
duck.fly();   // 鸭子在飞
duck.swim();  // 鸭子在游泳
```

## 接口中的成员

### 抽象方法

Java 8 之前，接口中只能有 `public abstract` 方法，**不能改别的权限**：

```java
public interface Animal {
    void eat();
    void sleep();
    // 等价于
    // public abstract void eat();
    // public abstract void sleep();
}
```

### 常量

接口中的字段默认是 `public static final`，即常量，**不能改别的权限**：

```java
public interface Config {
    String VERSION = "1.0";
    int MAX_SIZE = 100;
    // 等价于
    // public static final String VERSION = "1.0";
    // public static final int MAX_SIZE = 100;
}

System.out.println(Config.VERSION);  // 1.0
```

### 默认方法（Java 8+）

Java 8 引入了默认方法，允许接口中有方法实现，**不能改别的权限**：

```java
public interface Animal {
    void eat();  // 抽象方法

    default void sleep() {  // 默认方法
        System.out.println("动物在睡觉");
    }
}

public class Dog implements Animal {
    @Override
    public void eat() {
        System.out.println("狗在吃东西");
    }
    // sleep() 可以不重写，使用默认实现
}
```

### 静态方法（Java 8+）

Java 8 还允许接口中定义静态方法：

```java
public interface MathUtil {
    static int add(int a, int b) {
        return a + b;
    }
}

MathUtil.add(3, 5);  // 8
```

### 私有方法（Java 9+）

Java 9 允许接口中定义私有方法，用于复用默认方法中的逻辑：

```java
public interface DataProcessor {
    default void process() {
        validate();
        execute();
    }

    private void validate() {
        System.out.println("验证数据");
    }

    private void execute() {
        System.out.println("执行处理");
    }
}
```

## 接口继承

接口可以继承其他接口，使用 `extends`：

```java
public interface Animal {
    void eat();
}

public interface Flyable extends Animal {
    void fly();
}

public class Bird implements Flyable {
    @Override
    public void eat() {
        System.out.println("鸟在吃东西");
    }

    @Override
    public void fly() {
        System.out.println("鸟在飞翔");
    }
}
```

一个接口可以继承多个接口：

```java
public interface A {
    void methodA();
}

public interface B {
    void methodB();
}

public interface C extends A, B {
    void methodC();
}
```

## 接口冲突解决

### 方法冲突

当实现的多个接口有同名方法时，只需实现一次：

```java
public interface A {
    void doSomething();
}

public interface B {
    void doSomething();
}

public class MyClass implements A, B {
    @Override
    public void doSomething() {
        System.out.println("实现一次即可");
    }
}
```

### 默认方法冲突

当多个接口的默认方法冲突时，实现类必须重写该方法：

```java
public interface A {
    default void hello() {
        System.out.println("A 的 hello");
    }
}

public interface B {
    default void hello() {
        System.out.println("B 的 hello");
    }
}

public class MyClass implements A, B {
    @Override
    public void hello() {
        A.super.hello();  // 选择 A 的默认实现
        // 或 B.super.hello();
        // 或自定义实现
    }
}
```

### 类与接口冲突

当类继承的方法与接口默认方法冲突时，**类优先**：

```java
public class Parent {
    public void hello() {
        System.out.println("父类的 hello");
    }
}

public interface MyInterface {
    default void hello() {
        System.out.println("接口的 hello");
    }
}

public class Child extends Parent implements MyInterface {
    // 无需重写，父类方法优先
}
```

```java
new Child().hello();  // 父类的 hello
```

## 接口 vs 抽象类

| 对比项 | 接口 | 抽象类 |
| --- | --- | --- |
| 关键字 | `interface` | `abstract class` |
| 实现 | `implements` | `extends` |
| 多继承 | 支持多实现 | 不支持 |
| 构造方法 | 不能有 | 可以有 |
| 字段 | 只能有常量 | 可以有普通字段 |
| 方法 | 抽象方法 + 默认方法 + 静态方法 | 抽象方法 + 具体方法 |
| 访问修饰符 | 方法默认 `public` | 可以有 `private`、`protected` |
| 关系 | "can-do" 能力 | "is-a" 关系 |

## 使用场景

1. **定义行为规范**：多个不相关的类需要实现相同方法
2. **实现多重继承**：弥补 Java 单继承的限制
3. **解耦**：面向接口编程，降低耦合度

```java
// 不相关的类实现相同接口
public interface Comparable<T> {
    int compareTo(T other);
}

public class Student implements Comparable<Student> {
    int score;

    @Override
    public int compareTo(Student other) {
        return Integer.compare(this.score, other.score);
    }
}

public class Product implements Comparable<Product> {
    double price;

    @Override
    public int compareTo(Product other) {
        return Double.compare(this.price, other.price);
    }
}
```
