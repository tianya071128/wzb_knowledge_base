# 类型转换

Java 中的类型转换分为**基本类型的转换**和**引用类型的转换**。

## 基本类型的转换

### 自动类型转换（宽化转换）

小类型 → 大类型，自动进行，不会丢失数据。

```java
int a = 100;
long b = a;        // int → long，自动转换
double c = b;      // long → double，自动转换

// 转换顺序（从小到大）：
// byte → short → int → long → float → double
//         ↘ char ↗
```

### 强制类型转换（窄化转换）

大类型 → 小类型，需要显式声明，可能丢失数据。

```java
// 语法：(目标类型) 表达式

double a = 3.14;
int b = (int) a;           // 3.14 → 3（丢失小数部分）

long c = 100000L;
short d = (short) c;       // 100000 → -31072（超出范围，数据溢出）

int e = 128;
byte f = (byte) e;         // 128 → -128（byte 范围 -128~127）
```

### 精度丢失

```java
double a = 1234567890.123456789;
float b = (float) a;       // 1.23456794E9（精度丢失）

long c = 9876543210L;
int d = (int) c;           // 1286608618（超出 int 范围，数据溢出）
```

### 注意事项

#### 溢出不会报错

```java
int a = 2147483647;     // int 最大值
int b = a + 1;          // -2147483648（溢出，不会报错）

// 使用 Math.addExact 检测溢出
int c = Math.addExact(a, 1);    // ArithmeticException: integer overflow
```

#### 浮点数转整数的截断

```java
double a = 3.99;
int b = (int) a;        // 3（直接截断，不是四舍五入）

// 四舍五入使用 Math.round
int c = (int) Math.round(a);    // 4
```

#### char 的特殊转换

```java
int a = 65;
char b = (char) a;      // 'A'（Unicode 65 对应字符 A）

char c = 'A';
int d = c;              // 65（自动转换）
```

## 引用类型的转换

### 向上转型（自动）

子类 → 父类，自动进行，安全无风险。

```java
class Animal {
    void eat() { System.out.println("吃东西"); }
}

class Dog extends Animal {
    void bark() { System.out.println("汪汪叫"); }
}

Dog dog = new Dog();
Animal animal = dog;     // 向上转型（自动）

animal.eat();            // 可以调用父类方法
// animal.bark();        // 编译错误：无法调用子类特有方法
```

### 向下转型（强制）

父类 → 子类，需要显式声明，可能抛出 `ClassCastException`。

```java
Animal animal = new Dog();     // 向上转型
Dog dog = (Dog) animal;        // 向下转型（强制）

dog.bark();                    // 可以调用子类方法

// 错误的向下转型会抛出 ClassCastException
Animal animal2 = new Dog();
Cat cat = (Cat) animal2;       // ClassCastException
```

### instanceof 检查

向下转型前使用 `instanceof` 检查类型，避免 `ClassCastException`。

```java
Animal animal = new Dog();

// 先检查类型再转换
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;    // 安全转换
    dog.bark();
}

// Java 16+ 模式匹配（推荐）
if (animal instanceof Dog dog) {
    // 直接使用 dog 变量，无需显式转换
    dog.bark();
}
```

## 包装类的装箱和拆箱

```java
Integer a = 100;        // 自动装箱：int → Integer
int b = a;              // 自动拆箱：Integer → int

Integer c = null;
int d = c;              // NullPointerException（拆箱时 c 为 null）
```

## 字符串转换

```java
// 基本类型 → String
int a = 100;
String s1 = String.valueOf(a);      // "100"
String s2 = Integer.toString(a);    // "100"
String s3 = "" + a;                 // "100"（不推荐）

// String → 基本类型
String s = "100";
int b = Integer.parseInt(s);        // 100
long c = Long.parseLong(s);         // 100L
double d = Double.parseDouble(s);   // 100.0

// 格式错误会抛出 NumberFormatException
int e = Integer.parseInt("abc");    // NumberFormatException
```

## 类型转换总结

| 转换类型 | 方向        | 方式 | 风险                 |
| -------- | ----------- | ---- | -------------------- |
| 宽化转换 | 小 → 大     | 自动 | 无                   |
| 窄化转换 | 大 → 小     | 强制 | 精度丢失、溢出       |
| 向上转型 | 子类 → 父类 | 自动 | 无                   |
| 向下转型 | 父类 → 子类 | 强制 | ClassCastException   |
| 装箱     | 基本 → 包装 | 自动 | NullPointerException |
| 拆箱     | 包装 → 基本 | 自动 | NullPointerException |
