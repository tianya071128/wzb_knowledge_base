# 类的封装

封装是面向对象的三大特征之一，指将对象的**数据（字段）和操作数据的方法**捆绑在一起，对外隐藏实现细节，只暴露必要的接口。

## 封装的目的

- **保护数据**：防止外部直接访问或修改内部状态
- **隐藏实现**：调用者无需知道内部如何工作，只需知道如何使用
- **提高可维护性**：内部实现可以自由修改，不影响外部调用
- **提高安全性**：通过校验逻辑保证数据的有效性

## 实现封装

### 1. 字段设为 private

将字段声明为 `private`，外部无法直接访问：

```java
public class Student {
    private String name;
    private int age;
}
```

```java
Student stu = new Student();
// stu.name = "张三";  // ❌ 编译错误：name 是 private
```

### 2. 提供 public 的 getter/setter

通过公共方法提供受控访问：

```java
public class Student {
    private String name;
    private int age;

    // Getter
    public String getName() {
        return name;
    }

    // Setter（可加校验逻辑）
    public void setName(String name) {
        if (name != null && !name.isEmpty()) {
            this.name = name;
        }
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age > 0 && age < 150) {
            this.age = age;
        }
    }
}
```

```java
Student stu = new Student();
stu.setName("张三");
stu.setAge(20);
System.out.println(stu.getName());  // 张三
System.out.println(stu.getAge());   // 20

stu.setName("");       // 校验失败，不会修改
stu.setAge(-1);        // 校验失败，不会修改
stu.setAge(200);       // 校验失败，不会修改
```

## 封装的好处

### 数据校验

在 setter 中添加校验逻辑，确保数据有效性：

```java
public class BankAccount {
    private double balance;

    public void deposit(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("存款金额必须大于 0");
        }
        balance += amount;
    }

    public void withdraw(double amount) {
        if (amount <= 0 || amount > balance) {
            throw new IllegalArgumentException("取款金额无效");
        }
        balance -= amount;
    }

    public double getBalance() {
        return balance;
    }
}
```

### 隐藏实现细节

外部只需要知道如何使用，不需要知道内部如何工作：

```java
public class Counter {
    private int count = 0;

    public void increment() {
        count++;
    }

    public void decrement() {
        if (count > 0) {
            count--;
        }
    }

    public int getCount() {
        return count;
    }

    // 外部不需要知道 count 是如何管理的
    // 内部实现可以自由修改（比如改用 long 类型）
}
```

### 只读属性

只提供 getter 不提供 setter，实现只读：

```java
public class ImmutablePoint {
    private final int x;
    private final int y;

    public ImmutablePoint(int x, int y) {
        this.x = x;
        this.y = y;
    }

    public int getX() {
        return x;
    }

    public int getY() {
        return y;
    }
    // 没有 setter，对象创建后不可修改
}
```

## 封装原则

| 原则 | 说明 |
| --- | --- |
| 字段 `private` | 隐藏内部数据，防止直接访问 |
| 方法 `public` | 暴露必要的接口供外部调用 |
| 提供 getter/setter | 通过方法控制访问和修改 |
| setter 中加校验 | 确保数据有效性 |
| 内部实现可修改 | 只要不改变公共接口，内部实现可以自由调整 |
