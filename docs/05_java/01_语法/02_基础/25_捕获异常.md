# 捕获异常

捕获异常是指使用 `try-catch` 语句来处理程序运行过程中发生的异常，防止程序崩溃。

## 基本语法

```java
try {
    // 可能发生异常的代码
} catch (异常类型 变量名) {
    // 处理异常
}
```

## 基本示例

```java
public class ExceptionDemo {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;  // 除数为 0，抛出 ArithmeticException
            System.out.println("结果：" + result);  // 不会执行
        } catch (ArithmeticException e) {
            System.out.println("捕获到异常：" + e.getMessage());
        }
        
        System.out.println("程序继续执行...");  // 会执行
    }
}
```

输出：
```
捕获到异常：/ by zero
程序继续执行...
```

## 多个 catch 块

可以捕获多种类型的异常：

```java
public class MultiCatchDemo {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            System.out.println(arr[10]);  // 数组越界
            String str = null;
            System.out.println(str.length());  // 空指针
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("数组越界：" + e.getMessage());
        } catch (NullPointerException e) {
            System.out.println("空指针异常：" + e.getMessage());
        } catch (Exception e) {
            // 捕获其他所有异常（必须放在最后）
            System.out.println("其他异常：" + e.getMessage());
        }
    }
}
```

> **重要规则**：多个 catch 块必须按照**从具体到抽象**的顺序排列，即子类异常在前，父类异常在后。

```java
// ❌ 错误：父类异常在前，子类异常永远不会被匹配
try {
    // ...
} catch (Exception e) {
    // 所有异常都会被这里捕获
} catch (ArithmeticException e) {
    // 永远不会执行
}

// ✅ 正确：子类异常在前
try {
    // ...
} catch (ArithmeticException e) {
    // 先匹配具体异常
} catch (Exception e) {
    // 最后匹配通用异常
}
```

## 多异常合并处理（Java 7+）

如果多个异常的处理逻辑相同，可以合并：

```java
try {
    // 可能抛出多种异常的代码
    Class.forName("com.example.MyClass");
    FileReader reader = new FileReader("test.txt");
} catch (ClassNotFoundException | FileNotFoundException e) {
    // 同时处理多种异常
    System.out.println("发生异常：" + e.getMessage());
}
```

> **注意**：合并处理时，异常变量 `e` 是 `final` 的，不能重新赋值。

## finally 块

`finally` 块中的代码**无论是否发生异常都会执行**：

```java
public class FinallyDemo {
    public static void main(String[] args) {
        try {
            System.out.println("执行 try 块");
            int result = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("执行 catch 块");
        } finally {
            System.out.println("执行 finally 块");  // 总是会执行
        }
        
        System.out.println("程序结束");
    }
}
```

输出：
```
执行 try 块
执行 catch 块
执行 finally 块
程序结束
```

### finally 的执行时机

| 场景 | finally 是否执行 |
|------|-----------------|
| try 块正常结束 | ✅ 执行 |
| try 块抛出异常，被 catch 捕获 | ✅ 执行 |
| try 块抛出异常，未被捕获 | ✅ 执行（然后异常向上传播） |
| try 块中有 return | ✅ 执行（在 return 之前） |
| 调用 System.exit(0) | ❌ 不执行 |
| JVM 崩溃 | ❌ 不执行 |

### finally 中的 return 问题

```java
// ❌ 不推荐：finally 中的 return 会覆盖 try 中的 return
public static int test() {
    try {
        return 1;
    } finally {
        return 2;  // 最终返回 2，覆盖了 try 中的 1
    }
}

// ❌ 不推荐：finally 修改了 try 中要返回的值
public static int test2() {
    int result = 0;
    try {
        result = 1;
        return result;  // 准备返回 1
    } finally {
        result = 2;  // 修改了 result，但不影响返回值（基本类型）
    }
    // 返回 1
}

// ⚠️ 注意：如果是引用类型，finally 中的修改会影响返回值
public static StringBuilder test3() {
    StringBuilder sb = new StringBuilder("A");
    try {
        return sb;
    } finally {
        sb.append("B");  // 修改了对象内容，会影响返回值
    }
    // 返回 "AB"
}
```

> **最佳实践**：不要在 `finally` 中使用 `return`。

## try-with-resources（Java 7+）

自动关闭实现了 `AutoCloseable` 接口的资源，无需手动在 `finally` 中关闭：

```java
// 传统方式：手动关闭资源
public void readFileOld() {
    BufferedReader reader = null;
    try {
        reader = new BufferedReader(new FileReader("test.txt"));
        String line = reader.readLine();
        System.out.println(line);
    } catch (IOException e) {
        e.printStackTrace();
    } finally {
        if (reader != null) {
            try {
                reader.close();  // 手动关闭
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
}

// try-with-resources：自动关闭
public void readFileNew() {
    try (BufferedReader reader = new BufferedReader(new FileReader("test.txt"))) {
        String line = reader.readLine();
        System.out.println(line);
    } catch (IOException e) {
        e.printStackTrace();
    }
    // 自动关闭，无需 finally
}
```

### 多个资源

```java
try (
    Connection conn = DriverManager.getConnection(url, user, password);
    Statement stmt = conn.createStatement();
    ResultSet rs = stmt.executeQuery(sql)
) {
    while (rs.next()) {
        System.out.println(rs.getString("name"));
    }
} catch (SQLException e) {
    e.printStackTrace();
}
// 自动按相反顺序关闭：rs → stmt → conn
```

### 自定义可关闭资源

实现 `AutoCloseable` 接口：

```java
public class MyResource implements AutoCloseable {
    private String name;
    
    public MyResource(String name) {
        this.name = name;
        System.out.println("打开资源：" + name);
    }
    
    public void doSomething() {
        System.out.println("使用资源：" + name);
    }
    
    @Override
    public void close() throws Exception {
        System.out.println("关闭资源：" + name);
    }
}

// 使用
public class Demo {
    public static void main(String[] args) {
        try (MyResource resource = new MyResource("数据库连接")) {
            resource.doSomething();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

输出：
```
打开资源：数据库连接
使用资源：数据库连接
关闭资源：数据库连接
```

## 异常信息获取

异常对象提供了一些方法来获取异常信息：

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    // 获取异常信息
    System.out.println("异常消息：" + e.getMessage());
    System.out.println("异常类名：" + e.getClass().getName());
    
    // 打印堆栈跟踪
    e.printStackTrace();
    
    // 获取堆栈跟踪数组
    StackTraceElement[] stackTrace = e.getStackTrace();
    for (StackTraceElement element : stackTrace) {
        System.out.println(element);
    }
}
```

### getMessage() vs toString() vs printStackTrace()

| 方法 | 输出内容 |
|------|----------|
| `getMessage()` | 异常消息（简短描述） |
| `toString()` | 异常类名 + 异常消息 |
| `printStackTrace()` | 完整堆栈跟踪（输出到标准错误流） |

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("getMessage()：" + e.getMessage());
    System.out.println("toString()：" + e.toString());
    System.out.println("printStackTrace()：");
    e.printStackTrace();
}
```

输出：
```
getMessage()：/ by zero
toString()：java.lang.ArithmeticException: / by zero
printStackTrace()：
java.lang.ArithmeticException: / by zero
    at Demo.main(Demo.java:5)
```

## 异常捕获原则

### 1. 只捕获能处理的异常

```java
// ❌ 不好：捕获但不处理
try {
    // ...
} catch (IOException e) {
    // 什么都不做
}

// ✅ 好：捕获并处理
try {
    // ...
} catch (FileNotFoundException e) {
    System.out.println("文件不存在，使用默认配置");
    // 使用默认配置...
}
```

### 2. 捕获具体的异常

```java
// ❌ 不好：过于宽泛
try {
    // ...
} catch (Exception e) {
    // 不知道是什么异常
}

// ✅ 好：具体异常
try {
    // ...
} catch (IOException | SQLException e) {
    // 明确知道可能的异常类型
}
```

### 3. 不要捕获 Error

```java
// ❌ 错误：不应该捕获 Error
try {
    // ...
} catch (OutOfMemoryError e) {
    // 无法恢复
}

// ✅ 正确：只捕获 Exception
try {
    // ...
} catch (IOException e) {
    // 可恢复的异常
}
```

### 4. 尽早处理，不要传播过远

```java
// ❌ 不好：层层抛出，最终无法处理
public void method1() throws IOException { method2(); }
public void method2() throws IOException { method3(); }
public void method3() throws IOException { readFile(); }
public void readFile() throws IOException { /* ... */ }

// ✅ 好：在合适的层级处理
public void method1() {
    try {
        readFile();
    } catch (IOException e) {
        // 在这里处理
        logger.error("读取文件失败", e);
    }
}
```

## 常见场景

### 场景一：文件读取

```java
public String readFile(String path) {
    try (BufferedReader reader = new BufferedReader(new FileReader(path))) {
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            sb.append(line).append("\n");
        }
        return sb.toString();
    } catch (FileNotFoundException e) {
        System.out.println("文件不存在：" + path);
        return "";
    } catch (IOException e) {
        System.out.println("读取文件失败：" + e.getMessage());
        return "";
    }
}
```

### 场景二：网络请求

```java
public String fetchUrl(String url) {
    try {
        URL urlObj = new URL(url);
        HttpURLConnection conn = (HttpURLConnection) urlObj.openConnection();
        conn.setConnectTimeout(5000);
        conn.setReadTimeout(5000);
        
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(conn.getInputStream()))) {
            StringBuilder sb = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) {
                sb.append(line);
            }
            return sb.toString();
        }
    } catch (MalformedURLException e) {
        System.out.println("URL 格式错误：" + url);
    } catch (IOException e) {
        System.out.println("网络请求失败：" + e.getMessage());
    }
    return "";
}
```

### 场景三：数字转换

```java
public int parseNumber(String str) {
    try {
        return Integer.parseInt(str);
    } catch (NumberFormatException e) {
        System.out.println("无效的数字格式：" + str);
        return 0;  // 返回默认值
    }
}
```

### 场景四：反射操作

```java
public Object createInstance(String className) {
    try {
        Class<?> clazz = Class.forName(className);
        return clazz.getDeclaredConstructor().newInstance();
    } catch (ClassNotFoundException e) {
        System.out.println("类不存在：" + className);
    } catch (InstantiationException | IllegalAccessException | 
             NoSuchMethodException | InvocationTargetException e) {
        System.out.println("创建实例失败：" + e.getMessage());
    }
    return null;
}
```

## 注意事项

1. **try 块不能单独存在**：必须跟 catch 或 finally
2. **catch 块顺序**：从具体到抽象
3. **finally 执行时机**：在 return 之前执行
4. **资源关闭**：优先使用 try-with-resources
5. **不要忽略异常**：至少记录日志
6. **不要捕获 Error**：Error 表示严重错误，无法恢复
