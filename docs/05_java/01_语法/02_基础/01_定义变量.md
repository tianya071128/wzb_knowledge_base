# 定义变量

## 基本语法

Java 是强类型语言，变量必须先声明类型再使用。定义变量的基本格式：

```java
数据类型 变量名;       // 声明
数据类型 变量名 = 值;  // 声明并赋值
```

```java
int age;
age = 18;

String name = "张三";
double price = 9.9;
boolean isReady = true;
```

## 同时定义多个变量

可以在一行声明多个同类型变量，也可以分别赋值：

```java
int a = 1, b = 2, c = 3;

int x, y, z;
x = 10;
y = 20;
z = 30;
```

## 变量的分类

| 分类 | 位置 | 生命周期 | 示例 |
| --- | --- | --- | --- |
| 成员变量（字段） | 类内部、方法外部 | 随对象创建而存在，随对象销毁而销毁 | `private String name;` |
| 局部变量 | 方法内部、代码块内部 | 随方法/代码块执行而创建，执行结束而销毁 | `int count = 0;` |
| 静态变量 | 类内部，用 `static` 修饰 | 随类加载而创建，随类卸载而销毁 | `static int total;` |

```java
public class Student {
    // 成员变量
    private String name;
    private int age;

    // 静态变量
    static int count = 0;

    public void study() {
        // 局部变量
        int hours = 2;
        System.out.println(name + "学习了" + hours + "小时");
    }
}
```

## 常量

使用 `final` 关键字定义常量，一旦赋值不可修改：

```java
final double PI = 3.14159;
// PI = 3.14;  // 编译错误，final 变量不可重新赋值

public static final String VERSION = "1.0.0";  // 全局常量（静态常量）
```

## 类型推断（Java 10+）

使用 `var` 关键字，编译器根据右侧赋值自动推断变量类型：

```java
var message = "hello";   // 推断为 String
var count = 100;         // 推断为 int
var list = new ArrayList<String>();  // 推断为 ArrayList<String>
```

注意事项：
- `var` 只能用于局部变量，不能定义成员变量
- 声明时必须同时初始化，编译器才能推断类型
- 推断后类型不可变，后续不能赋其他类型的值
