# 静态字段和静态方法

`static` 关键字用于修饰类的成员，表示该成员**属于类本身**，而非某个对象实例。所有对象共享同一个静态成员。

## 静态字段

静态字段（类变量）被所有对象共享，无论创建多少个对象，静态字段只有一份：

```java
public class Student {
    static int count = 0;   // 静态字段，所有对象共享
    String name;            // 实例字段，每个对象独立一份

    public Student(String name) {
        this.name = name;
        count++;
    }
}
```

```java
Student s1 = new Student("张三");
Student s2 = new Student("李四");
Student s3 = new Student("王五");

System.out.println(Student.count);  // 3，所有对象共享
```

### 访问方式

```java
// ✅ 推荐：通过类名访问
Student.count = 0;

// ❌ 不推荐：通过对象访问（容易误解为实例字段）
Student s = new Student("张三");
s.count = 0;  // 语法上允许，但不推荐
```

### 静态字段的默认值

与实例字段一样，未初始化时会赋予默认值：

| 类型 | 默认值 |
| --- | --- |
| `int`、`long`、`byte`、`short` | `0` |
| `float`、`double` | `0.0` |
| `boolean` | `false` |
| 引用类型 | `null` |

### 静态常量

`static final` 常用于定义全局常量：

```java
public class MathConstants {
    public static final double PI = 3.14159;
    public static final String APP_NAME = "MyApp";
}

System.out.println(MathConstants.PI);       // 3.14159
System.out.println(MathConstants.APP_NAME); // MyApp
```

## 静态方法

静态方法属于类本身，通过类名调用，不需要创建对象：

```java
public class MathUtil {
    public static int add(int a, int b) {
        return a + b;
    }

    public static int max(int a, int b) {
        return a > b ? a : b;
    }
}

MathUtil.add(3, 5);   // 8
MathUtil.max(3, 5);   // 5
```

### 静态方法的限制

静态方法中**不能**访问非静态成员（因为非静态成员属于对象实例）：

```java
public class Student {
    String name;            // 实例字段
    static int count;       // 静态字段

    public static void doSomething() {
        // System.out.println(name);  // ❌ 错误：不能访问实例字段
        System.out.println(count);    // ✅ 可以访问静态字段
    }
}
```

> **原因**：静态方法在类加载时就存在，此时可能还没有创建任何对象，所以无法访问实例成员。

### 静态方法中不能使用 this

`this` 指向当前对象实例，静态方法不属于任何对象，因此不能使用 `this`：

```java
public static void test() {
    // System.out.println(this);  // ❌ 编译错误
}
```

## 静态代码块

`static { ... }` 在**类加载时执行一次**，常用于初始化静态字段：

```java
public class DatabaseConfig {
    static String url;
    static int port;

    static {
        // 类加载时执行一次
        url = "jdbc:mysql://localhost:3306/mydb";
        port = 3306;
        System.out.println("静态代码块执行");
    }
}
```

多个静态代码块按顺序执行：

```java
public class Config {
    static int a;
    static int b;

    static {
        a = 1;
    }

    static {
        b = 2;
    }
}
```

## 静态导入

使用 `import static` 可以省略类名前缀，直接调用静态成员：

```java
import static java.lang.Math.PI;
import static java.lang.Math.sqrt;

public class Circle {
    public double getArea(double radius) {
        return PI * radius * radius;  // 无需写 Math.PI
    }

    public double getDiagonal(double a, double b) {
        return sqrt(a * a + b * b);   // 无需写 Math.sqrt
    }
}
```

> **注意**：过度使用静态导入会降低代码可读性，建议只在频繁使用时引入。

## 静态 vs 实例对比

| 对比项 | 静态成员（static） | 实例成员（非 static） |
| --- | --- | --- |
| 归属 | 类本身 | 对象实例 |
| 内存 | 类加载时分配，共享一份 | 每个对象独立一份 |
| 访问方式 | 类名.成员名 | 对象名.成员名 |
| 访问限制 | 不能访问实例成员、不能用 this | 可以访问静态成员和实例成员 |
| 生命周期 | 随类加载而创建，随类卸载而销毁 | 随对象创建而创建，随对象销毁而销毁 |
