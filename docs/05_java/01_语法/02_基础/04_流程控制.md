# 流程控制

Java 的流程控制语句分为三类：**条件语句**、**循环语句**和**跳转语句**。

## 条件语句

### if / else

```java
int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### switch

```java
int day = 3;

switch (day) {
    case 1:
        System.out.println("周一");
        break;
    case 2:
        System.out.println("周二");
        break;
    case 3:
        System.out.println("周三");
        break;
    default:
        System.out.println("其他");
}
```



### switch 表达式（Java 14+）

使用 `->` 语法，无需 `break`，支持返回值：

```java
int day = 3;

String name = switch (day) {
    case 1 -> "周一";
    case 2 -> "周二";
    case 3 -> "周三";
    default -> "其他";
};
```

使用 `yield` 返回值（用于代码块形式）：

```java
int result = switch (day) {
    case 1, 2, 3 -> {
        System.out.println("工作日");
        yield 1;
    }
    case 4, 5 -> {
        System.out.println("周末前");
        yield 2;
    }
    default -> 0;
};
```

## 循环语句

### for

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

### while

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

### do-while

至少执行一次循环体：

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);
```

### 增强 for 循环（for-each）

用于遍历数组和集合：

```java
int[] arr = {10, 20, 30, 40, 50};

for (int val : arr) {
    System.out.println(val);
}
```

## 跳转语句

### break

跳出当前循环或 `switch` 语句：

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;    // 当 i == 5 时退出循环
    }
    System.out.println(i);  // 输出 0 1 2 3 4
}
```

### continue

跳过本次循环的剩余部分，进入下一次迭代：

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;   // 跳过偶数
    }
    System.out.println(i);  // 输出 1 3 5 7 9
}
```

### 标签（label）

配合 `break` / `continue` 跳出或跳过多层嵌套循环：

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break outer;    // 跳出外层循环
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}
```

## 三元运算符

`if-else` 的简写形式：

```java
int a = 10, b = 20;
int max = (a > b) ? a : b;    // 20
```
