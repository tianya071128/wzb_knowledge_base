# 抽象类

抽象类是不能被实例化的类，用于定义子类的通用模板。抽象类可以包含**抽象方法**（只有声明没有实现）和**具体方法**（有完整实现）。

## 基本语法

```java
[修饰符] abstract class 类名 {
    // 抽象方法（只有声明，没有方法体）
    [修饰符] abstract 返回类型 方法名(参数列表);

    // 具体方法（有完整实现）
    [修饰符] 返回类型 方法名(参数列表) {
        // 方法体
    }
}
```

```java
public abstract class Animal {
    String name;

    // 抽象方法：只有声明，没有实现
    public abstract void makeSound();

    // 具体方法：有完整实现
    public void eat() {
        System.out.println(name + "在吃东西");
    }
}
```

## 抽象类的特点

- 抽象类**不能被实例化**（不能 `new`）
- 抽象类可以包含抽象方法和具体方法
- 抽象类可以有构造方法（由子类调用）
- 抽象类可以有字段（包括 `private`、`protected`、`public`）

```java
// ❌ 错误：不能实例化抽象类
Animal a = new Animal();  // 编译错误

// ✅ 正确：通过子类实例化
Animal a = new Dog();
```

## 子类实现抽象方法

子类继承抽象类时，必须**实现所有抽象方法**，否则子类也必须是抽象类：

```java
public abstract class Animal {
    String name;

    public abstract void makeSound();
    public abstract void move();
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("汪汪汪");
    }

    @Override
    public void move() {
        System.out.println("狗在跑");
    }
}
```

```java
Animal dog = new Dog();
dog.makeSound();  // 汪汪汪
dog.move();       // 狗在跑
```

## 抽象类里面可以有什么

* ✅ 普通成员变量（实例字段）
  * 全部字段修饰符都支持
* ✅ static 静态字段、静态方法 

* ✅ 普通实例方法（有方法体） 

  * 支持所有的修饰符

* ✅ abstract 抽象方法（无方法体） 

  * 支持访问权限：`public`、`protected`、`default`
  * 抽象方法**不能用 private**：子类看不见，无法实现。
  * ❌不能搭配： `abstract + final`、`abstract + private`、`abstract + static`，全部冲突。

* ✅ 构造方法！抽象类**有构造方法**，只是不能直接 new；子类 new 的时候，`super()`调用抽象父类构造。 

* ✅ final 方法、static 代码块、实例代码块

* ❌ 不能有：`abstract` 构造方法；`abstract` 静态方法

### 抽象类的构造方法

抽象类可以有构造方法，由子类通过 `super()` 调用：

```java
public abstract class Animal {
    String name;

    public Animal(String name) {
        this.name = name;
    }

    public abstract void makeSound();
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 调用父类构造方法
    }

    @Override
    public void makeSound() {
        System.out.println(name + "：汪汪汪");
    }
}
```

```java
Dog dog = new Dog("旺财");
dog.makeSound();  // 旺财：汪汪汪
```

### 抽象类与具体方法

抽象类可以同时包含抽象方法和具体方法，具体方法可以被所有子类复用：

```java
public abstract class Shape {
    // 抽象方法：子类必须实现
    public abstract double getArea();
    public abstract double getPerimeter();

    // 具体方法：子类可以直接复用
    public void printInfo() {
        System.out.println("面积：" + getArea());
        System.out.println("周长：" + getPerimeter());
    }
}

public class Circle extends Shape {
    double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
}
```

```java
Circle circle = new Circle(5);
circle.printInfo();  // 复用父类的具体方法
// 面积：78.5398...
// 周长：31.4159...
```

## 抽象类 vs 普通类

| 对比项 | 抽象类 | 普通类 |
| --- | --- | --- |
| 实例化 | 不能实例化 | 可以实例化 |
| 抽象方法 | 可以有 | 不能有 |
| 具体方法 | 可以有 | 可以有 |
| 字段 | 可以有 | 可以有 |
| 构造方法 | 可以有（子类调用） | 可以有 |
| 继承 | 子类必须实现抽象方法 | 子类可以重写方法 |

## 抽象类 vs 接口

| 对比项 | 抽象类 | 接口 |
| --- | --- | --- |
| 关键字 | `abstract class` | `interface` |
| 继承 | 单继承 `extends` | 多实现 `implements` |
| 构造方法 | 可以有 | 不能有 |
| 字段 | 可以有普通字段 | 只能有 `public static final` 常量 |
| 方法 | 抽象方法 + 具体方法 | Java 8 前只有抽象方法 |
| 关系 | "is-a" 关系 | "can-do" 能力 |
