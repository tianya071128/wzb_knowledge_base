# 访问权限修饰符

Java 通过访问修饰符控制类、字段、方法的可见范围，实现**封装**。

## 四种访问级别

| 修饰符 | 同类 | 同包 | 子类 | 其他包 |
| --- | --- | --- | --- | --- |
| `private` | ✅ | ❌ | ❌ | ❌ |
| `default`默认（不写） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

### private

只能在本类内部访问，最严格的访问级别：

```java
public class Student {
    private String name;
    private int age;

    // 通过 public 方法提供受控访问
    public String getName() {
        return name;
    }

    public void setName(String name) {
        if (name != null && !name.isEmpty()) {
            this.name = name;
        }
    }
}
```

> **封装原则**：字段通常声明为 `private`，通过 `public` 的 getter/setter 方法提供访问。

### default（默认）

不写修饰符时为默认访问级别，同包内的类可以访问：

**就算 new 出对象，照样不能访问不同包中 default 的字段 / 方法。**

核心规则：**只认包，不认对象、不认继承关系**。

```java
// 包：com.example.school
public class Student {
    String name;      // default，同包可访问
    int age;          // default，同包可访问
}

// 同包
package com.example.school;
public class Teacher {
    public void check(Student stu) {
        System.out.println(stu.name);  // ✅ 同包可以访问
        Student stu2 = new Student();
        stu2.name // ✅ 同包中 new 的对象可以访问
    }
}

// 不同包
package com.example.other;
public class Outsider {
    public void check(Student stu) {
        // System.out.println(stu.name);  // ❌ 不同包无法访问
         Student stu2 = new Student();
         // stu2.name // ❌ 不同包 new 的对象无法访问
    }
}
```

### protected

同包类 + 子类（即使在不同包）都可以访问：

```java
package com.example.school;
public class Person {
    protected String name;
}

// 同包（可以访问）
package com.example.school;
public class Teacher {
    public void test(Person p) {
        System.out.println(p.name);  // ✅ 同包
    }
}

// 不同包但是子类（可以访问）
package com.example.other;
import com.example.school.Person;
public class Student extends Person {
    public void show() {
        System.out.println(this.name);  // ✅ 子类可以访问
    }
}
```

> **注意**：通过子类对象的引用访问父类的 `protected` 成员时，只能访问子类继承的那部分，不能访问其他父类对象的 `protected` 成员。

### public

任何地方都可以访问，最宽松的访问级别：

```java
public class Student {
    public String name;
    public void study() { ... }
}

// 任何包中都可以访问
Student stu = new Student();
stu.name = "张三";
stu.study();
```

## 类级别的修饰符

类本身只能使用 `public` 或默认两种修饰符：

| 修饰符 | 说明 |
| --- | --- |
| `public` | 任何包都可以使用该类 |
| 默认（不写） | 只有同包可以使用该类 |

```java
// 公共类，任何地方可以使用
public class Student { ... }

// 包私有类，只有同包可以访问
class Helper { ... }
```

> **注意**：一个 `.java` 文件中最多只能有一个 `public` 类，且文件名必须与该 `public` 类同名。

## 选择原则

| 场景 | 推荐修饰符 |
| --- | --- |
| 字段（属性） | `private`，通过 getter/setter 暴露 |
| 内部辅助方法 | `private` |
| 需要被子类复用的方法/字段 | `protected` |
| 对外公开的接口方法 | `public` |
| 常量 | `public static final` |
