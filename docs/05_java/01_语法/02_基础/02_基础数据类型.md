# 基础数据类型

Java 的数据类型分为两大类：**基本数据类型**（8 种）和 **引用数据类型**。

## 基本数据类型

### 整数类型

| 类型 | 占用字节 | 取值范围 | 默认值 |
| --- | --- | --- | --- |
| `byte` | 1 | -128 ~ 127 | 0 |
| `short` | 2 | -32768 ~ 32767 | 0 |
| `int` | 4 | -2^31 ~ 2^31-1 | 0 |
| `long` | 8 | -2^63 ~ 2^63-1 | 0L |

```java
byte a = 127;
short b = 32767;
int c = 100000;
long d = 100000L;  // long 字面量需要加 L 后缀
```

### 浮点类型

| 类型 | 占用字节 | 精度 | 默认值 |
| --- | --- | --- | --- |
| `float` | 4 | 约 6-7 位有效数字 | 0.0f |
| `double` | 8 | 约 15-17 位有效数字 | 0.0d |

```java
float f = 3.14f;    // float 字面量需要加 f 后缀
double d = 3.14;    // double 是默认浮点类型，可不加 d
```

### 字符类型

| 类型 | 占用字节 | 取值范围 | 默认值 |
| --- | --- | --- | --- |
| `char` | 2 | 0 ~ 65535（Unicode） | '\u0000' |

```java
char c1 = 'A';        // 单个字符
char c2 = 65;         // 用 Unicode 编码赋值
char c3 = '\n';       // 转义字符
char c4 = '\u0041';   // Unicode 表示（即 'A'）
```

### 布尔类型

| 类型 | 占用字节 | 取值 | 默认值 |
| --- | --- | --- | --- |
| `boolean` | 不确定（JVM 实现相关） | `true` / `false` | false |

```java
boolean isReady = true;
boolean isEmpty = false;
```

> **注意**：`boolean` 不能与整数进行隐式转换，不能用 `0` 或 `1` 代替 `false` 和 `true`。

## 引用数据类型

除 8 种基本类型外，其余都是引用类型：

- **类（Class）**：`String`、自定义类等
- **接口（Interface）**
- **数组（Array）**
- **枚举（Enum）**

```java
String name = "张三";       // 类
int[] scores = {90, 85, 78}; // 数组
```

## 默认值

当变量作为**类的成员变量**（字段）声明但未显式赋值时，Java 会自动赋予默认值：

| 类型 | 默认值 |
| --- | --- |
| `byte`、`short`、`int`、`long` | `0` |
| `float` | `0.0f` |
| `double` | `0.0d` |
| `char` | `'\u0000'`（空字符） |
| `boolean` | `false` |
| 引用类型（类、接口、数组、枚举） | `null` |

```java
public class Demo {
    int count;        // 默认值 0
    double price;     // 默认值 0.0d
    boolean flag;     // 默认值 false
    String name;      // 默认值 null
    int[] scores;     // 默认值 null
}
```

> **注意**：**局部变量没有默认值**，使用前必须显式赋值，否则编译报错。
>
> ```java
> public void test() {
>     int x;           // 未赋值
>     System.out.println(x);  // 编译错误：variable x might not have been initialized
> }
> ```

## 类型转换

### 自动类型转换（小 → 大）

容量小的类型可以自动转换为容量大的类型，无需强制转换：

```java
int a = 100;
long b = a;      // int → long，自动转换
double c = a;    // int → double，自动转换
```

转换顺序：`byte → short → int → long → float → double`

### 强制类型转换（大 → 小）

容量大的类型转容量小的类型需要强制转换，可能会丢失精度：

```java
long a = 100;
int b = (int) a;      // long → int，强制转换

double c = 3.99;
int d = (int) c;      // 结果为 3，小数部分被截断

int e = 130;
byte f = (byte) e;    // 结果为 -126，超出 byte 范围发生溢出
```
