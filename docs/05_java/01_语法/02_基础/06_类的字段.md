# 类的字段

字段（Field）是类中声明的变量，用于存储对象的状态数据。字段也叫**成员变量**或**实例变量**。

## 声明字段

```java
public class Student {
    String name;        // 实例字段
    int age;
}
```

## 字段的默认值

字段在声明后未显式赋值时，Java 会自动赋予默认值：

| 类型 | 默认值 |
| --- | --- |
| `byte`、`short`、`int`、`long` | `0` |
| `float` | `0.0f` |
| `double` | `0.0d` |
| `char` | `'\u0000'` |
| `boolean` | `false` |
| 引用类型 | `null` |

> **注意**：局部变量没有默认值，必须显式初始化后才能使用。

## 访问和修改字段

通过对象引用来访问字段：

```java
Student stu = new Student();

// 赋值
stu.name = "张三";
stu.age = 20;

// 读取
System.out.println(stu.name);  // 张三
System.out.println(stu.age);   // 20
```

## 在方法中使用字段

方法中可以直接通过字段名访问当前对象的字段，也可以用 `this` 显式引用：

```java
public class Student {
    String name;
    int age;

    public void introduce() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
        // 等价于
        System.out.println("我叫" + this.name + "，今年" + this.age + "岁");
    }
}
```

### 字段与局部变量同名

当字段和局部变量同名时，局部变量会**遮蔽**字段，需要用 `this` 访问字段：

```java
public class Student {
    String name;

    public void setName(String name) {
        // name = name;      // 错误：只是给参数赋值
        this.name = name;    // 正确：this.name 是字段，name 是参数
    }
}
```

## 字段的修饰符

### 访问修饰符

| 修饰符 | 同类 | 同包 | 子类 | 其他包 |
| --- | --- | --- | --- | --- |
| `private` | ✅ | ❌ | ❌ | ❌ |
| `default`默认（不写） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

```java
public class Student {
    private String name;     // 只能本类访问
    int age;                 // 同包可访问
    protected String school; // 同包 + 子类可访问
    public String id;        // 任何地方可访问
}
```

> **封装原则**：字段通常声明为 `private`，通过 `public` 的 getter/setter 方法提供访问。

### static 修饰符

`static` 字段属于类本身，被所有对象共享：

```java
public class Student {
    static int count = 0;   // 静态字段，所有对象共享

    public Student() {
        count++;
    }
}

new Student();
new Student();
System.out.println(Student.count);  // 2
```

### final 修饰符

`final` 字段一旦赋值就不可修改，常用于定义常量：

```java
public class MathConstants {
    public static final double PI = 3.14159;
    public final String ID = "MC-001";  // 实例常量，每个对象不同但不可修改
}
```

### volatile 修饰符

`volatile` 保证字段在多线程环境中的可见性，每次读取都从主内存获取最新值：

```java
public class Task {
    volatile boolean running = true;

    public void stop() {
        running = false;  // 其他线程能立即看到修改
    }
}
```

### transient 修饰符

`transient` 标记字段不参与序列化，序列化时该字段的值会被忽略，反序列化后恢复为默认值：

```java
import java.io.Serializable;

public class User implements Serializable {
    String name;             // 会被序列化
    transient String password; // 不会被序列化
}
```

> **注意**：`transient` 只能修饰实例字段，不能修饰 `static` 字段（静态字段本身就不参与序列化）。

## Getter 和 Setter

**遵循封装原则，用 `private` 保护字段，通过方法提供受控访问**：

```java
public class Student {
    private String name;
    private int age;

    // Getter
    public String getName() {
        return name;
    }

    // Setter（可加校验逻辑）
    public void setName(String name) {
        if (name != null && !name.isEmpty()) {
            this.name = name;
        }
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age > 0 && age < 150) {
            this.age = age;
        }
    }
}
```

```java
Student stu = new Student();
stu.setName("张三");
stu.setAge(20);
System.out.println(stu.getName());  // 张三
System.out.println(stu.getAge());   // 20
```
