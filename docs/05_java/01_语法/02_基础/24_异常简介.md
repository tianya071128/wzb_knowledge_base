# 异常简介

异常（Exception）是程序运行过程中发生的错误或意外情况。Java 提供了完善的异常处理机制，使程序能够优雅地处理错误。

## 异常的本质

异常是一个对象，当程序出现错误时，会创建一个异常对象并抛出。

```java
public class ExceptionDemo {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3};

        // 数组越界，抛出 ArrayIndexOutOfBoundsException
        System.out.println(arr[10]);

        // 下面的代码不会执行
        System.out.println("程序结束");
    }
}
```

运行结果：

```
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 10 out of bounds for length 3
    at ExceptionDemo.main(ExceptionDemo.java:6)
```

## 异常体系结构

```
Throwable（根类）
├── Error（严重错误）
│   ├── OutOfMemoryError
│   ├── StackOverflowError
│   └── ...
└── Exception（异常）
    ├── RuntimeException（运行时异常）
    │   ├── NullPointerException
    │   ├── ArrayIndexOutOfBoundsException
    │   ├── ClassCastException
    │   └── ArithmeticException
    └── 检查异常（Checked Exception）
        ├── IOException
        ├── SQLException
        └── FileNotFoundException
```

### Error vs Exception

| 特性             | Error                                | Exception                         |
| ---------------- | ------------------------------------ | --------------------------------- |
| **性质**         | 严重错误                             | 可恢复的错误                      |
| **可处理性**     | ❌ 不可处理                          | ✅ 可以处理                       |
| **原因**         | JVM 系统级错误                       | 程序逻辑错误                      |
| **示例**         | OutOfMemoryError、StackOverflowError | IOException、NullPointerException |
| **是否需要处理** | 否                                   | 是                                |

## 检查异常 vs 运行时异常

Java 中的异常分为两大类：**检查异常**（Checked Exception）和**运行时异常**（Runtime Exception，也叫未检查异常 Unchecked Exception）。

### 对比总览 

| 特性             | 检查异常                  | 运行时异常                                |
| ---------------- | ------------------------- | ----------------------------------------- |
| **继承关系**     | 继承 `Exception`          | 继承 `RuntimeException`                   |
| **检查时机**     | 编译时检查                | 运行时检查                                |
| **是否必须处理** | ✅ 必须处理               | ❌ 不强制处理                             |
| **处理方式**     | try-catch 或 throws       | 可选处理                                  |
| **可恢复性**     | 通常可恢复                | 通常是编程错误                            |
| **典型场景**     | 外部资源操作              | 程序逻辑错误                              |
| **示例**         | IOException、SQLException | NullPointerException、ArithmeticException |

### 检查异常（Checked Exception）

#### 基本特点

- 继承自 `Exception` 类（不包括 `RuntimeException` 及其子类）
- **编译时检查**：编译器强制要求处理
- 表示**可恢复的异常**情况
- 通常与**外部资源**或**环境**相关

#### 必须处理的两种方式

**方式一：try-catch 捕获处理**

```java
public void readFile() {
    try {
        FileReader reader = new FileReader("test.txt");
        int data = reader.read();
        System.out.println("读取到数据：" + data);
    } catch (FileNotFoundException e) {
        System.out.println("文件不存在，请检查路径");
    } catch (IOException e) {
        System.out.println("读取文件时发生错误");
    }
}
```

**方式二：throws 声明抛出**

```java
// 声明抛出异常，由调用者处理
public void readFile() throws IOException {
    FileReader reader = new FileReader("test.txt");
    int data = reader.read();
}

// 调用者必须处理
public static void main(String[] args) {
    try {
        readFile();
    } catch (IOException e) {
        e.printStackTrace();
    }
}
```

#### 常见检查异常

| 异常类                       | 说明           | 触发场景                        |
| ---------------------------- | -------------- | ------------------------------- |
| `IOException`                | I/O 操作异常   | 文件读写、网络通信失败          |
| `FileNotFoundException`      | 文件不存在     | 打开不存在的文件                |
| `SQLException`               | 数据库操作异常 | SQL 执行失败、连接断开          |
| `ClassNotFoundException`     | 类未找到       | 反射加载类时类不存在            |
| `InterruptedException`       | 线程被中断     | Thread.sleep() 期间线程被中断   |
| `CloneNotSupportedException` | 不支持克隆     | 调用 clone() 但未实现 Cloneable |

#### 实际应用场景

```java
// 文件操作
public String loadConfig(String path) throws IOException {
    BufferedReader reader = null;
    try {
        reader = new BufferedReader(new FileReader(path));
        return reader.readLine();
    } finally {
        if (reader != null) {
            reader.close();  // 必须处理关闭时的 IOException
        }
    }
}

// 数据库操作
public User findUser(int id) throws SQLException {
    Connection conn = DriverManager.getConnection(url, user, password);
    try {
        PreparedStatement stmt = conn.prepareStatement("SELECT * FROM users WHERE id = ?");
        stmt.setInt(1, id);
        ResultSet rs = stmt.executeQuery();
        // 处理结果...
    } finally {
        conn.close();  // 必须处理关闭时的 SQLException
    }
}

// 反射操作
public Object createInstance(String className) throws ClassNotFoundException,
        InstantiationException, IllegalAccessException {
    Class<?> clazz = Class.forName(className);  // ClassNotFoundException
    return clazz.newInstance();  // InstantiationException, IllegalAccessException
}
```

### 运行时异常（Runtime Exception）

#### 基本特点

- 继承自 `RuntimeException` 类
- **运行时检查**：编译器不强制要求处理
- 表示**编程错误**，通常应该通过代码逻辑避免
- **可以不处理**，但建议通过预防来避免

#### 为什么可以不处理？

运行时异常通常表示**程序 Bug**，应该通过改进代码来避免，而不是通过异常处理来恢复：

```java
// ❌ 不好：用 try-catch 处理可以避免的 Bug
public String getFirstElement(List<String> list) {
    try {
        return list.get(0);
    } catch (IndexOutOfBoundsException e) {
        return null;  // 掩盖了问题
    }
}

// ✅ 好：通过检查避免问题
public String getFirstElement(List<String> list) {
    if (list == null || list.isEmpty()) {
        return null;  // 或者抛出有意义的异常
    }
    return list.get(0);
}
```

#### 常见运行时异常

| 异常类                            | 说明         | 触发场景             | 预防方法               |
| --------------------------------- | ------------ | -------------------- | ---------------------- |
| `NullPointerException`            | 空指针       | 调用 null 对象的方法 | 判空检查               |
| `ArrayIndexOutOfBoundsException`  | 数组越界     | 访问非法数组索引     | 检查索引范围           |
| `StringIndexOutOfBoundsException` | 字符串越界   | 访问非法字符串索引   | 检查长度               |
| `ClassCastException`              | 类型转换错误 | 错误的类型转换       | 使用 instanceof 检查   |
| `ArithmeticException`             | 算术异常     | 除数为 0             | 检查除数               |
| `NumberFormatException`           | 数字格式异常 | 字符串转数字失败     | 检查格式或用 try-catch |
| `IllegalArgumentException`        | 非法参数     | 方法参数不合法       | 参数校验               |
| `IllegalStateException`           | 非法状态     | 对象状态不正确       | 检查对象状态           |
| `UnsupportedOperationException`   | 不支持的操作 | 调用不支持的方法     | 检查 API 文档          |

#### 实际场景示例

```java
// NullPointerException
String str = null;
System.out.println(str.length());  // ❌ NullPointerException

// 预防
if (str != null) {
    System.out.println(str.length());
}

// ArrayIndexOutOfBoundsException
int[] arr = {1, 2, 3};
System.out.println(arr[5]);  // ❌ ArrayIndexOutOfBoundsException

// 预防
if (index >= 0 && index < arr.length) {
    System.out.println(arr[index]);
}

// ClassCastException
Object obj = "Hello";
Integer num = (Integer) obj;  // ❌ ClassCastException

// 预防
if (obj instanceof Integer) {
    Integer num = (Integer) obj;
}

// ArithmeticException
int result = 10 / 0;  // ❌ ArithmeticException: / by zero

// 预防
if (divisor != 0) {
    int result = 10 / divisor;
}

// NumberFormatException
String numStr = "abc";
int num = Integer.parseInt(numStr);  // ❌ NumberFormatException

// 预防
try {
    int num = Integer.parseInt(numStr);
} catch (NumberFormatException e) {
    System.out.println("无效的数字格式");
}

// IllegalArgumentException
public void setAge(int age) {
    if (age < 0 || age > 150) {
        throw new IllegalArgumentException("年龄必须在 0-150 之间");
    }
    this.age = age;
}
```

### 如何选择？

#### 使用检查异常的场景

- **外部资源操作**：文件、网络、数据库
- **可恢复的错误**：可以提供替代方案
- **调用者需要知道的情况**：强制调用者处理

```java
// 文件不存在，调用者可以提供默认配置或提示用户
public Config loadConfig(String path) throws ConfigNotFoundException {
    // ...
}
```

#### 使用运行时异常的场景

- **编程错误**：参数校验、状态检查
- **无法恢复的错误**：程序 Bug
- **框架设计**：Spring、Hibernate 大量使用运行时异常

```java
// 参数错误，应该由调用者保证
public void setName(String name) {
    if (name == null || name.isEmpty()) {
        throw new IllegalArgumentException("姓名不能为空");
    }
    this.name = name;
}
```

### 自定义异常的选择

```java
// 检查异常：继承 Exception
public class ConfigNotFoundException extends Exception {
    public ConfigNotFoundException(String message) {
        super(message);
    }
}

// 运行时异常：继承 RuntimeException
public class InvalidParameterException extends RuntimeException {
    public InvalidParameterException(String message) {
        super(message);
    }
}
```

**选择原则**：

- 如果调用者**必须处理**（可恢复）→ 检查异常
- 如果是**编程错误**（不可恢复）→ 运行时异常

## 异常处理最佳实践

### 1. 只捕获能处理的异常

```java
// ❌ 不好：捕获所有异常但不处理
try {
    // ...
} catch (Exception e) {
    // 什么都不做
}

// ✅ 好：只捕获能处理的异常
try {
    // ...
} catch (FileNotFoundException e) {
    System.out.println("文件不存在，使用默认配置");
}
```

### 2. 不要忽略异常

```java
// ❌ 不好：忽略异常
try {
    // ...
} catch (IOException e) {
    // 忽略
}

// ✅ 好：至少记录日志
try {
    // ...
} catch (IOException e) {
    logger.error("读取文件失败", e);
}
```

### 3. 使用具体的异常类型

```java
// ❌ 不好：过于宽泛
try {
    // ...
} catch (Exception e) {
    // ...
}

// ✅ 好：具体异常
try {
    // ...
} catch (IOException | SQLException e) {
    // ...
}
```

### 4. 尽早抛出异常

```java
// ❌ 不好：延迟发现问题
public void process(String data) {
    // 很多代码...
    if (data == null) {
        throw new IllegalArgumentException("data 不能为 null");
    }
}

// ✅ 好：尽早检查
public void process(String data) {
    if (data == null) {
        throw new IllegalArgumentException("data 不能为 null");
    }
    // 业务逻辑...
}
```

### 5. 使用 try-with-resources

```java
// ✅ 推荐：自动管理资源
try (Connection conn = DriverManager.getConnection(url, user, password);
     Statement stmt = conn.createStatement();
     ResultSet rs = stmt.executeQuery(sql)) {
    // 处理结果
} catch (SQLException e) {
    logger.error("数据库操作失败", e);
}
```

## 常见异常总结

| 异常                             | 原因             | 解决方法             |
| -------------------------------- | ---------------- | -------------------- |
| `NullPointerException`           | 对象为 null      | 检查 null 判断       |
| `ArrayIndexOutOfBoundsException` | 数组索引越界     | 检查索引范围         |
| `ClassCastException`             | 类型转换错误     | 使用 instanceof 检查 |
| `ArithmeticException`            | 除数为 0         | 检查除数             |
| `NumberFormatException`          | 字符串转数字失败 | 检查字符串格式       |
| `IllegalArgumentException`       | 参数不合法       | 检查参数范围         |
| `IOException`                    | I/O 操作失败     | 检查文件/网络连接    |
| `FileNotFoundException`          | 文件不存在       | 检查文件路径         |

## 异常处理流程总结

```
1. 发生异常 → 创建异常对象
2. 查找 catch 块 → 按顺序匹配异常类型
3. 执行 catch 块 → 处理异常
4. 执行 finally 块 → 清理资源（如果有）
5. 程序继续执行 / 异常向上传播
```
