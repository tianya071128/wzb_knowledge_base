# 构造方法

构造方法（Constructor）是用于创建和初始化对象的特殊方法，在 `new` 关键字创建对象时自动调用。

## 基本语法

```java
[修饰符] 类名(参数列表) {
    // 初始化代码
}
```

- 方法名必须与**类名相同**
- **没有返回类型**（不是 `void`）
- 可以重载，一个类可以有多个构造方法

## 默认构造方法

如果类中没有定义任何构造方法，Java 会自动提供一个**无参的默认构造方法**：

```java
public class Student {
    String name;
    int age;
    // 编译器自动生成：public Student() {}
}

Student stu = new Student();  // 调用默认构造方法
```

> **注意**：一旦手动定义了任何构造方法，默认构造方法就**不再自动提供**。如果需要无参构造，必须显式定义。

## 有参构造方法

```java
public class Student {
    String name;
    int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

Student stu = new Student("张三", 20);
```

## 构造方法重载

同一个类可以定义多个构造方法，只要参数列表不同：

```java
public class Student {
    String name;
    int age;

    // 无参构造
    public Student() {
        this.name = "未知";
        this.age = 0;
    }

    // 单参构造
    public Student(String name) {
        this.name = name;
        this.age = 0;
    }

    // 双参构造
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

```java
Student s1 = new Student();              // 无参构造
Student s2 = new Student("李四");        // 单参构造
Student s3 = new Student("王五", 25);    // 双参构造
```

## this 调用其他构造方法

使用 `this(...)` 可以在一个构造方法中调用本类的另一个构造方法，**必须是构造方法中的第一行语句**：

```java
public class Student {
    String name;
    int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public Student(String name) {
        this(name, 0);   // 调用双参构造方法，age 默认 0
    }

    public Student() {
        this("未知", 0);  // 调用双参构造方法
    }
}
```

## 构造方法的修饰符

### 访问修饰符

| 修饰符 | 说明 |
| --- | --- |
| `public` | 任何地方都可以创建该类的对象 |
| `protected` | 同包类或子类可以创建对象 |
| `default`默认（不写） | 只有同包类可以创建对象 |
| `private` | 只有本类内部可以创建对象（常用于单例模式） |

```java
public class Singleton {
    private static Singleton instance;

    private Singleton() {  // 私有构造方法，外部无法 new
    }

    public static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}

Singleton s = Singleton.getInstance();
```

## 构造方法与方法的区别

| 对比项 | 构造方法 | 普通方法 |
| --- | --- | --- |
| 名称 | 必须与类名相同 | 自定义名称 |
| 返回类型 | 没有返回类型 | 有返回类型（可以是 void） |
| 调用方式 | `new` 关键字自动调用 | 通过对象引用调用 |
| 继承 | 不能继承 | 可以继承 |
| 数量 | 可以有多个（重载） | 可以有多个（重载） |
