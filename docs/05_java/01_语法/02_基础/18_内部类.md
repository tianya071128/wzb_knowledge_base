# 内部类

内部类（Inner Class）是定义在另一个类内部的类。内部类可以访问外部类的所有成员（包括 `private`），常用于逻辑上属于外部类但又需要独立封装的场景。

## 内部类的分类

| 类型 | 声明位置 | 是否有构造方法 | 是否持有外部类引用 |
| --- | --- | --- | --- |
| 成员内部类 | 类体内 | 有 | 是 |
| 静态内部类 | 类体内，加 `static` | 有 | 否 |
| 局部内部类 | 方法体内 | 有 | 是（访问 effectively final 变量） |
| 匿名内部类 | 表达式中 | 无（通过构造参数） | 是（访问 effectively final 变量） |

## 成员内部类

定义在外部类内部的普通类：

```java
public class Outer {
    private String name = "外部类";

    // 成员内部类
    public class Inner {
        public void show() {
            System.out.println("访问外部类字段：" + name);  // 可以访问 private
        }
    }
}
```

```java
// 创建成员内部类对象（必须依赖外部类实例）
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.show();  // 访问外部类字段：外部类
```

### 特点

- 成员内部类不能有静态声明（除非是编译期常量 `static final`）。
- 成员内部类对象隐式地持有一个指向外部类对象的引用，所以必须先有外部类对象，才能创建内部类对象。
- 在内部类中可以使用 `Outer.this` 获取外部类引用。
- 可以访问外部类全部字段方法，包含 `private`

## 静态内部类

使用 `static` 修饰的内部类：

```java
public class Outer {
    private static String name = "外部类";

    // 静态内部类
    public static class StaticInner {
        public void show() {
            System.out.println("访问外部类静态字段：" + name);
            // 不能访问外部类的非静态成员
        }
    }
}
```
它与外部类的实例无关，可以直接创建：

```java
// 创建静态内部类对象（不依赖外部类实例）
Outer.StaticInner inner = new Outer.StaticInner();
inner.show();
```

### 特点

- 静态内部类不持有外部类实例的引用，因此不能直接访问外部类的非静态成员。

- 它可以有静态成员和非静态成员。

- 只能访问外部类 **static 静态成员**

- 常用于作为辅助类或建造者模式中的 Builder。

  ```java
  public class UserVO {
      private String name;
      //静态内部类
      public static class AddressVO{
          private String city;
      }
  }
  ```

  

## 局部内部类

局部内部类是定义在方法、构造器或代码块内部的类，作用域仅限于该代码块：

```java
public class Outer {
    public void doSomething() {
        class Local {
            public void show() {
                System.out.println("局部内部类");
            }
        }
		
        // 在方法内部直接执行 new
        Local local = new Local();
        local.show();
    }
}
```

### 特点

- 局部内部类不能用 `public`、`private`、`protected`、`static` 修饰。
- 可以访问外部类的成员
  - 如果没有同名的,直接访问
  - 如果存在同名的, 通过 `Outer.this` 引用
- 可以访问方法内部(局部变量)被 `final` 或 effectively final（有效 final）。
- 局部内部类在方法结束后就会被销毁，但它的对象可能仍然存在（例如作为返回值），此时它访问的局部变量会被复制一份。

## 匿名内部类

没有类名的内部类，通常用于实现接口或继承抽象类：

```java
public interface Greeting {
    void sayHello();
}

public class Main {
    public static void main(String[] args) {
        // 匿名内部类实现接口 Greeting
        Greeting greeting = new Greeting() {
            @Override
            public void sayHello() {
                System.out.println("Hello!");
            }
        };

        greeting.sayHello();  // Hello!
    }
}
```

### 特点

* 匿名内部类没有构造器，因为它没有名字。

* 它可以访问外部类的成员和方法内 effectively final 的局部变量。

* 在 Java 8 之后，如果接口只有一个抽象方法（函数式接口），可以用 Lambda 表达式替代匿名内部类。

* 可以实现接口或者继承类

  ```java
  public class Main {
      public static void main(String[] args) {
          HashMap<String, String> map1 = new HashMap<>(); // 普通的HashMap实例
          HashMap<String, String> map2 = new HashMap<>() {}; // 匿名类, 没有需要重写的内容
          HashMap<String, String> map3 = new HashMap<>() {
              // 添加了static代码块来初始化数据
              {
                  put("A", "1");
                  put("B", "2");
              }
          };
          System.out.println(map3.get("A"));
      }
  }
  ```

### 访问外部变量

匿名内部类访问外部局部变量时，变量必须是 `final` 或**事实上的 final**（Java 8+）：

```java
public class Main {
    public void test() {
        final int count = 10;

        Runnable r = new Runnable() {
            @Override
            public void run() {
                System.out.println(count);  // ✅ 可以访问
            }
        };
    }
}
```

### 常见用途

**事件监听器**：

```java
button.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        System.out.println("按钮被点击");
    }
});
```

**线程**：

```java
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("线程执行中");
    }
}).start();
```

### Lambda 替代匿名内部类

Java 8 引入 Lambda，函数式接口的匿名内部类可以用 Lambda 替代：

```java
// 匿名内部类
Runnable r1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello");
    }
};

// Lambda（等价）
Runnable r2 = () -> System.out.println("Hello");
```

> **注意**：Lambda 只能替代**函数式接口**（只有一个抽象方法的接口）。

## 内部类的访问权限

| 类型       | 定义位置       | 是否可有静态成员   | 是否持有外部类引用 | 创建方式                  |
| :--------- | :------------- | :----------------- | :----------------- | :------------------------ |
| 成员内部类 | 类体中，方法外 | 否（除非静态常量） | 是                 | `outer.new Inner()`       |
| 局部内部类 | 方法或代码块内 | 否                 | 是                 | 在方法内直接 `new`        |
| 匿名内部类 | 表达式内       | 否                 | 是                 | `new 接口/父类() { ... }` |
| 静态内部类 | 类体中，方法外 | 是                 | 否                 | `new Outer.StaticInner()` |
