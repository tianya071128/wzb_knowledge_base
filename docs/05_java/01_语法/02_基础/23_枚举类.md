# 枚举类

枚举（enum）是一种特殊的类，用于定义固定数量的常量实例。枚举使代码更简洁、类型更安全。

## 基本语法

```java
enum 枚举名 {
    枚举值1, 枚举值2, 枚举值3, ...;
}
```

- 枚举值默认是 `public static final` 的
- 枚举值通常使用**全大写**命名
- 枚举类隐式继承自 `java.lang.Enum`

## 定义枚举

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY;
}

// 使用枚举
Day today = Day.MONDAY;
System.out.println(today);  // MONDAY
```

## 枚举的常用方法

枚举类提供了一些内置方法：

| 方法                   | 说明                          |
| ---------------------- | ----------------------------- |
| `values()`             | 返回所有枚举值的数组          |
| `valueOf(String name)` | 根据名称返回对应的枚举值      |
| `name()`               | 返回枚举值的名称              |
| `ordinal()`            | 返回枚举值的序号（从 0 开始） |

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY;
}

// 遍历所有枚举值
for (Day day : Day.values()) {
    System.out.println(day);
}

// 根据名称获取枚举值
Day day = Day.valueOf("MONDAY");

// 获取枚举值信息
Day today = Day.MONDAY;
System.out.println(today.name());      // MONDAY
System.out.println(today.ordinal());   // 0
```

## 枚举的构造方法

枚举可以有自己的构造方法，用于初始化字段：

```java
public enum Season {
    SPRING("春天", 1),
    SUMMER("夏天", 2),
    AUTUMN("秋天", 3),
    WINTER("冬天", 4);

    private final String chineseName;
    private final int order;

    // 构造方法必须是 private 或包级私有
    Season(String chineseName, int order) {
        this.chineseName = chineseName;
        this.order = order;
    }

    public String getChineseName() {
        return chineseName;
    }

    public int getOrder() {
        return order;
    }
}

// 使用
Season season = Season.SPRING;
System.out.println(season.getChineseName());  // 春天
System.out.println(season.getOrder());        // 1
```

> **注意**：枚举的构造方法默认且必须是私有的，不能声明为 `public` 或 `protected`。

## 枚举的字段和方法

枚举可以包含字段、方法和实现接口：

```java
public enum Operation {
    ADD("+") {
        @Override
        public double apply(double a, double b) {
            return a + b;
        }
    },
    SUBTRACT("-") {
        @Override
        public double apply(double a, double b) {
            return a - b;
        }
    },
    MULTIPLY("*") {
        @Override
        public double apply(double a, double b) {
            return a * b;
        }
    },
    DIVIDE("/") {
        @Override
        public double apply(double a, double b) {
            if (b == 0) throw new IllegalArgumentException("除数不能为 0");
            return a / b;
        }
    };

    private final String symbol;

    Operation(String symbol) {
        this.symbol = symbol;
    }

    public String getSymbol() {
        return symbol;
    }

    // 抽象方法，每个枚举值必须实现
    public abstract double apply(double a, double b);
}

// 使用
double result = Operation.ADD.apply(10, 5);  // 15.0
System.out.println(Operation.MULTIPLY.getSymbol());  // *
```

## 枚举实现接口

枚举可以实现一个或多个接口：

```java
public interface Describable {
    String describe();
}

public enum Status implements Describable {
    PENDING("待处理"),
    IN_PROGRESS("处理中"),
    COMPLETED("已完成");

    private final String description;

    Status(String description) {
        this.description = description;
    }

    @Override
    public String describe() {
        return description;
    }
}

// 使用
Status status = Status.PENDING;
System.out.println(status.describe());  // 待处理
```

## 枚举在 switch 中的使用

枚举常用于 switch 语句：

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY;
}

public void printDayType(Day day) {
    switch (day) {
        case MONDAY:
        case TUESDAY:
        case WEDNESDAY:
        case THURSDAY:
        case FRIDAY:
            System.out.println("工作日");
            break;
        case SATURDAY:
        case SUNDAY:
            System.out.println("周末");
            break;
    }
}
```

## 枚举的单例模式

枚举是实现单例模式最简单的方式：

```java
public enum Singleton {
    INSTANCE;

    // 可以添加方法和字段
    public void doSomething() {
        System.out.println("执行操作...");
    }
}

// 使用
Singleton singleton = Singleton.INSTANCE;
singleton.doSomething();
```

> **优势**：枚举单例自动支持序列化，并且线程安全，还能防止反射攻击和反序列化破坏。

## 枚举的常见用法

### 状态码定义

```java
public enum ResponseCode {
    SUCCESS(200, "成功"),
    NOT_FOUND(404, "资源未找到"),
    SERVER_ERROR(500, "服务器错误");

    private final int code;
    private final String message;

    ResponseCode(int code, String message) {
        this.code = code;
        this.message = message;
    }

    public int getCode() {
        return code;
    }

    public String getMessage() {
        return message;
    }
}
```

### 星期/月份等固定集合

```java
public enum Month {
    JANUARY(1), FEBRUARY(2), MARCH(3),

    JULY(7), AUGUST(8), SEPTEMBER(9),

    private final int value;

    Month(int value) {
        this.value = value;

    }

```

## 枚举 vs 常量类

| 特性        | 枚举        | 常量类（static final） |
| ----------- | ----------- | ---------------------- |
| 类型安全    | ✅ 是       | ❌ 否                  |
| 命名空间    | ✅ 有       | ❌ 无                  |
| 可遍历      | ✅ 可以     | ❌ 不可以              |
| 可添加方法  | ✅ 可以     | ❌ 不可以              |
| switch 支持 | ✅ 原生支持 | ⚠️ 需要常量表达式      |
| 序列化安全  | ✅ 安全     | ⚠️ 需要额外处理        |

```java
// ❌ 常量类：类型不安全，可以传入任意 int
public class StatusConstants {
    public static final int PENDING = 0;
    public static final int COMPLETED = 1;
}
public void process(int status) { ... }  // 可以传入任意值

// ✅ 枚举：类型安全，只能传入枚举值
public enum Status {
    PENDING, COMPLETED;
}
public void process(Status status) { ... }  // 只能传入 Status 枚举值
```

## 枚举 vs 普通 class

枚举类在编译后会被转换为特殊的 class 文件。通过对比可以清楚地看到枚举与普通类的区别。

### 源码对比

```java
// 枚举类源码
public enum Color {
    RED, GREEN, BLUE;
}

// 等价于编译后的 class（简化版）
public final class Color extends java.lang.Enum<Color> {
    // 每个枚举值都是 public static final 常量
    public static final Color RED = new Color("RED", 0);
    public static final Color GREEN = new Color("GREEN", 1);
    public static final Color BLUE = new Color("BLUE", 2);

    // 存储所有枚举值的数组
    private static final Color[] $VALUES = {RED, GREEN, BLUE};

    // 私有构造方法
    private Color(String name, int ordinal) {
        super(name, ordinal);
    }

    // values() 方法：返回所有枚举值的数组
    public static Color[] values() {
        return $VALUES.clone();
    }

    // valueOf() 方法：根据名称获取枚举值
    public static Color valueOf(String name) {
        return Enum.valueOf(Color.class, name);
    }
}
```

### 详细对比表

| 特性               | 枚举类                    | 普通 class                   |
| ------------------ | ------------------------- | ---------------------------- |
| **继承关系**       | 隐式继承 `java.lang.Enum` | 默认继承 `java.lang.Object`  |
| **实例数量**       | 固定数量，在编译时确定    | 可以创建任意数量             |
| **构造方法**       | 必须是 private            | 可以是 public/protected/默认 |
| **能否继承其他类** | ❌ 不能（已继承 Enum）    | ✅ 可以                      |
| **能否实现接口**   | ✅ 可以                   | ✅ 可以                      |
| **能否被继承**     | ❌ 不能（final 类）       | ✅ 可以（非 final 时）       |
| **内置方法**       | `values()`, `valueOf()`   | 无                           |
| **ordinal 属性**   | ✅ 有（序号）             | ❌ 无                        |
| **序列化**         | 自动支持                  | 需要手动实现                 |
| **switch 支持**    | ✅ 原生支持               | ❌ 不支持                    |

### 带字段的枚举编译结果

```java
// 源码
public enum Season {
    SPRING("春天"),
    SUMMER("夏天"),
    AUTUMN("秋天"),
    WINTER("冬天");

    private final String chineseName;

    Season(String chineseName) {
        this.chineseName = chineseName;
    }

    public String getChineseName() {
        return chineseName;
    }
}
```

编译后（简化版）：

```java
public final class Season extends java.lang.Enum<Season> {
    public static final Season SPRING;
    public static final Season SUMMER;
    public static final Season AUTUMN;
    public static final Season WINTER;

    private final String chineseName;  // 自定义字段
    private static final Season[] $VALUES;

    // 私有构造方法，接收 name 和 ordinal，以及自定义参数
    private Season(String name, int ordinal, String chineseName) {
        super(name, ordinal);
        this.chineseName = chineseName;
    }

    // 静态初始化块：初始化所有枚举值
    static {
        SPRING = new Season("SPRING", 0, "春天");
        SUMMER = new Season("SUMMER", 1, "夏天");
        AUTUMN = new Season("AUTUMN", 2, "秋天");
        WINTER = new Season("WINTER", 3, "冬天");
        $VALUES = new Season[]{SPRING, SUMMER, AUTUMN, WINTER};
    }

    public String getChineseName() {
        return chineseName;
    }

    public static Season[] values() {
        return $VALUES.clone();
    }

    public static Season valueOf(String name) {
        return Enum.valueOf(Season.class, name);
    }
}
```

### 关键点总结

1. **枚举类是 final 的**：不能被继承
2. **枚举值是单例的**：在静态初始化块中创建，JVM 保证线程安全
3. **构造方法参数**：编译器自动添加 `String name, int ordinal` 参数
4. **`$VALUES` 数组**：存储所有枚举值，`values()` 方法返回其克隆
5. **隐式继承 Enum**：所以不能再继承其他类

## 注意事项

1. **枚举不能继承其他类**：因为枚举已经隐式继承了 `java.lang.Enum`
2. **枚举可以 implements 接口**：可以实现一个或多个接口
3. **枚举值是单例的**：每个枚举值在 JVM 中只有一个实例
4. **枚举是线程安全的**：枚举值的创建由 JVM 保证线程安全
5. **枚举支持序列化**：Java 自动处理枚举的序列化和反序列化
