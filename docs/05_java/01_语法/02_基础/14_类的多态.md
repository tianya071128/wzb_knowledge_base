# 类的多态

多态（Polymorphism）是指同一个方法在不同对象上表现出不同的行为。多态是面向对象编程的核心特征，通过**父类引用指向子类对象**实现运行时动态绑定。

## 多态的表现形式

```java
Animal a1 = new Dog();
Animal a2 = new Cat();

a1.makeSound();  // 汪汪汪
a2.makeSound();  // 喵喵喵
```

同样是 `Animal` 类型的引用，调用同一个 `makeSound()` 方法，却表现出不同的行为。

## 实现多态的条件

1. **继承**：子类继承父类
2. **重写**：子类重写父类的方法
3. **向上转型**：父类引用指向子类对象

```java
public class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("汪汪汪");
    }
}

public class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("喵喵喵");
    }
}
```

```java
// 多态：父类引用指向子类对象
Animal a1 = new Dog();
Animal a2 = new Cat();

a1.makeSound();  // 汪汪汪（运行时决定调用 Dog 的 makeSound）
a2.makeSound();  // 喵喵喵（运行时决定调用 Cat 的 makeSound）
```

## 向上转型和向下转型

### 向上转型（子类 → 父类）

自动进行，安全：

```java
Dog dog = new Dog();
Animal animal = dog;   // 向上转型，自动进行

animal.makeSound();    // 汪汪汪（多态）
```

### 向下转型（父类 → 子类）

需要强制转换，可能不安全：

```java
Animal animal = new Dog();

Dog dog = (Dog) animal;    // ✅ 向下转型成功
dog.bark();                // 汪汪汪（Dog 特有方法）

Cat cat = (Cat) animal;    // ❌ 运行时 ClassCastException
```

### instanceof 判断

使用 `instanceof` 判断对象的实际类型，避免转换异常：

```java
Animal animal = new Dog();

if (animal instanceof Dog) {
    Dog dog = (Dog) animal;
    dog.bark();
}

// Java 16+ 模式匹配
if (animal instanceof Dog dog) {
    dog.bark();  // 自动转换
}
```

## 多态的应用

### 统一处理不同子类

```java
public class AnimalTest {
    public static void testSound(Animal animal) {
        animal.makeSound();  // 根据实际类型调用不同方法
    }

    public static void main(String[] args) {
        testSound(new Dog());   // 汪汪汪
        testSound(new Cat());   // 喵喵喵
        testSound(new Bird());  // 叽叽叽
    }
}
```

### 集合中使用多态

```java
Animal[] animals = {
    new Dog(),
    new Cat(),
    new Bird()
};

for (Animal animal : animals) {
    animal.makeSound();  // 每个对象表现出不同的行为
}
```

### 策略模式

```java
public interface Payment {
    void pay(double amount);
}

public class Alipay implements Payment {
    @Override
    public void pay(double amount) {
        System.out.println("使用支付宝支付：" + amount);
    }
}

public class WechatPay implements Payment {
    @Override
    public void pay(double amount) {
        System.out.println("使用微信支付：" + amount);
    }
}

public class Order {
    private Payment payment;

    public Order(Payment payment) {
        this.payment = payment;
    }

    public void checkout(double amount) {
        payment.pay(amount);  // 多态：不同支付方式有不同实现
    }
}
```

```java
Order order1 = new Order(new Alipay());
Order order2 = new Order(new WechatPay());

order1.checkout(100);  // 使用支付宝支付：100
order2.checkout(100);  // 使用微信支付：100
```

## 多态的限制

### 只能调用父类声明的方法

向上转型后，只能调用父类中声明的方法，不能调用子类特有方法：

```java
Animal animal = new Dog();

animal.makeSound();  // ✅ 父类有声明
// animal.bark();    // ❌ 编译错误：Animal 中没有 bark 方法
```

### 成员字段、静态方法和字段不参与多态

多态只针对方法，成员字段、静态方法和字段不存在多态：

- **方法：编译看左边，运行看右边**（多态）
- **成员字段、静态方法和字段：编译看左边，运行也看左边；永远看引用的声明类型**

```java
public class Animal {
    String name = "动物";
}

public class Dog extends Animal {
    String name = "狗";
}

Animal a = new Dog();
System.out.println(a.name);  // 动物（字段不参与多态，访问的是父类字段）
```

## 动态绑定 vs 静态绑定

| 对比项 | 动态绑定（运行时） | 静态绑定（编译时） |
| --- | --- | --- |
| 对象 | 实例方法（重写） | 静态方法、私有方法、构造方法 |
| 时机 | 运行时根据对象实际类型决定 | 编译时根据引用类型决定 |
| 多态 | 支持 | 不支持 |

```java
Animal a = new Dog();
a.makeSound();       // 动态绑定：运行时调用 Dog 的 makeSound
Animal.staticMethod(); // 静态绑定：编译时确定调用 Animal 的静态方法
```
