# 类的方法

方法（Method）是类中定义的函数，用于封装可复用的行为逻辑。方法包含**声明**（返回类型、方法名、参数列表）和**方法体**。

## 基本语法

```java
[修饰符] 返回类型 方法名(参数列表) {
    // 方法体
    return 返回值;  // 如果返回类型不是 void，则必须有返回值
}
```

```java
public int add(int a, int b) {
    return a + b;
}
```

### 无参无返回值

```java
public void sayHello() {
    System.out.println("Hello!");
}
```

### 有参有返回值

```java
public String greet(String name) {
    return "你好，" + name;
}
```

### void 方法

`void` 表示方法没有返回值：

```java
public void printInfo(String name, int age) {
    System.out.println("姓名：" + name + "，年龄：" + age);
    return;  // 可省略，用于提前退出方法
}
```

## 可变参数（varargs）

用 `...` 表示可变数量的参数，在方法内部被当作数组处理：

```java
public int sum(int... nums) {
    int total = 0;
    for (int n : nums) {
        total += n;
    }
    return total;
}

sum();            // 0
sum(1, 2, 3);     // 6
sum(1, 2, 3, 4, 5); // 15
```

> **注意**：可变参数必须是参数列表的**最后一个**，且每个方法只能有一个可变参数。

## 静态方法

`static` 方法属于类本身，通过类名直接调用，无需创建对象：

```java
public class MathUtil {
    public static int max(int a, int b) {
        return a > b ? a : b;
    }
}

MathUtil.max(3, 5);  // 5（通过类名调用）
```

> **注意**：静态方法中不能使用 `this`，也不能直接访问非静态成员。

## 方法的修饰符

### 访问修饰符

| 修饰符 | 同类 | 同包 | 子类 | 其他包 |
| --- | --- | --- | --- | --- |
| `private` | ✅ | ❌ | ❌ | ❌ |
| `default`默认（不写） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

```java
public class Student {
    private void checkName(String name) { ... }    // 只能本类调用
    void study() { ... }                           // 同包可调用
    protected void printResult() { ... }           // 同包 + 子类可调用
    public String getName() { ... }                // 任何地方可调用
}
```

### static 修饰符

使方法成为类方法，通过类名调用：

```java
public static int add(int a, int b) {
    return a + b;
}
```

### final 修饰符

`final` 方法不能被子类重写：

```java
public class Base {
    public final void doSomething() {
        System.out.println("不能被子类重写");
    }
}
```

### abstract 修饰符

`abstract` 方法只有声明没有方法体，必须在抽象类或接口中定义：

```java
public abstract class Shape {
    public abstract double getArea();  // 子类必须实现
}
```

### synchronized 修饰符

`synchronized` 方法在多线程环境下保证同一时刻只有一个线程可以执行该方法：

```java
public class BankAccount {
    private double balance;

    public synchronized void deposit(double amount) {
        balance += amount;
    }
}
```

## 方法调用

### 通过对象调用

```java
Student stu = new Student();
stu.study();
```

### 通过类名调用（静态方法）

```java
MathUtil.max(3, 5);
```

### 方法内调用其他方法

```java
public class Student {
    public void learn() {
        study();           // 调用同类其他方法
        this.study();      // 等价写法
    }

    public void study() {
        System.out.println("正在学习");
    }
}
```

## 递归

方法可以调用自身，用于解决可以分解为子问题的问题：

```java
public int factorial(int n) {
    if (n <= 1) {
        return 1;    // 递归终止条件
    }
    return n * factorial(n - 1);  // 递归调用
}

factorial(5);  // 120
```

> **注意**：递归必须有终止条件，否则会导致栈溢出（`StackOverflowError`）。
