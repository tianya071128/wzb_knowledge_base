# 数组类型

数组是存储**相同类型**数据的固定大小的有序集合。数组属于引用类型。

## 声明和初始化

### 一维数组

```java
// 方式一：声明后初始化
int[] arr1 = new int[5];             // 创建长度为 5 的 int 数组，默认值为 0

// 方式二：声明时直接赋值
int[] arr2 = {1, 2, 3, 4, 5};

// 方式三：使用 new 并指定初始值
int[] arr3 = new int[]{1, 2, 3, 4, 5};
```

> **注意**：`int arr[]` 也是合法语法（C 风格），但推荐使用 `int[] arr`（Java 风格）。

### 二维数组

```java
// 规则二维数组（3 行 4 列）
int[][] matrix = new int[3][4];

// 直接赋值
int[][] matrix2 = {
    {1, 2, 3},
    {4, 5, 6}
};

// 不规则数组（每行长度可以不同）
int[][] jagged = new int[3][];
jagged[0] = new int[2];
jagged[1] = new int[4];
jagged[2] = new int[3];
```



## 数组的默认值

数组作为成员变量时默认值为 `null`；创建数组后，各元素会自动赋予对应类型的默认值：

| 元素类型                       | 元素默认值 |
| ------------------------------ | ---------- |
| `byte`、`short`、`int`、`long` | `0`        |
| `float`                        | `0.0f`     |
| `double`                       | `0.0d`     |
| `char`                         | `'\u0000'` |
| `boolean`                      | `false`    |
| 引用类型                       | `null`     |

```java
int[] nums = new int[3];        // {0, 0, 0}
double[] prices = new double[2]; // {0.0, 0.0}
String[] names = new String[3];  // {null, null, null}
```

## 数组的特点

- **长度固定**：创建后长度不可变，无法动态增减元素
- **类型统一**：同一数组只能存储同一类型的元素
- **有序**：元素按索引有序排列，支持随机访问
- **引用类型**：数组是对象，存储在堆中，变量保存的是引用

## 继承关系

**数组直接父类是 Object**，可以调用 Object 的方法：`equals()`、`hashCode()`、`getClass()`、`toString()`。

## 数组的操作

数组直接继续 `Object`, 可以调用 `Object` 的相关方法

### 访问和修改元素

通过下标（索引）访问元素，下标从 `0` 开始：

```java
int[] arr = {10, 20, 30, 40, 50};

int first = arr[0];      // 10
int last = arr[4];       // 50
int len = arr.length;    // 5（数组长度）

arr[2] = 99;             // 修改第三个元素：{10, 20, 99, 40, 50}
```

> **注意**：下标范围是 `0` 到 `length - 1`，超出会抛出 `ArrayIndexOutOfBoundsException`。

### 遍历数组

#### for 循环

```java
int[] arr = {10, 20, 30, 40, 50};

for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

#### 增强 for 循环（for-each）

```java
for (int val : arr) {
    System.out.println(val);
}
```

#### 二维数组遍历

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
```
