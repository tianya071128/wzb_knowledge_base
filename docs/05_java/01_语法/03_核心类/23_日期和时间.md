# 日期和时间

Java 8 引入了全新的日期时间 API（`java.time` 包），解决了旧版 `Date` 和 `Calendar` 的诸多问题。

## 时间和时区知识

### 时间的基本概念

- **UTC（协调世界时）**：全球时间标准，以前称为 GMT（格林威治标准时间）
- **时区（Time Zone）**：地球上使用同一标准时间的区域，如 `Asia/Shanghai`、`America/New_York`
- **时区偏移（Zone Offset）**：与 UTC 的时间差，如 `+08:00`（中国）、`-05:00`（纽约）
- **夏令时（DST）**：部分地区夏季会将时间调快 1 小时

### 时间戳

- **时间戳（Timestamp）**：从 1970-01-01 00:00:00 UTC 到现在的毫秒数或秒数
- 时间戳与时区无关，是全球统一的

### 日期时间的组成

```
日期时间 = 日期（年/月/日） + 时间（时/分/秒/纳秒） + 时区
```

## Java 日期时间 API 概览

| 类                  | 说明             | 包含信息                   |
| ------------------- | ---------------- | -------------------------- |
| `LocalDate`         | 本地日期         | 年、月、日（无时区）       |
| `LocalTime`         | 本地时间         | 时、分、秒、纳秒（无时区） |
| `LocalDateTime`     | 本地日期时间     | 日期 + 时间（无时区）      |
| `ZonedDateTime`     | 带时区的日期时间 | 日期 + 时间 + 时区         |
| `Instant`           | 时间戳           | UTC 时间点                 |
| `ZoneId`            | 时区 ID          | 如 `Asia/Shanghai`         |
| `ZoneOffset`        | 时区偏移         | 如 `+08:00`                |
| `DateTimeFormatter` | 日期时间格式化器 | 格式化与解析               |
| `Period`            | 日期间隔         | 年、月、日                 |
| `Duration`          | 时间间隔         | 时、分、秒、纳秒           |

## 类之间的关系

```
Instant（时间戳）
    ↓ 结合时区
ZonedDateTime（带时区的日期时间）
    ↓ 去掉时区
LocalDateTime（本地日期时间）
    ↓ 拆分
LocalDate（日期） + LocalTime（时间）
```

## 选择指南

| 场景                       | 推荐类          |
| -------------------------- | --------------- |
| 只需要日期                 | `LocalDate`     |
| 只需要时间                 | `LocalTime`     |
| 需要日期和时间，不关心时区 | `LocalDateTime` |
| 需要处理时区               | `ZonedDateTime` |
| 需要记录事件发生的精确时刻 | `Instant`       |
| 计算两个日期之间的差       | `Period`        |
| 计算两个时间之间的差       | `Duration`      |

> **建议**：优先使用 Java 8+ 的 `java.time` API，避免使用旧的 `Date` 和 `Calendar`。
