# 包装类型

Java 为每个基本数据类型都提供了对应的包装类（Wrapper Class），使基本类型可以像对象一样使用。

## 基本类型与包装类对应关系

| 基本类型  | 包装类      | 字节数 | 取值范围       |
| --------- | ----------- | ------ | -------------- |
| `byte`    | `Byte`      | 1      | -128 ~ 127     |
| `short`   | `Short`     | 2      | -32768 ~ 32767 |
| `int`     | `Integer`   | 4      | -2^31 ~ 2^31-1 |
| `long`    | `Long`      | 8      | -2^63 ~ 2^63-1 |
| `float`   | `Float`     | 4      | IEEE 754       |
| `double`  | `Double`    | 8      | IEEE 754       |
| `char`    | `Character` | 2      | Unicode        |
| `boolean` | `Boolean`   | -      | true / false   |

## 自动装箱与拆箱

```java
// 自动装箱：基本类型 → 包装类
Integer a = 100;           // 等价于 Integer.valueOf(100)

// 自动拆箱：包装类 → 基本类型
int b = a;                 // 等价于 a.intValue()
```

## 缓存机制

Integer、Short、Long、Byte 等类对 -128 ~ 127 范围内的值进行了缓存：

```java
Integer a = 100;
Integer b = 100;
System.out.println(a == b);  // true（使用缓存）

Integer c = 200;
Integer d = 200;
System.out.println(c == d);  // false（超出缓存范围）
```

> **注意**：比较包装类的值时，应使用 `equals()` 而非 `==`。
