# 集合

Java 集合框架（Collections Framework）提供了一套性能优良、设计精良的接口和类，用于存储和操作数据集合。

## 集合框架概览

```
Collection（接口）
    ├─ List（接口）：有序、可重复
    │   ├─ ArrayList
    │   ├─ LinkedList
    │   └─ Vector
    ├─ Set（接口）：无序、不可重复
    │   ├─ HashSet
    │   ├─ LinkedHashSet
    │   └─ TreeSet
    └─ Queue（接口）：队列
        ├─ LinkedList
        ├─ PriorityQueue
        └─ Deque（接口）

Map（接口）：键值对
    ├─ HashMap
    ├─ LinkedHashMap
    ├─ TreeMap
    └─ Hashtable
```

## 核心接口

| 接口    | 特点                 | 常用实现                  |
| ------- | -------------------- | ------------------------- |
| `List`  | 有序、可重复、有索引 | ArrayList、LinkedList     |
| `Set`   | 无序、不可重复       | HashSet、TreeSet          |
| `Queue` | 先进先出（FIFO）     | LinkedList、PriorityQueue |
| `Map`   | 键值对、键唯一       | HashMap、TreeMap          |

## 选择指南

| 场景                 | 推荐类       |
| -------------------- | ------------ |
| 需要有序、按索引访问 | `ArrayList`  |
| 频繁插入/删除        | `LinkedList` |
| 需要去重             | `HashSet`    |
| 需要排序             | `TreeSet`    |
| 键值对存储           | `HashMap`    |
| 需要排序的键值对     | `TreeMap`    |
