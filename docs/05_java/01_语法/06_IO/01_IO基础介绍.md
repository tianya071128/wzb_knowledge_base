# IO 基础介绍

## 什么是 IO

IO（Input/Output，输入/输出）是指程序与外部设备之间的数据传输。在 Java 中，IO 指的是通过 `java.io` 包提供的类和接口，对文件、网络、内存等数据源进行读取和写入操作。

- **输入（Input）**：数据从外部（文件、网络、键盘等）读入到程序中。
- **输出（Output）**：数据从程序写到外部（文件、网络、控制台等）。

## IO 的分类

按照不同的维度，Java IO 可以分为以下几类：

### 1. 按数据流向划分

- **输入流**：只能从中读取数据，如 `InputStream`、`Reader`。
- **输出流**：只能向其写入数据，如 `OutputStream`、`Writer`。

### 2. 按处理数据单位划分

- **字节流**：以字节（8 位）为单位处理数据，适合处理图片、音视频等二进制数据。抽象基类为 `InputStream` 和 `OutputStream`。
- **字符流**：以字符（16 位）为单位处理数据，适合处理文本数据。抽象基类为 `Reader` 和 `Writer`。

### 3. 按功能角色划分

- **节点流**：直接从数据源（文件、数组、管道等）读写的流，如 `FileInputStream`、`FileReader`。
- **处理流（包装流）**：对一个已存在的流进行包装，提供缓冲、转换等增强功能，如 `BufferedInputStream`、`InputStreamReader`。

## IO 流的核心类体系

`java.io` 包中最重要的四个抽象基类如下：

| 抽象基类 | 说明 | 常见实现类 |
| --- | --- | --- |
| `InputStream` | 字节输入流 | `FileInputStream`、`BufferedInputStream`、`ObjectInputStream` |
| `OutputStream` | 字节输出流 | `FileOutputStream`、`BufferedOutputStream`、`ObjectOutputStream` |
| `Reader` | 字符输入流 | `FileReader`、`BufferedReader`、`InputStreamReader` |
| `Writer` | 字符输出流 | `FileWriter`、`BufferedWriter`、`OutputStreamWriter` |

```java
// 字节流读取文件示例
try (FileInputStream fis = new FileInputStream("data.txt")) {
    int b;
    while ((b = fis.read()) != -1) {
        System.out.print((char) b);
    }
}

// 字符流读取文件示例（带缓冲）
try (BufferedReader br = new BufferedReader(new FileReader("data.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}
```

## IO 的基本使用模式

无论使用哪种流，读取数据的模式基本一致：

1. 创建流对象，建立数据通道；
2. 循环读写，直到数据结束（读方法返回 `-1` 或 `null`）；
3. 关闭流，释放资源（推荐使用 try-with-resources 自动关闭）。

```java
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    fos.write("Hello IO".getBytes());
}
```

## 新旧 IO

除了传统的 `java.io` 包（BIO），Java 还提供了：

- **NIO（New IO，Java 1.4）**：基于通道（Channel）和缓冲区（Buffer）的 IO，支持非阻塞模式，位于 `java.nio` 包。
- **NIO.2（Java 7）**：引入 `java.nio.file` 包，提供 `Path`、`Files` 等工具类，大幅简化了文件操作。

传统 `java.io` 是学习 Java IO 的基础，后续章节将围绕字节流、字符流及其常用实现类展开。
