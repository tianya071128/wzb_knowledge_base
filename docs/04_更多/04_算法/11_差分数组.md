# 差分数组

差分数组通过记录相邻元素的差值，将区间内所有元素统一加减一个值的操作，转化为对两个端点的修改。它适合多次区间更新、最后统一查询结果的场景，可以看作前缀和的逆操作。

## 构造差分数组

对于长度为 `n` 的数组 `a`：

- `diff[0] = a[0]`。
- `diff[i] = a[i] - a[i - 1]`（`1 <= i < n`）。

例如，`a = [1, 3, 6, 10]` 对应 `diff = [1, 2, 3, 4]`。对 `diff` 求前缀和即可还原 `a`。

## 区间修改

将闭区间 `[l, r]` 内的所有元素加上 `k`，只需：

```js
diff[l] += k;
if (r + 1 < n) diff[r + 1] -= k;
```

区间内部相邻元素同时增加 `k`，差值不变；只有区间起点与区间结束后的差值发生变化。因此单次更新的时间复杂度为 `O(1)`。

也可以额外增加一个哨兵位置，使 `diff` 长度为 `n + 1`，这样可以直接操作 `diff[r + 1]`；还原时只读取前 `n` 项。

## 代码示例

```js
function applyRangeUpdates(nums, updates) {
  const n = nums.length;
  const diff = new Array(n + 1).fill(0);
  for (let i = 0; i < n; i++) {
    diff[i] = nums[i] - (i === 0 ? 0 : nums[i - 1]);
  }

  for (const [l, r, k] of updates) {
    diff[l] += k;
    diff[r + 1] -= k;
  }

  const result = [];
  let sum = 0;
  for (let i = 0; i < n; i++) {
    sum += diff[i];
    result.push(sum);
  }
  return result;
}

applyRangeUpdates([1, 2, 3, 4], [[1, 2, 5]]); // [1, 7, 8, 4]
```

示例要求每次更新满足 `0 <= l <= r < n`。对 `m` 次区间更新，总时间复杂度为 `O(n + m)`，额外空间复杂度为 `O(n)`。

## 应用场景

- 批量执行区间加减，最后输出数组。
- 航班预订、拼车等区间累计计数问题。

如果需要交替进行区间更新和查询，一般考虑树状数组或线段树。
