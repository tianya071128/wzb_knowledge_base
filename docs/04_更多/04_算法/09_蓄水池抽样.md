# 蓄水池抽样

蓄水池抽样（Reservoir Sampling）用于从总量未知的数据流中随机抽取 `k` 个样本。它只需遍历一次数据，并保存至多 `k` 个元素；当已读取 `n` 个元素且 `n >= k` 时，每个元素进入当前样本的概率都是 `k / n`。

## 基本原理

1. 将前 `k` 个元素放入蓄水池。
2. 读取第 `i` 个元素时（`i > k`，从 `1` 开始计数），在 `[0, i - 1]` 内均匀生成随机整数 `r`。
3. 如果 `r < k`，用当前元素替换蓄水池中下标为 `r` 的元素；否则跳过。

新元素以 `k / i` 的概率进入样本，已选元素则可能被替换，从而保持等概率抽样。

## 代码示例

下面的实现支持数组及同步生成器等可迭代对象，`k` 必须是非负整数。

```js
function reservoirSampling(dataSource, k) {
  if (!Number.isInteger(k) || k < 0) {
    throw new RangeError('抽样数量必须是非负整数');
  }
  if (k === 0) return [];

  const reservoir = [];
  let count = 0;

  for (const value of dataSource) {
    count++;
    if (count <= k) {
      reservoir.push(value);
    } else {
      const r = Math.floor(Math.random() * count);
      if (r < k) reservoir[r] = value;
    }
  }
  return reservoir;
}

const sample = reservoirSampling([1, 2, 3, 4, 5, 6], 3);
console.log(sample); // 随机返回 3 个样本
```

数据不足 `k` 个时返回全部元素。遍历 `n` 个元素的时间复杂度为 `O(n)`，额外空间复杂度为 `O(k)`。

## 应用场景

- 从不能一次性载入内存的大文件中随机抽取记录。
- 从数据流中维护固定大小的随机样本。
- 对无法事先确定长度的链表或可迭代对象进行抽样。
