# 辗转相除法

辗转相除法（Euclidean Algorithm），也叫欧几里得算法，用于快速求两个整数的最大公约数（GCD）。核心公式是：

```text
gcd(a, b) = gcd(b, a % b)
```

## 基本原理

若一个数能够同时整除 `a` 和 `b`，它也能够整除 `a % b`；反过来也成立。因此，`a` 与 `b` 的公约数和 `b` 与余数的公约数相同。

不断用除数和余数替换原来的两个数，直到余数为 `0`，此时的除数就是最大公约数。

例如：`gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6`。

## 代码示例

```js
function gcd(a, b) {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return a;
}

gcd(48, 18); // 6
```

示例适用于 JavaScript 安全整数；`gcd(a, 0) = |a|`，代码约定 `gcd(0, 0) = 0`。对两个正整数，时间复杂度为 `O(log(min(a, b)))`，额外空间复杂度为 `O(1)`。

## 应用场景

- 求最大公约数、约分分数。
- 求两个正整数的最小公倍数：`lcm(a, b) = a / gcd(a, b) * b`。
