# 摩尔投票法

摩尔投票法（Boyer-Moore Voting Algorithm）用于查找数组中的多数元素，即出现次数大于 `⌊n / 2⌋` 的元素。它通过抵消不同元素，只维护一个候选元素和计数器，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 基本原理

1. 初始化计数器 `count = 0`。
2. 遍历数组：当计数器为 `0` 时，将当前元素设为候选元素；当前元素与候选元素相同则计数加一，否则减一。
3. 如果题目不保证多数元素存在，需要再次遍历数组，确认候选元素的出现次数大于 `⌊n / 2⌋`。

不同元素两两抵消后，真正占据一半以上的元素一定能够留下；但留下的候选元素不一定是多数元素，因此不能省略必要的验证。

## 代码示例

```js
function majorityElement(nums) {
  let candidate;
  let count = 0;

  for (const num of nums) {
    if (count === 0) candidate = num;
    count += num === candidate ? 1 : -1;
  }

  let occurrences = 0;
  for (const num of nums) {
    if (num === candidate) occurrences++;
  }
  return occurrences > nums.length / 2 ? candidate : undefined;
}

majorityElement([2, 2, 1, 1, 1, 2, 2]); // 2
```

## 应用场景

- 查找出现次数超过数组长度一半的元素。
- 查找出现次数超过 `n / 3` 的元素时，可扩展为维护两个候选元素，并分别验证出现次数。
