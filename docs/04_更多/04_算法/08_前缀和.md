# 前缀和

前缀和通过预先累计数组或矩阵中的元素之和，将重复的区间求和转化为几个前缀和之间的加减运算。它适合数据不变、需要多次查询区间和的场景。

## 一维前缀和

定义 `prefixSum[i]` 为前 `i` 个元素之和，使用长度为 `n + 1` 的数组，并令 `prefixSum[0] = 0`：

- 构建：`prefixSum[i + 1] = prefixSum[i] + nums[i]`。
- 查询闭区间 `[l, r]`：`prefixSum[r + 1] - prefixSum[l]`。

```js
function calculatePrefixSum(nums) {
  const prefixSum = new Array(nums.length + 1).fill(0);
  for (let i = 0; i < nums.length; i++) {
    prefixSum[i + 1] = prefixSum[i] + nums[i];
  }
  return prefixSum;
}

const prefixSum = calculatePrefixSum([1, 2, 3, 4]);
prefixSum[4] - prefixSum[1]; // 区间 [1, 3] 的和为 9
```

预处理时间与空间复杂度均为 `O(n)`，单次查询为 `O(1)`。

## 二维前缀和

定义 `sum[i][j]` 为矩阵前 `i` 行、前 `j` 列的元素之和，额外增加一行、一列零作为边界。

```js
function calculate2DPrefixSum(matrix) {
  const rows = matrix.length;
  const cols = matrix[0]?.length ?? 0;
  const sum = Array.from({ length: rows + 1 }, () =>
    new Array(cols + 1).fill(0)
  );

  for (let i = 1; i <= rows; i++) {
    for (let j = 1; j <= cols; j++) {
      sum[i][j] =
        sum[i - 1][j] +
        sum[i][j - 1] -
        sum[i - 1][j - 1] +
        matrix[i - 1][j - 1];
    }
  }
  return sum;
}
```

查询左上角为 `(r1, c1)`、右下角为 `(r2, c2)` 的闭合矩形区域（原矩阵下标从 `0` 开始）：

```js
sum[r2 + 1][c2 + 1] -
  sum[r1][c2 + 1] -
  sum[r2 + 1][c1] +
  sum[r1][c1];
```

减去上方和左侧区域后，左上角重叠区域被减了两次，需要加回一次。预处理时间与空间复杂度均为 `O(mn)`，单次查询为 `O(1)`。

## 应用场景

- 一维数组的多次区间求和。
- 二维矩阵的多次区域求和。
- 配合哈希表统计满足特定和条件的子数组。
