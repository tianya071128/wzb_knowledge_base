# 二分查找

二分查找（Binary Search），也叫二分搜索，通过比较目标值与搜索区间的中间元素，每次排除一半不可能包含答案的范围。它通常用于有序数组，时间复杂度为 `O(log n)`，迭代实现的额外空间复杂度为 `O(1)`。

以下示例均针对按升序排列的数值数组。

## 基本原理

1. 用 `left` 和 `right` 表示当前搜索区间的左右边界。
2. 计算中间位置 `mid`，比较 `nums[mid]` 与目标值 `target`。
3. 中间元素偏小，搜索右半部分；偏大，搜索左半部分；相等则找到目标。
4. 重复以上过程，直到找到目标或搜索区间为空。

例如，在 `[1, 3, 5, 7, 9]` 中查找 `7`：先比较中间的 `5`，排除左半部分，再在 `[7, 9]` 中找到 `7`。

## 查找目标元素

使用闭区间 `[left, right]`，初始范围为 `[0, nums.length - 1]`。当 `left > right` 时，区间为空。

```js
function binarySearch(nums, target) {
  let left = 0;
  let right = nums.length - 1;

  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) {
      left = mid + 1;
    } else {
      right = mid - 1;
    }
  }
  return -1;
}

binarySearch([1, 3, 5, 7, 9], 7); // 3
binarySearch([1, 3, 5, 7, 9], 4); // -1
binarySearch([], 7); // -1
```

如果数组包含重复元素，该实现返回某个匹配位置，不保证是第一个或最后一个。

## 查找左右边界

有重复元素时，标准二分查找只能找到某个匹配位置。如果要找第一个或最后一个匹配位置，可以分别查找下界和上界。

可以把边界查找理解为：按某个条件把有序数组分成两段，前一段都不满足条件，后一段都满足条件，边界就是**第一个满足条件的位置**。

以 `nums = [1, 2, 2, 2, 4]`、`target = 2` 为例：

| 下标 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 元素 | 1 | 2 | 2 | 2 | 4 |
| `nums[i] >= 2` | 否 | 是 | 是 | 是 | 是 |
| `nums[i] > 2` | 否 | 否 | 否 | 否 | 是 |

- 下界条件是 `nums[i] >= target`，第一个满足的位置是 `1`。
- 上界条件是 `nums[i] > target`，第一个满足的位置是 `4`。
- 两者之间的 `[1, 4)` 就是所有等于目标值的元素。

下面统一使用左闭右开区间 `[left, right)`，初始 `right = nums.length`。这样返回值的范围是 `[0, n]`，其中 `n` 表示所有元素都不满足条件。循环结束时 `left === right`，该位置就是边界。

### 下界：第一个大于或等于目标值的位置

```js
function lowerBound(nums, target) {
  let left = 0;
  let right = nums.length;

  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] < target) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }
  return left;
}
```

当 `nums[mid] >= target` 时，中间位置仍可能是答案，因此使用 `right = mid` 保留它，并继续向左收缩；当 `nums[mid] < target` 时，中间位置及其左侧都不可能是答案，因此使用 `left = mid + 1`。

循环过程中始终满足：

- `[0, left)` 中的元素都小于 `target`。
- `[right, n)` 中的元素都大于或等于 `target`。

当 `left === right` 时，两段之间没有待确认的元素，`left` 就是第一个大于或等于目标值的位置。

以 `lowerBound([1, 2, 2, 2, 4], 2)` 为例：

| 搜索区间 | `mid` | `nums[mid]` | 判断 | 下一步 |
| --- | --- | --- | --- | --- |
| `[0, 5)` | 2 | 2 | `2 >= 2` | `right = 2` |
| `[0, 2)` | 1 | 2 | `2 >= 2` | `right = 1` |
| `[0, 1)` | 0 | 1 | `1 < 2` | `left = 1` |
| `[1, 1)` | - | - | 区间为空 | 返回 `1` |

若所有元素都小于目标值，返回 `nums.length`，表示应插入数组末尾，而不是有效元素下标。

### 上界：第一个大于目标值的位置

```js
function upperBound(nums, target) {
  let left = 0;
  let right = nums.length;

  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] <= target) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }
  return left;
}
```

与下界的区别只在于相等时的处理：上界要跳过所有等于目标值的元素，所以 `nums[mid] === target` 时也执行 `left = mid + 1`，继续向右搜索。

循环过程中始终满足：

- `[0, left)` 中的元素都小于或等于 `target`。
- `[right, n)` 中的元素都大于 `target`。

以 `upperBound([1, 2, 2, 2, 4], 2)` 为例：

| 搜索区间 | `mid` | `nums[mid]` | 判断 | 下一步 |
| --- | --- | --- | --- | --- |
| `[0, 5)` | 2 | 2 | `2 <= 2` | `left = 3` |
| `[3, 5)` | 4 | 4 | `4 > 2` | `right = 4` |
| `[3, 4)` | 3 | 2 | `2 <= 2` | `left = 4` |
| `[4, 4)` | - | - | 区间为空 | 返回 `4` |

若没有元素大于目标值，返回 `nums.length`。

### 返回值速查

仍以 `nums = [1, 2, 2, 2, 4]` 为例：

| `target` | `lowerBound` | `upperBound` | 说明 |
| --- | --- | --- | --- |
| `0` | `0` | `0` | 所有元素都大于目标值 |
| `2` | `1` | `4` | 目标值存在，出现范围为 `[1, 3]` |
| `3` | `4` | `4` | 目标值不存在，两者相等，都是插入位置 |
| `5` | `5` | `5` | 所有元素都小于目标值，返回 `n` |

由此可以得到：

- `lowerBound === upperBound` 时，数组中不存在目标值。
- `upperBound - lowerBound` 是目标值的出现次数。
- 两个函数的返回值都可能等于 `nums.length`，访问 `nums[index]` 前要先检查是否越界。

### 查找重复元素的范围

```js
const nums = [1, 2, 2, 2, 4];
const target = 2;
const first = lowerBound(nums, target);
const end = upperBound(nums, target);

const range =
  first < nums.length && nums[first] === target
    ? [first, end - 1]
    : [-1, -1];

console.log(range); // [1, 3]
console.log(end - first); // 目标值出现 3 次
```

`lowerBound` 返回的是候选位置，需要检查是否越界以及该位置是否等于目标值；不能直接将它视为查找成功。目标值存在时，最后一次出现的位置为 `upperBound(nums, target) - 1`。

## 边界查找的变种

很多边界问题都可以转化为“第一个满足条件的位置”，再根据需要减一或比较相邻元素。下面的示例复用前面的 `lowerBound` 和 `upperBound`。

| 需求 | 写法 | 不存在时 |
| --- | --- | --- |
| 第一个 `>= target` | `lowerBound(nums, target)` | `n` |
| 第一个 `> target` | `upperBound(nums, target)` | `n` |
| 最后一个 `< target` | `lowerBound(nums, target) - 1` | `-1` |
| 最后一个 `<= target` | `upperBound(nums, target) - 1` | `-1` |
| 第一个 `=== target` | `lowerBound`，再检查是否相等 | `-1` |
| 最后一个 `=== target` | `upperBound - 1`，再检查是否相等 | `-1` |

### 搜索插入位置

在有序数组中插入目标值，并保持数组有序。如果目标值已存在，插入到第一个相同元素之前，这正好是下界：

```js
function searchInsert(nums, target) {
  return lowerBound(nums, target);
}

searchInsert([1, 3, 5, 6], 5); // 2
searchInsert([1, 3, 5, 6], 2); // 1
searchInsert([1, 3, 5, 6], 7); // 4
```

如果希望插入到相同元素之后，使用 `upperBound`。

### 最后一个小于或小于等于目标值的位置

“最后一个小于 `target`”的下一个位置，就是“第一个大于或等于 `target`”的位置，因此只需将下界减一。同理，“最后一个小于或等于 `target`”等于上界减一。

```js
function lastLess(nums, target) {
  return lowerBound(nums, target) - 1;
}

function lastLessOrEqual(nums, target) {
  return upperBound(nums, target) - 1;
}

const nums = [1, 2, 2, 2, 4];
lastLess(nums, 2); // 0
lastLessOrEqual(nums, 2); // 3
lastLess(nums, 1); // -1，不存在小于 1 的元素
```

这类写法常用于查找“不超过某个值的最大元素”，例如按分数线查找最后一个达标档位、按时间查找某个时刻之前的最后一条记录。

### 统计落在区间内的元素个数

统计值在闭区间 `[low, high]` 内的元素个数：

- `lowerBound(nums, low)` 是第一个大于或等于 `low` 的位置。
- `upperBound(nums, high)` 是第一个大于 `high` 的位置。
- 两者之差就是区间内的元素个数。

```js
function countInRange(nums, low, high) {
  return Math.max(0, upperBound(nums, high) - lowerBound(nums, low));
}

countInRange([1, 2, 2, 2, 4, 6], 2, 4); // 4
countInRange([1, 2, 2, 2, 4, 6], 3, 3); // 0
```

当 `low > high` 时，差值不会大于 `0`，`Math.max` 用于统一返回 `0`。如果需要统计开区间或半开区间，只需将对应端点在 `lowerBound` 和 `upperBound` 之间切换。

### 查找最接近目标值的元素

下界位置 `i` 是第一个大于或等于目标值的元素，最接近目标值的元素只可能是 `nums[i - 1]` 或 `nums[i]`：

```js
function findClosest(nums, target) {
  if (nums.length === 0) return -1;

  const i = lowerBound(nums, target);
  if (i === 0) return 0;
  if (i === nums.length) return nums.length - 1;

  // 距离相同时，返回较小元素的下标
  return target - nums[i - 1] <= nums[i] - target ? i - 1 : i;
}

findClosest([1, 4, 6, 9], 5); // 1，4 和 6 的距离相同，取较小值
findClosest([1, 4, 6, 9], 8); // 3
findClosest([1, 4, 6, 9], 20); // 3
```

需要注意 `i` 为 `0` 或 `nums.length` 时，只有一侧存在候选元素。

### 降序数组中的边界

二分的关键是判断条件在数组上具有单调性，而不是必须使用升序数组。对于降序数组，只需改变比较方向：

```js
// 降序数组：第一个小于或等于 target 的位置
function lowerBoundDesc(nums, target) {
  let left = 0;
  let right = nums.length;

  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] > target) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }
  return left;
}

// 降序数组：第一个小于 target 的位置
function upperBoundDesc(nums, target) {
  let left = 0;
  let right = nums.length;

  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] >= target) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }
  return left;
}

const desc = [9, 7, 7, 3, 1];
lowerBoundDesc(desc, 7); // 1
upperBoundDesc(desc, 7); // 3，7 的出现范围为 [1, 2]
```

### 通用写法：查找第一个满足条件的位置

将比较逻辑抽成判断函数 `check`，就能复用同一套二分模板。要求 `check` 在搜索区间上满足“前面都为 `false`，后面都为 `true`”。

```js
// 在 [left, right) 中查找第一个满足 check 的位置，都不满足时返回 right
function findFirst(left, right, check) {
  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (check(mid)) {
      right = mid;
    } else {
      left = mid + 1;
    }
  }
  return left;
}
```

前面的上下界都可以用它表示：

```js
const lower = findFirst(0, nums.length, (i) => nums[i] >= target);
const upper = findFirst(0, nums.length, (i) => nums[i] > target);
```

它也适用于按字段排序的对象数组。例如，日志已按时间升序排列，查找第一条时间不早于 `200` 的日志：

```js
const logs = [
  { id: 1, time: 100 },
  { id: 2, time: 160 },
  { id: 3, time: 230 },
  { id: 4, time: 300 },
];

const index = findFirst(0, logs.length, (i) => logs[i].time >= 200);
logs[index]; // { id: 3, time: 230 }
```

### 二分答案：整数平方根

二分不只能搜索数组下标，也能搜索答案的取值范围。求非负整数 `x` 的平方根并向下取整时，条件 `k * k > x` 随 `k` 增大从 `false` 变为 `true`。找到第一个满足条件的 `k` 后，`k - 1` 就是答案：

```js
function mySqrt(x) {
  return findFirst(0, x + 1, (k) => k * k > x) - 1;
}

mySqrt(0); // 0
mySqrt(8); // 2
mySqrt(16); // 4
```

示例适用于 `k * k` 不超过 JavaScript 安全整数范围的输入；处理更大的整数时，可以改用 `BigInt`。

## 边界注意事项

| 区间约定 | 初始右边界 | 循环条件 | 排除右半区间 |
| --- | --- | --- | --- |
| 闭区间 `[left, right]` | `n - 1` | `left <= right` | `right = mid - 1` |
| 左闭右开 `[left, right)` | `n` | `left < right` | `right = mid` |

- 不要混用两种模板的循环条件和边界更新方式。
- 中间位置已被排除时，向右搜索应使用 `left = mid + 1`，避免区间不缩小导致死循环。
- 使用 `Math.floor` 计算整数下标；JavaScript 的位运算会将数值转为 32 位整数，不宜直接用 `>> 1` 处理大下标。
- 以上比较规则依赖升序排列。若输入无序，需要先排序，但排序会改变原有下标，并增加预处理成本。

## 应用场景

- 在有序数组中快速查找目标值或插入位置。
- 查找重复元素的首尾位置、统计出现次数。
- 查找不超过或不小于某个值的元素，以及最接近目标值的元素。
- 在按时间、分数等字段排序的数据中查找第一个或最后一个满足条件的记录。
- 对满足单调性的判断条件进行“二分答案”，例如求整数平方根、寻找满足容量要求的最小值；此时总复杂度还要乘以每次判断的复杂度。
